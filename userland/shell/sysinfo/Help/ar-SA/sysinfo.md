## NAME

sysinfo — الاستعلام عن معلومات النظام

## SYNOPSIS

`sysinfo <query>`

## DESCRIPTION

يصدر استعلامًا منمّطًا واحدًا إلى واجهة معلومات النظام ويعرض الرد. ليس
في TAIRiX ملفا `/proc` ولا `/sys`: هذا الأمر هو وجه الطرفية للواجهة
نفسها ذات الإصدارات والمفحوصة بالقدرات التي يستخدمها كل برنامج، ولا
مسار يتجاوز فحص القدرة.

الاستعلامات:

- `processes`، `ps` — سرد العمليات، صف لكل عملية.
- `memory`، `mem` — إحصاءات ذاكرة النواة (يحتاج
  `CAP_SYSINFO_KERNEL`).
- `hardware`، `hw` — شجرة العتاد المكتشفة (يحتاج `CAP_SYSINFO_HW`).
- `identity`، `id` — هوية الجهاز وإصدار نظام التشغيل.
- `uptime` — الزمن منذ الإقلاع ووقت ساعة الحائط للإقلاع.
- `limits`، `rlimits` — حدود مواردك الفعلية والاستخدام الحي.
- `seats` — جرد المقاعد: مالك كل شاشة ووحدة التحكم الأمامية لها
  (يتطلب `CAP_SYSINFO_HW`).
- `pressure` — مقياس ضغط الذاكرة الحي: النطاق وعلامات المياه وعدّادات
  الانتقال (يتطلب `CAP_SYSINFO_KERNEL`).
- `reclaim` — سجل الذاكرات المؤقتة القابلة للاستعادة، سطر لكل فئة
  (يتطلب `CAP_SYSINFO_KERNEL`).
- `ramzip` — عدّادات طبقة الذاكرة المضغوطة (يتطلب `CAP_SYSINFO_KERNEL`).
- `cpu` — عمق قائمة التشغيل وتبديلات السياق والاستباقات لكل معالج
  (يتطلب `CAP_SYSINFO_KERNEL`).
- `irq`، `irqs` — جدول مقاطعات النواة: سطر لكل خط مقاطعة مرتبط — معرّفه،
  ومهمة المشغّل المالكة، وعدد المقاطعات منذ الإقلاع، وما إذا كان الخط في
  الحجر (يتطلب `CAP_SYSINFO_HW`).
- `cpuinfo` — تقرير المعالج لكل وحدة معالجة (مجموعة أوسع من
  `/proc/cpuinfo`): الطراز والمُصنّع، وفئة الأداء، وأعلام امتدادات
  مجموعة التعليمات، وسجل الهوية الخام، وسرعة ساعة النواة المقيسة حيًّا
  (بالميغاهرتز — أو «unknown» بصدق حيث لا يوجد عدّاد لساعة النواة)،
  والتردد المرجعي أو قاعدة الوقت الثابتة. حقائق عتاد عامة، ولا تتطلب أي
  قدرة.
- `storage`، `io` — صحة إدخال وإخراج التخزين لكل وحدة تخزين: سطر لكل وحدة
  تخزين كتلية مدركة للأعطال — بادئة معرّفها الدائم، ونقطة خدمة الكتل التي
  تخدمها، وتوافرها الحالي (available/degraded/recovering/lost)، وعدّادات
  النتائج التراكمية (الإتمامات، وإعادات التهيئة، والمُهلات، وأخطاء
  الوسيط، وإعادات الإصدار) التي يظهر عندها القرص المتعطل أو المتقطع
  (يتطلب `CAP_SYSINFO_KERNEL`).
- `raid`، `arrays` — مصفوفات RAID المُركّبة والأجهزة التي يحتفظ بها مُركّب
  المصفوفات: سطر لكل مصفوفة — بادئة هويتها، ومستواها، وصحتها
  (optimal/degraded/recovering/failed)، وعدد الأعضاء المتزامنين
  والمُعرّفين، ووحدة التشريح، وعدد الكتل، وأي إعادة بناء أو تحقق جارٍ —
  ثم سطر لكل جهاز — عقدته في شجرة العتاد، والمصفوفة التي ينتمي إليها
  (شَرطة للمرشّح غير المنتسب)، وفتحته، ودوره
  (candidate/held/in-sync/resyncing/faulted)، وحجمه، وجيل البيانات
  الوصفية الذي يحمله (يتطلب `CAP_SYSINFO_HW`).
- `show <resource-ref>` — يقرأ مرجع مورد واحدًا من `info:`/`state:`/`stats:`
  ويطبع قيمته. هذه الفضاءات تقدّم قيمًا مُصنّفة عبر هذه الواجهة، لا مجاري
  بايتات، فلا يستطيع `cat` فتحها. والرفض يذكر القدرة المطلوبة.
- `describe <resource-ref>` — يطبع مغلّف الاستجابة بدلًا من القيمة: منتجها،
  والتفويض الذي قُدّمت به، وبيانات الحمل الوصفية — لمقياس: نوعه ووحدته
  وسلوك تصفيره ونافذة قياسه؛ ولحقيقة: نوعها وحساسيتها.
- `help` — المساعدة القصيرة لهذا الأمر نفسه.

بدون استعلام تُعرض المساعدة القصيرة.

## OPTIONS

- `--all, -a` — مع `processes`: سرد كل عمليات النظام لا عملياتك فقط؛
  لا يمنح الخدمة هذه الرؤية إلا لمستدعٍ يحمل `CAP_SYSINFO_GLOBAL`.
- `-h, -?` — عرض المساعدة القصيرة لهذا الأمر نفسه.

## EXAMPLES

- `sysinfo identity` — طباعة هوية الجهاز وإصدار نظام التشغيل.
- `sysinfo ps --all` — سرد كل عمليات النظام.

## EXIT STATUS

- `0` — أُجيب الاستعلام وعُرض.
- `1` — رفضت الخدمة أو فشلت، أو تعذّر إيصال النتيجة.
- `2` — لم يُفهم سطر الأوامر.

## ENVIRONMENT

- `LANG` — المنطقة المفضلة للمساعدة القصيرة (وسم BCP-47 مثل `ar-SA`).
