## NAME

users — إدارة حسابات المستخدمين والمجموعات

## SYNOPSIS

`users [-h | -?]`

## DESCRIPTION

يشغّل جلسة إدارة الحسابات التفاعلية فوق الواجهة المبوَّبة
`users_admin`. تُقرَّر كل عملية في جانب النواة تحت هويتك الموثّقة من
النواة: بدون `CAP_USER_ADMIN` في سقف حسابك تُرفض كل عملية عند
الإرسال. تُقرأ كلمات السر مع إطفاء صدى الطرفية وتُهشّر في جانب العميل
إلى سجل مملّح؛ النص الصريح لا يعبر الواجهة أبدًا ولا يُردَّد صداه ولا
يُسجَّل.

لا تأخذ الأداة معطيات: تُدار الحسابات بأوامر تُكتب داخل الجلسة.

- `list` — سرد حسابات المستخدمين.
- `groups` — سرد المجموعات.
- `create <name> <uid> <gid>` — إنشاء حساب.
- `passwd <name>` — ضبط كلمة سر حساب.
- `lock <name>`، `unlock <name>` — تعطيل حساب أو إعادة تمكينه.
- `grant <name> <CAP_...>`، `revoke <name> <CAP_...>` — تحرير منح
  القدرات لحساب.
- `deluser <name>` — حذف حساب.
- `addgroup`، `delgroup` — إنشاء مجموعة أو حذفها.
- `help` — سرد أوامر الجلسة.
- `exit`، `quit` — إنهاء الجلسة.

## OPTIONS

- `-h, -?` — عرض المساعدة القصيرة لهذا الأمر نفسه والخروج.

## EXIT STATUS

- `0` — انتهت الجلسة نظيفة، أو عُرضت المساعدة القصيرة.
- `2` — لم يُفهم سطر الأوامر.

## ENVIRONMENT

- `LANG` — المنطقة المفضلة للمساعدة القصيرة (وسم BCP-47 مثل `ar-SA`).
