## NAME

users — ユーザーアカウントとグループを管理する

## SYNOPSIS

`users [-h | -?]`

## DESCRIPTION

門で守られた `users_admin` インターフェースの上で、対話的なアカウント管
理セッションを実行します。すべての操作はカーネル側で、カーネルが証明した
あなたの身元のもとに裁定されます。アカウントの上限に `CAP_USER_ADMIN` が
なければ、すべての操作はディスパッチの時点で拒否されます。パスワードは端
末のエコーを切って読み取られ、クライアント側で塩付きレコードへハッシュ化
されます。平文がインターフェースを渡ることはなく、エコーも記録もされませ
ん。

このツールはオペランドを取りません。アカウントはセッション内で打つコマン
ドで管理します。

- `list` — ユーザーアカウントを一覧する。
- `groups` — グループを一覧する。
- `create <name> <uid> <gid>` — アカウントを作る。
- `passwd <name>` — アカウントのパスワードを設定する。
- `lock <name>`、`unlock <name>` — アカウントを無効化・再有効化する。
- `grant <name> <CAP_...>`、`revoke <name> <CAP_...>` — アカウントの権
  能付与を編集する。
- `deluser <name>` — アカウントを削除する。
- `addgroup`、`delgroup` — グループを作る・削除する。
- `help` — セッションのコマンドを一覧する。
- `exit`、`quit` — セッションを終える。

## OPTIONS

- `-h, -?` — このコマンド自身の短いヘルプを表示して終了する。

## EXIT STATUS

- `0` — セッションがきれいに終わった、または短いヘルプを表示した。
- `2` — コマンド行を解釈できなかった。

## ENVIRONMENT

- `LANG` — 短いヘルプの優先ロケール（`ja-JP` のような BCP-47 タグ）。
