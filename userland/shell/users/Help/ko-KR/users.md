## NAME

users — 사용자 계정과 그룹 관리하기

## SYNOPSIS

`users [-h | -?]`

## DESCRIPTION

문지기가 있는 `users_admin` 인터페이스 위에서 대화형 계정 관리 세션을
실행합니다. 모든 작업은 커널 쪽에서, 커널이 증명한 당신의 신원 아래
결정됩니다. 계정 상한에 `CAP_USER_ADMIN`이 없으면 모든 작업이 분배
시점에 거부됩니다. 비밀번호는 터미널 에코를 끈 채 읽히고 클라이언트
쪽에서 소금 친 레코드로 해시됩니다. 평문은 인터페이스를 결코 건너지
않으며 에코되거나 기록되지도 않습니다.

이 도구는 피연산자를 받지 않습니다. 계정은 세션 안에서 입력하는 명령으로
관리합니다.

- `list` — 사용자 계정을 나열합니다.
- `groups` — 그룹을 나열합니다.
- `create <name> <uid> <gid>` — 계정을 만듭니다.
- `passwd <name>` — 계정의 비밀번호를 설정합니다.
- `lock <name>`, `unlock <name>` — 계정을 비활성화하거나 다시
  활성화합니다.
- `grant <name> <CAP_...>`, `revoke <name> <CAP_...>` — 계정의 능력
  부여를 편집합니다.
- `deluser <name>` — 계정을 삭제합니다.
- `addgroup`, `delgroup` — 그룹을 만들거나 삭제합니다.
- `help` — 세션 명령을 나열합니다.
- `exit`, `quit` — 세션을 끝냅니다.

## OPTIONS

- `-h, -?` — 이 명령 자체의 짧은 도움말을 표시하고 종료합니다.

## EXIT STATUS

- `0` — 세션이 깨끗하게 끝났거나 짧은 도움말이 표시되었습니다.
- `2` — 명령줄을 이해하지 못했습니다.

## ENVIRONMENT

- `LANG` — 짧은 도움말의 선호 로캘(`ko-KR` 같은 BCP-47 태그).
