## NAME

users — адмініструвати облікові записи користувачів та групи

## SYNOPSIS

`users [-h | -?]`

## DESCRIPTION

Запускає інтерактивний сеанс адміністрування облікових записів через
контрольований інтерфейс `users_admin`. Кожна операція вирішується на
боці ядра за вашою посвідченою ядром ідентичністю: без
`CAP_USER_ADMIN` у стелі вашого облікового запису будь-яку операцію
буде відхилено під час диспетчеризації. Паролі читаються з вимкненим
відлунням термінала та хешуються на боці клієнта в засолений запис;
відкритий текст ніколи не перетинає інтерфейс і ніколи не показується
та не журналюється.

Інструмент не приймає операндів: облікові записи адмініструються
командами, набраними в сеансі.

- `list` — вивести облікові записи користувачів.
- `groups` — вивести групи.
- `create <name> <uid> <gid>` — створити обліковий запис.
- `passwd <name>` — встановити пароль облікового запису.
- `lock <name>`, `unlock <name>` — вимкнути чи знову ввімкнути
  обліковий запис.
- `grant <name> <CAP_...>`, `revoke <name> <CAP_...>` — змінити надані
  обліковому запису можливості.
- `deluser <name>` — видалити обліковий запис.
- `addgroup`, `delgroup` — створити чи видалити групу.
- `help` — вивести команди сеансу.
- `exit`, `quit` — завершити сеанс.

## OPTIONS

- `-h, -?` — показати коротку довідку цієї команди та вийти.

## EXIT STATUS

- `0` — сеанс завершився чисто, або було показано коротку довідку.
- `2` — командний рядок не було зрозуміло.

## ENVIRONMENT

- `LANG` — бажана локаль для короткої довідки (тег BCP-47, як-от
  `uk-UA`).
