## NAME

elsh — TAIRiX のコマンドシェル

## SYNOPSIS

`elsh [-h | -?]`

## DESCRIPTION

対話的なコマンドシェル — 継承した標準ストリーム上の読取・評価・印字ルー
プ — を実行します。打鍵されたコマンド語はまずシェルの組み込みコマンドに
対して、次にシステムアプリストア（`/System/Apps`）、次に `PATH` 変数の
ディレクトリに対して解決されます。ストアは `PATH` より先に探されるので、
`PATH` がシステムコマンドを覆い隠すことはできません。解決できない語は
`127` で終了し、解決できたが実行できないバンドルは `126` で終了します。

組み込みコマンド：

- `cd <path>`、`pwd` — 作業ディレクトリの変更と印字。
- `echo ...` — オペランドの印字。
- `export NAME=value`、`unset NAME` — エクスポートされた環境の編集。
- `jobs`、`fg`、`bg` — ジョブ制御。
- `ulimit` — 資源制限の読み取りと設定。
- `elevate` — コンソールのログイン監督者を通して再認証したうえでコマン
  ドを一つ実行する。
- `help` — 組み込みコマンドの一覧。
- `exit [code]` — セッションを終える。

シェルはオペランドを取りません。スクリプトの実行はまだ文法に含まれてい
ません。

端末ではシェルは対話的な行エディタを提供します。上下キーでコマンド履歴をたどり、`Ctrl-R` で履歴を検索し、`Ctrl-C`
で編集中の行を破棄し、空行での `Ctrl-D` でセッションを終了します。Tab はコマンド名、パス、`sys:random`
のようなリソース参照を補完します。

## OPTIONS

- `-h, -?` — このコマンド自身の短いヘルプを表示して終了する。

## EXIT STATUS

- 組み込み `exit` のコード。入力ストリームが終わったとき（または短いヘ
  ルプを表示したとき）は `0`。
- `2` — 呼び出しを解釈できなかった。

## ENVIRONMENT

- `PATH` — システムアプリストアの後に探すディレクトリ。
- `LANG` — 短いヘルプの優先ロケール（`ja-JP` のような BCP-47 タグ）。起
  動されるすべてのコマンドにエクスポートされる。
