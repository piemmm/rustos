## NAME

elsh — TAIRiX의 명령 셸

## SYNOPSIS

`elsh [-h | -?]`

## DESCRIPTION

대화형 명령 셸 — 상속받은 표준 스트림 위의 읽기-평가-인쇄 루프 — 를
실행합니다. 입력된 명령어는 먼저 셸의 내장 명령에, 그다음 시스템 명령
스토어(`/System/Commands`)에, 시스템 앱 스토어(`/System/Applications`)에,
사용자 자신의 명령 스토어(`<home>/Commands`)와 앱
스토어(`<home>/Applications`)에, 그다음 `PATH` 변수의 디렉터리들에 대해
해석됩니다. 이 네 스토어는 사용자가 재정렬하거나 재정의할 수 없는 고정된
접두부이므로 `PATH`는 시스템 명령을 결코 가릴 수 없습니다. 해석되지 않는
단어는 `127`로 종료하고, 해석되었으나 실행할 수 없는 번들은 `126`으로
종료합니다.

내장 명령:

- `cd <path>`, `pwd` — 작업 디렉터리를 바꾸고 인쇄합니다.
- `echo ...` — 피연산자를 인쇄합니다.
- `export NAME=value`, `unset NAME` — 내보낸 환경을 편집합니다.
- `jobs`, `fg`, `bg` — 작업 제어.
- `ulimit` — 자원 제한을 읽고 부과합니다.
- `elevate` — 콘솔의 로그인 감독자를 통해 재인증한 뒤 명령 하나를
  실행합니다.
- `help` — 내장 명령을 나열합니다.
- `exit [code]` — 세션을 끝냅니다.

셸은 피연산자를 받지 않습니다. 스크립트 실행은 아직 문법에 없습니다.

터미널에서 셸은 대화형 줄 편집기를 제공합니다. 위/아래 화살표로 명령 기록을 이동하고, `Ctrl-R` 로 기록을 검색하며,
`Ctrl-C` 는 편집 중인 줄을 버리고, 빈 줄에서 `Ctrl-D` 는 세션을 끝냅니다. Tab 은 명령 이름, 경로,
`sys:random` 같은 리소스 참조를 완성합니다.

## OPTIONS

- `-h, -?` — 이 명령 자체의 짧은 도움말을 표시하고 종료합니다.

## EXIT STATUS

- 내장 `exit`의 코드, 또는 입력 스트림이 끝났을 때(또는 짧은 도움말이
  표시되었을 때) `0`.
- `2` — 호출을 이해하지 못했습니다.

## ENVIRONMENT

- `PATH` — 고정된 스토어 접두부 다음에 검색되는 디렉터리들.
- `LANG` — 짧은 도움말의 선호 로캘(`ko-KR` 같은 BCP-47 태그). 시작되는
  모든 명령에 내보내집니다.
