## NAME

files — 图形文件系统浏览器

## SYNOPSIS

`files`

## DESCRIPTION

打开一个桌面窗口列出文件系统，从根视图开始。顶行显示当前目录的路径；
下方各行列出该目录的条目，选中的条目以当前主题的强调色高亮。每次目录
读取都是在启动用户身份下经过权限检查的普通列目录操作：无法读取的目录
会被拒绝，绝不猜测。

浏览器可以从桌面的开始菜单（`Files` 项）启动，也可以在 shell 中按名称
启动。它需要一个正在运行的图形会话：没有图形会话时，窗口通道不可达，
浏览器会在标准错误流上报告拒绝原因并退出。

窗口用键盘操作：`下` 和 `上` 移动选择，`回车` 打开选中的目录，
`退格` 返回上级目录。从桌面关闭窗口即结束浏览器。

## EXIT STATUS

正常关闭后返回零；当窗口通道、共享帧区域或初始目录列表被拒绝时返回非
零（原因写在标准错误流上）。
