## NAME

files — 图形文件系统浏览器

## SYNOPSIS

`files [--desktop] [directory] [-h | -?]`

## DESCRIPTION

打开一个桌面窗口列出文件系统，从命令行上给出的 `directory` 开始；未给
出时从启动用户的主目录开始。顶行显示当前目录的路径；下方各行列出该目
录的条目，选中的条目以当前主题的强调色高亮。每次目录读取都是在启动用
户身份下经过权限检查的普通列目录操作：无法读取的目录会被拒绝，绝不猜
测。

浏览器可以从任务栏上永久的 `Files` 按钮启动，也可以在 shell 中按名称
启动。它需要一个正在运行的图形会话：没有图形会话时，窗口通道不可达，
浏览器会在标准错误流上报告拒绝原因并退出。

窗口用键盘操作：`下` 和 `上` 移动选择，`回车` 打开选中的目录，
`退格` 返回上级目录。从桌面关闭窗口即结束浏览器。

`directory` 操作数按不可信输入对待：它必须是系统路径长度限制之内的绝
对路径，其每个组成部分都必须是真实的目录名——`.` 和 `..` 不是，因此一
种写法绝不会指向与其读法不同的地方。违反其中任一规则的目录，或启动用
户无法列出的目录，都会被拒绝并在标准错误流上说明原因，窗口转而在主目
录打开，这样错误的参数绝不会让用户没有窗口。第二个操作数会被直接拒
绝，而不是忽略。

## OPTIONS

- `--desktop` — 作为桌面自身的文件管理器组件运行：图标栏上的一个固定位置，
  提供你的位置和已挂载的卷；在被请求之前不打开窗口，也没有退出的办法。桌面
  会话在启动时传入此选项；与它一同指定 `directory` 会被拒绝，因为组件不会打开
  可以放置它的窗口。
- `-h, -?` — 显示本命令自身的简短帮助并退出。

## EXIT STATUS

正常关闭后，或显示简短帮助后返回零；无法理解命令行时返回 `2`；当窗口
通道、共享帧区域或初始目录列表被拒绝时返回非零（原因写在标准错误流
上）。
