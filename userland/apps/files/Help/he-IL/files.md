## NAME

files — דפדפן גרפי של מערכת הקבצים

## SYNOPSIS

`files`

## DESCRIPTION

פותח חלון בשולחן העבודה המציג את מערכת הקבצים, החל מתצוגת השורש. השורה
העליונה מציגה את נתיב הספרייה הנוכחית; השורות שמתחתיה מפרטות את רשומות
הספרייה, כאשר הרשומה הנבחרת מודגשת בצבע ההדגשה של ערכת הנושא הפעילה.
כל קריאת ספרייה היא רישום רגיל הנבדק מול ההרשאות תחת זהות המשתמש
שהפעיל את התוכנית: ספרייה שאינה ניתנת לקריאה נדחית, ולעולם אינה
מנוחשת.

הדפדפן מופעל מתפריט ההתחלה של שולחן העבודה (הפריט `Files`) או בשמו
ממעטפת. הוא דורש הפעלה גרפית פעילה: בלעדיה ערוץ החלון אינו נגיש,
והדפדפן מדווח על הסירוב בזרם השגיאה התקני ומסתיים.

החלון מופעל במקלדת: `למטה` ו`למעלה` מזיזים את הבחירה, `Enter` פותח את
הספרייה הנבחרת, ו־`Backspace` עולה לספריית האב. סגירת החלון משולחן
העבודה מסיימת את הדפדפן.

## EXIT STATUS

אפס לאחר סגירה נקייה; ערך שונה מאפס כאשר ערוץ החלון, אזור המסגרות
המשותף או הרישום הראשוני של הספרייה נדחו (הסיבה מצוינת בזרם השגיאה
התקני).
