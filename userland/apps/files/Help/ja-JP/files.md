## NAME

files — グラフィカルなファイルシステムブラウザ

## SYNOPSIS

`files`

## DESCRIPTION

ルートビューから始めて、ファイルシステムを一覧表示するデスクトップ
ウィンドウを開きます。最上行は現在のディレクトリのパスを示し、その下
の行はディレクトリの項目を一覧します。選択中の項目は、アクティブな
テーマのアクセント色で強調表示されます。ディレクトリの読み取りはすべ
て、起動したユーザーの身元のもとで権限確認される通常の一覧取得です。
読めないディレクトリは拒否され、推測されることはありません。

ブラウザはデスクトップのスタートメニュー（`Files` 項目）から、または
シェルから名前で起動します。実行中のグラフィカルセッションが必要で
す。セッションがない場合、ウィンドウチャネルに到達できず、ブラウザは
標準エラーストリームに拒否を報告して終了します。

ウィンドウはキーボードで操作します。`下` と `上` で選択を移動し、
`Enter` で選択したディレクトリを開き、`Backspace` で親ディレクトリに
戻ります。デスクトップからウィンドウを閉じるとブラウザは終了します。

## EXIT STATUS

正常に閉じた後はゼロ。ウィンドウチャネル、共有フレーム領域、または
最初のディレクトリ一覧が拒否された場合は非ゼロ（理由は標準エラー
ストリームに出力されます）。
