## NAME

files — グラフィカルなファイルシステムブラウザ

## SYNOPSIS

`files [--desktop] [directory] [-h | -?]`

## DESCRIPTION

コマンド行で指定された `directory` から、指定がなければ起動したユーザー
のホームディレクトリから始めて、ファイルシステムを一覧表示するデスク
トップウィンドウを開きます。最上行は現在のディレクトリのパスを示し、そ
の下の行はディレクトリの項目を一覧します。選択中の項目は、アクティブな
テーマのアクセント色で強調表示されます。ディレクトリの読み取りはすべ
て、起動したユーザーの身元のもとで権限確認される通常の一覧取得です。
読めないディレクトリは拒否され、推測されることはありません。

ブラウザはタスクバーの固定 `Files` ボタンから、またはシェルから名前
で起動します。実行中のグラフィカルセッションが必要です。セッション
がない場合、ウィンドウチャネルに到達できず、ブラウザは標準エラー
ストリームに拒否を報告して終了します。

ウィンドウはキーボードで操作します。`下` と `上` で選択を移動し、
`Enter` で選択したディレクトリを開き、`Backspace` で親ディレクトリに
戻ります。デスクトップからウィンドウを閉じるとブラウザは終了します。

`directory` オペランドは信頼できない入力として扱われます。システムのパ
ス長制限に収まる絶対パスでなければならず、その各構成要素は本物のディレ
クトリ名でなければなりません。`.` と `..` はそれに当たらないため、ある
綴りが読めるとおりの場所以外を指すことは決してありません。これらの規則
のいずれかに反するディレクトリ、または起動したユーザーが一覧できない
ディレクトリは、理由を標準エラーストリームに示して拒否され、ウィンドウ
は代わりにホームディレクトリで開きます。したがって、誤った引数によって
ユーザーがウィンドウを得られなくなることはありません。二つ目のオペラン
ドは無視されるのではなく、そのまま拒否されます。

## OPTIONS

- `--desktop` — デスクトップ自身のファイルマネージャー構成要素として動作
  する。アイコンバー上の恒久的なスロットが自分の場所とマウント済みボリュー
  ムを提示し、求められるまでウィンドウは開かず、終了する手段もない。デスク
  トップセッションが起動時にこれを渡す。これと併せて `directory` を指定するこ
  とは拒否される。構成要素はそれを入れるウィンドウを開かないからである。
- `-h, -?` — このコマンド自身の短いヘルプを表示して終了する。

## EXIT STATUS

正常に閉じた後、または短いヘルプを表示した後はゼロ。コマンド行を解釈で
きなかった場合は `2`。ウィンドウチャネル、共有フレーム領域、または最初
のディレクトリ一覧が拒否された場合は非ゼロ（理由は標準エラーストリーム
に出力されます）。
