## NAME

files — 그래픽 파일 시스템 탐색기

## SYNOPSIS

`files [directory] [-h | -?]`

## DESCRIPTION

명령줄에 지정한 `directory`에서, 지정하지 않으면 실행한 사용자의 홈
디렉터리에서 시작하여 파일 시스템을 나열하는 데스크톱 창을 엽니다. 맨
위 행은 현재 디렉터리의 경로를 보여 주고, 그 아래 행들은 디렉터리의
항목을 나열하며, 선택된 항목은 활성 테마의 강조 색으로 표시됩니다.
모든 디렉터리 읽기는 실행한 사용자의 신원으로 권한 검사를 거치는
일반적인 목록 조회입니다. 읽을 수 없는 디렉터리는 거부되며, 결코
추측하지 않습니다.

탐색기는 작업 표시줄의 고정 `Files` 버튼에서 또는 셸에서 이름으로
실행합니다. 실행 중인 그래픽 세션이 필요합니다. 세션이 없으면 창
채널에 도달할 수 없고, 탐색기는 표준 오류 스트림에 거부 사유를
보고하고 종료합니다.

창은 키보드로 조작합니다. `아래`/`위`는 선택을 이동하고, `Enter`는
선택한 디렉터리를 열며, `Backspace`는 상위 디렉터리로 올라갑니다.
데스크톱에서 창을 닫으면 탐색기가 종료됩니다.

`directory` 피연산자는 신뢰할 수 없는 입력으로 취급됩니다. 시스템의
경로 길이 한계 안에 있는 절대 경로여야 하며, 각 구성 요소는 실제
디렉터리 이름이어야 합니다. `.`과 `..`은 그렇지 않으므로, 어떤 표기도
읽히는 곳과 다른 곳을 뜻할 수 없습니다. 그 규칙 중 하나라도 어기는
디렉터리, 또는 실행한 사용자가 나열할 수 없는 디렉터리는 사유를 표준
오류 스트림에 알리며 거부되고, 창은 대신 홈 디렉터리에서 열립니다.
따라서 잘못된 인수 때문에 사용자에게 창이 없는 일은 없습니다. 두 번째
피연산자는 무시되지 않고 그대로 거부됩니다.

## OPTIONS

- `-h, -?` — 이 명령 자체의 짧은 도움말을 표시하고 종료합니다.

## EXIT STATUS

정상적으로 닫히거나 짧은 도움말을 표시한 뒤에는 0. 명령줄을 이해하지
못하면 `2`. 그 밖에 창 채널, 공유 프레임 영역 또는 초기 디렉터리 목록이
거부되면 0이 아닌 값(사유는 표준 오류 스트림에 기록됩니다).
