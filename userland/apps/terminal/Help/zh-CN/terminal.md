## NAME

terminal — 图形终端仿真器

## SYNOPSIS

`terminal`

## DESCRIPTION

打开一个桌面窗口，在 80×24 字符的屏幕上承载用户的默认 shell。输入到
获得焦点窗口的按键被发送给 shell；shell 写出的一切（标准输出与标准
错误一样）都通过共享的 ANSI/VT 词汇表解释，并用当前主题的调色板绘
制。终端本身从不回显：回显与行编辑属于 shell，与控制台上完全一致。

终端从桌面的程序库（任务栏上的 `Library` 按钮）启动，或在 shell 中
按名称启动。它需要一个正在运行的图形会话：没有它，窗口通道不可达，
终端会在标准错误流上报告拒绝并退出。

当 shell 退出（例如执行 `exit`）或从桌面关闭窗口时，会话结束；关闭
窗口会以输入端的文件结束符结束 shell。

## EXIT STATUS

干净关闭或 shell 自行退出后为零；当无法承载 shell，或窗口通道、共享
帧区域或事件信箱被拒绝时为非零（原因会写在标准错误流上）。
