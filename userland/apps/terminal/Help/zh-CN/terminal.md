## NAME

terminal — 图形终端仿真器

## SYNOPSIS

`terminal`

## DESCRIPTION

打开一个桌面窗口，在 80×25 字符的屏幕上承载用户的默认 shell。输入到
获得焦点窗口的按键被发送给 shell；shell 写出的一切（标准输出与标准
错误一样）都通过共享的 ANSI/VT 词汇表解释，并以设置中选择的配色方案
绘制。终端本身从不回显：回显与行编辑属于 shell，与控制台上完全一致。

窗口以 80×25 屏幕在当前文本大小下的测量尺寸打开，以便适应其显示的
显示器；如果屏幕对于该尺寸太小，则会缩小文本而不是缩小窗口，因为
针对 80 列进行布局的程序仍然必须获得这 80 列。

终端从桌面的程序库（任务栏上的 `Library` 按钮）启动，或在 shell 中
按名称启动。它需要一个正在运行的图形会话：没有它，窗口通道不可达，
终端会在标准错误流上报告拒绝并退出。

当 shell 退出（例如执行 `exit`）或从桌面关闭窗口时，会话结束；关闭
窗口会以输入端的文件结束符结束 shell。

在屏幕上的任意位置按鼠标副键（右键）可打开终端菜单。每一行都有一个
键盘快捷键，无论菜单是否打开都有效；按 `Escape` 或点击菜单外的位置
可将其取消而不进行选择。

| 行 | 快捷键 | 作用 |
| --- | --- | --- |
| 设置… | `Ctrl ,` | 打开下面描述的设置。 |
| 放大文本 | `Ctrl +` | 将屏幕绘制大一阶。 |
| 缩小文本 | `Ctrl -` | 将屏幕绘制小一阶。 |
| 实际大小 | `Ctrl 0` | 返回默认文本大小。 |
| 清除屏幕 | `Ctrl Shift K` | 在不写入 shell 的情况下清空屏幕。 |
| 关闭 | `Ctrl Shift W` | 关闭窗口并结束 shell。 |

设置在窗口内打开，有两个选项卡。**外观** (Appearance) 选择配色方案，
设置文本大小，并编辑用户自己的方案。附带的方案有 *System*（跟随桌面
的深色或浅色外观）、*Midnight*、*Phosphor*、*Amber*、*Ember*、
*Contrast*、*Paper* 和 *Custom*。选择 *Custom* 将使用选择器下方编辑
的颜色：由 20 种颜色组成的网格，屏幕即由此绘制——包括背景、前景、
光标、光标文本以及 16 种 ANSI 颜色——并为当前选中的颜色提供红、绿、
蓝滑块。

**效果** (Effects) 设置屏幕的绘制方式。

| 效果 | 作用 |
| --- | --- |
| 不透明度 | 背景的坚实程度。低于满值时，桌面会从文本后面透出，而文本仍保持完全清晰。 |
| 背景模糊 | 透视窗口后面的桌面模糊程度。对完全不透明的窗口没有影响。 |
| 扫描线 | 使隔行变暗，这是阴极射线管阴影掩模外观的平坦部分。 |
| 噪点 | 一种运动的每像素底噪，就像模拟信号所具有的那样。 |
| 磷光 | 亮起像素的持续时间，使快速滚动的文本留下拖尾。 |
| 抖动 | 一种缓慢移动的水平波动，就像失步的显像管那样。 |

每项更改都会立即生效，并保存到用户自己的配置文件
`~/Settings/Terminal/terminal.conf` 中，因此以后的终端将以相同的方式
打开。该配置文件是一个包含 `键 值` 行的纯文本文件，以 `#` 开头表示
注释，可以手动编辑；颜色写为六位纯十六进制数字（`1b242e`），绝不带有
前导 `#`，否则会开始一个注释。配置文件缺失表示使用默认值；终端无法
读取或解析的配置文件也表示使用默认值，其原因会报告在标准错误流上。

## EXIT STATUS

干净关闭或 shell 自行退出后为零；当无法承载 shell，或窗口通道、共享
帧区域或事件信箱被拒绝时为非零（原因会写在标准错误流上）。

## ENVIRONMENT

`HOME`
: 账户的主目录，终端在其中读写自己的配置文件。没有它，终端将以默认
配置运行，并且不保存任何内容。

`TERM`
: 以 `xterm-256color` 导出给所承载的 shell，用于说明此终端呈现的
仿真器。任何继承而来的值都会被替换；环境的其余部分原样传递给 shell。
