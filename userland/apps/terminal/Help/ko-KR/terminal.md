## NAME

terminal — 그래픽 터미널 에뮬레이터

## SYNOPSIS

`terminal`

## DESCRIPTION

80×24 문자 화면에서 사용자의 기본 셸을 호스팅하는 데스크톱 창을
엽니다. 초점이 있는 창에 입력된 키는 셸로 전송되며, 셸이 쓰는 모든
것(표준 출력과 표준 오류 모두)은 공유 ANSI/VT 어휘로 해석되어 활성
테마의 팔레트로 그려집니다. 터미널 자체는 결코 에코하지 않습니다.
에코와 줄 편집은 콘솔에서와 똑같이 셸의 몫입니다.

터미널은 데스크톱의 시작 메뉴(`Terminal` 항목)에서 또는 셸에서
이름으로 실행합니다. 실행 중인 그래픽 세션이 필요합니다. 세션이
없으면 창 채널에 도달할 수 없으며, 터미널은 표준 오류 스트림에
거부를 보고하고 종료합니다.

셸이 종료되거나(예: `exit`) 데스크톱에서 창을 닫으면 세션이
끝납니다. 창을 닫으면 셸의 입력에 파일 끝이 전달되어 셸이
종료됩니다.

## EXIT STATUS

정상 종료 또는 셸 자체의 종료 후에는 0입니다. 셸을 호스팅할 수
없거나 창 채널, 공유 프레임 영역 또는 이벤트 우편함이 거부되면 0이
아닌 값입니다(이유는 표준 오류 스트림에 표시됩니다).
