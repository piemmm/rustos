## NAME

terminal — 그래픽 터미널 에뮬레이터

## SYNOPSIS

`terminal`

## DESCRIPTION

80×25 문자 화면에서 사용자의 기본 셸을 호스팅하는 데스크톱 창을
엽니다. 초점이 있는 창에 입력된 키는 셸로 전송되며, 셸이 쓰는 모든
것(표준 출력과 표준 오류 모두)은 공유 ANSI/VT 어휘로 해석되어 설정에서
선택한 색상 테마로 그려집니다. 터미널 자체는 결코 에코하지 않습니다.
에코와 줄 편집은 콘솔에서와 똑같이 셸의 몫입니다.

창은 현재 텍스트 크기에서 80×25 화면이 측정되는 크기로 열리므로,
창이 표시되는 디스플레이에 맞춰집니다. 해당 크기에 비해 화면이 너무
작으면 창을 좁히는 대신 텍스트 크기를 줄입니다. 이는 80열로 레이아웃을
잡는 프로그램이 여전히 80열을 확보해야 하기 때문입니다.

터미널은 데스크톱의 프로그램 라이브러리(작업 표시줄의 `Library`
버튼)에서 또는 셸에서 이름으로 실행합니다. 실행 중인 그래픽 세션이
필요합니다. 세션이 없으면 창 채널에 도달할 수 없으며, 터미널은 표준
오류 스트림에 거부를 보고하고 종료합니다.

셸이 종료되거나(예: `exit`) 데스크톱에서 창을 닫으면 세션이
끝납니다. 창을 닫으면 셸의 입력에 파일 끝이 전달되어 셸이
종료됩니다.

화면 어디에서나 보조(오른쪽) 마우스 버튼을 누르면 터미널 메뉴가
열립니다. 모든 항목에는 메뉴가 열려 있는지 여부와 관계없이 작동하는
키보드 단축키가 있으며, `Escape`를 누르거나 메뉴 바깥을 클릭하면
아무것도 선택하지 않고 메뉴를 닫습니다.

| 항목 | 단축키 | 동작 |
| --- | --- | --- |
| 설정… | `Ctrl ,` | 아래에 설명된 설정을 엽니다. |
| 크게 | `Ctrl +` | 화면을 한 단계 크게 그립니다. |
| 작게 | `Ctrl -` | 화면을 한 단계 작게 그립니다. |
| 실제 크기 | `Ctrl 0` | 기본 텍스트 크기로 돌아갑니다. |
| 화면 지우기 | `Ctrl Shift K` | 셸에 쓰지 않고 화면을 지웁니다. |
| 닫기 | `Ctrl Shift W` | 창을 닫고 셸을 종료합니다. |

설정은 창 안에서 열리며 두 개의 탭이 있습니다. **Appearance**(모양)는
색상 테마를 선택하고, 텍스트 크기를 설정하며, 사용자 고유의 테마를
편집합니다. 기본 제공되는 테마는 *System*(데스크톱의 어둡거나 밝은
모양을 따름), *Midnight*, *Phosphor*, *Amber*, *Ember*, *Contrast*,
*Paper*, *Custom*입니다. *Custom*을 선택하면 선택기 아래에서 편집한
색상을 사용합니다. 이는 배경, 전경, 커서, 커서 텍스트 및 16개의 ANSI
색상 등 화면을 구성하는 20개 색상의 격자로, 선택한 색상에 대해 빨강,
초록, 파랑 슬라이더가 있습니다.

**Effects**(효과)는 화면이 그려지는 방식을 설정합니다.

| 효과 | 동작 |
| --- | --- |
| 불투명도 | 배경이 얼마나 불투명한지 설정합니다. 완전히 불투명하지 않으면 배경 너머로 데스크톱이 비쳐 보이지만 텍스트 가독성은 그대로 유지됩니다. |
| 배경 흐림 | 투명한 창 뒤의 데스크톱을 얼마나 흐리게 처리할지 설정합니다. 완전히 불투명한 창에는 효과가 없습니다. |
| 스캔 라인 | 한 줄 걸러 어둡게 하여 섀도우 마스크의 평평한 느낌을 줍니다. |
| 노이즈 | 아날로그 신호에서 볼 수 있는 픽셀당 동적 노이즈를 추가합니다. |
| 잔상 | 불이 켜진 픽셀이 지속되는 시간을 설정하여 빠르게 스크롤되는 텍스트가 궤적을 남기게 합니다. |
| 흔들림 | 동기화가 맞지 않는 브라운관처럼 느리게 이동하는 수평 흔들림을 추가합니다. |

모든 변경 사항은 즉시 적용되며 사용자의 프로필에 저장되어 다음에
터미널을 열 때도 동일하게 적용됩니다. 프로필은 운영체제의 설정
서비스가 보관하며 이 터미널 전용입니다. 다른 어떤 응용 프로그램도
읽거나 변경할 수 없습니다. 사용자가 실제로 바꾼 항목만 저장되므로
*기본값 복원*은 현재 값을 고정하는 것이 아니라 그 선택을 제거합니다.
그러면 관리자나 이후 판의 터미널이 바꾼 값이 적용됩니다. 터미널이
해석할 수 없는 설정은 기본값으로 남고 표준 오류 스트림에 보고되며,
설정 서비스에 도달할 수 없으면 터미널은 함께 배포된 값으로 동작하고
이 또한 보고됩니다.

## EXIT STATUS

정상 종료 또는 셸 자체의 종료 후에는 0입니다. 셸을 호스팅할 수
없거나 창 채널, 공유 프레임 영역 또는 이벤트 우편함이 거부되면 0이
아닌 값입니다(이유는 표준 오류 스트림에 표시됩니다).

## ENVIRONMENT

`HOME`
: 계정의 홈 디렉터리로, 터미널이 프로필을 읽고 쓰는 곳입니다. 이
값이 없으면 터미널은 기본 프로필로 동작하며 아무것도 저장하지
않습니다.

`TERM`
: 호스팅되는 셸에 `xterm-256color`로 내보내어 이 터미널이 제시하는
에뮬레이터를 알립니다. 상속된 값은 대체되며, 나머지 환경은 그대로
셸에 전달됩니다.
