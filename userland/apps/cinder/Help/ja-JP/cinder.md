## NAME

cinder — サークルに住み、デスクトップを歩き回るデスクトップの相棒

## SYNOPSIS

`cinder`

## DESCRIPTION

Cinder の入った小さなサークルのウィンドウを開きます。Cinder は TAIRiX のマスコッ
トで、錆色と炭色の小さな生きものです。うろうろしたり、毛づくろいをしたり、うとう
としたり、ポインタの位置に気づいたりします。

外に出すこともできます。アイコンバーのメニューから **Cinder を外に出す** を選ぶ
と、サークルを出てデスクトップそのものへ行き、ウィンドウの間を歩き回ります。ウィ
ンドウに出会うと、よじ登ってタイトルバーに座ったり、ぺたんと平たくなって下をくぐ
ったり、単に回り込んだりします。どうするかはウィンドウの形と機嫌次第です。ポイン
タを近づけると見つめ、小走りで追いかけ、追いついたら飛びかかります。

クリックすれば撫でられます。サークルの中でも外でも同じです。撫でられると機嫌がよ
くなります。デスクトップに出ているときクリックを受け取るのは本体だけです。まわり
の透明な部分は背後にあるものに属するので、作業中のウィンドウの上に座っていても、
そのウィンドウ宛てのクリックを飲み込むことはありません。

サークルの中では抱き上げて床のどこにでも下ろせますし、ボールを転がして遊べます。

**メニュー.** **Cinder を外に出す** / **Cinder を呼び戻す** で居場所が切り替わります。

**終了** は Cinder を終わらせ、デスクトップから片づけます。

**サークルを閉じる.** サークルのウィンドウを閉じても終了はしません。Cinder は常駐アプリケーションです。
中にいるときに閉じればしまわれ、外にいるときに閉じればそのまま歩き回り続けます。
バーのアイコンをクリックすればサークルをまた開けます。終わらせるのは *終了* です。

**機嫌.** Cinder は三つのことを求めます。休息、遊び、そして付き合いです。走り回ると体力が減
り、昼寝で戻ります。じっとしていると退屈し、ポインタを追いかけると楽しくなります。
撫でられると機嫌がよくなります。これらを管理する必要はありません。餌をやるものは
なく、放っておいても何も悪いことは起きません。ひと目でどんな機嫌かわかるようにす
るためのものです。

どんな気分だったか、外に出ていたかどうかは、セッションをまたいで覚えています。

**外に出られないとき.** ウィンドウの外でデスクトップ上にいるには `CAP_DESKTOP_LAYER` ケーパビリティが必要
です。本アプリケーションは署名済みマニフェストでこれを要求しますが、アカウントの
付与でも許可されている必要があります。許可されていない場合、あるいはグラフィカル
セッションがない場合、**Cinder を外に出す** はその理由をサークル内と標準エラー出
力に示し、サークルはそのまま動き続けます。Cinder は中にいるだけです。

## EXIT STATUS

正常終了なら `0`。ゼロ以外のステータスには必ず理由が標準エラー出力に伴います。
