## NAME

cinder — 住在围栏里、在桌面上闲逛的桌面伙伴

## SYNOPSIS

`cinder`

## DESCRIPTION

打开一个装着 Cinder 的小围栏窗口。Cinder 是 TAIRiX 的吉祥物：一只锈红与炭黑相间
的小生物，会四处溜达、理毛、打盹，并且会注意到你的指针在哪里。

可以把它放出来。在它的图标栏菜单中选择**放 Cinder 出去**，它便离开围栏来到桌面
本身，在你的窗口之间漫步。遇到窗口时，它会爬上去坐在标题栏上，把自己压扁从窗口
下面钻过去，或者干脆绕过去——具体做什么取决于窗口的形状和它的心情。把指针移到它
附近，它会盯着看、小跑着追过去，追上了还会扑上去。

点击它就可以摸摸它，无论在围栏里还是在桌面上。摸摸能让它高兴。在桌面上只有它本
身会接住这次点击：它周围的透明区域属于它后面的东西，所以趴在你工作窗口上的伙伴
绝不会吞掉本该落到那个窗口上的点击。

在围栏里你还可以把它抱起来放到地板上的任何地方，并拨弄那个球。

**菜单.** **放 Cinder 出去** / **把 Cinder 叫回来** 切换它所在的位置。

**退出** 会结束它，并把它从桌面上收走。

**关闭围栏.** 关闭围栏窗口并不会退出。Cinder 是常驻应用：它在里面时关闭围栏就是把它收起来，它
在外面时关闭围栏则让它继续闲逛。点击栏上的图标可以重新打开围栏。结束它的是
*退出*。

**心情.** Cinder 想要三样东西：休息、玩耍和陪伴。跑动会消耗体力，小睡能恢复；一直待着不动
会让它无聊，追指针则让它开心；摸摸能让它高兴。这些你都不需要管理——没有东西要喂
它，你不管它也不会出什么问题。它存在只是为了让你一眼看出它是什么心情。

它的感受，以及它当时是否在外面，都会在会话之间记住。

**当它出不去时.** 要在窗口之外出现在桌面上，需要 `CAP_DESKTOP_LAYER` 能力；本应用在其签名清单中请
求该能力，同时你账户的授权也必须允许。如果不允许——或者没有图形会话——**放 Cinder
出去** 会在围栏中和标准错误上说明原因，而围栏照常工作。Cinder 只是待在里面。

## EXIT STATUS

干净退出时为 `0`。非零状态总会在标准错误上附带原因。
