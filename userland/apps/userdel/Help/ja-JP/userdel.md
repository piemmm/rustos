## NAME

userdel — ユーザーアカウントを削除する

## SYNOPSIS

`userdel [--] NAME`

## DESCRIPTION

ユーザーデータベースからアカウントを一つ取り除きます。アカウントの削除は管理操作です。ユーザー管理の権能を持たない呼び出し元をデータベースは拒否します。

何を取り除けるかを裁定するのはデータベースです。ユーザーを管理できる最後の有効なアカウントの削除は拒否されるので、システムが管理手段を失うことはありません。

`--` はオプション解析を終え、以降のすべての引数はオペランドです。

## OPTIONS

- `-h, -?, --help` — このコマンド自身の短いヘルプを表示します。

## EXAMPLES

- `userdel ada` — アカウント `ada` を削除します。

## EXIT STATUS

- `0` — アカウントを削除しました。
- `1` — データベースが削除を拒否または失敗しました（権能の欠如、未知のアカウント、最後の管理者など）。理由は標準エラーに出力されます。
- `2` — コマンドラインを解釈できませんでした。

## ENVIRONMENT

- `LANG` — 短いヘルプに使う優先ロケール（`ja-JP` のような BCP-47 タグ）。
