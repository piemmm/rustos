## NAME

userdel — 사용자 계정을 삭제한다

## SYNOPSIS

`userdel [--] NAME`

## DESCRIPTION

사용자 데이터베이스에서 계정 하나를 제거합니다. 계정 삭제는 관리 작업이며, 사용자 관리 권능이 없는 호출자는 데이터베이스가 거부합니다.

무엇을 제거할 수 있는지는 데이터베이스가 판단합니다. 사용자를 관리할 수 있는 마지막 활성 계정의 삭제는 거부되므로, 시스템이 관리 수단을 잃는 일은 없습니다.

`--` 는 옵션 해석을 끝내며, 그 뒤의 모든 인수는 피연산자입니다.

## OPTIONS

- `-h, -?, --help` — 이 명령 자체의 짧은 도움말을 표시합니다.

## EXAMPLES

- `userdel ada` — 계정 `ada` 를 삭제합니다.

## EXIT STATUS

- `0` — 계정을 삭제했습니다.
- `1` — 데이터베이스가 삭제를 거부했거나 실패했습니다(권능 부족, 알 수 없는 계정, 마지막 관리자 등). 이유는 표준 오류로 출력됩니다.
- `2` — 명령줄을 이해하지 못했습니다.

## ENVIRONMENT

- `LANG` — 짧은 도움말에 쓰는 선호 로케일(`ko-KR` 같은 BCP-47 태그).
