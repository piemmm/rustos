## NAME

userdel — вилучити обліковий запис користувача

## SYNOPSIS

`userdel [--] NAME`

## DESCRIPTION

Вилучає один обліковий запис із бази користувачів. Вилучення запису — адміністративна дія: база відмовляє тому, хто не має повноваження адміністрування користувачів.

База вирішує, що можна вилучити. Вона відмовляє у вилученні останнього активного запису, який може адмініструвати користувачів, щоб система ніколи не лишилася без способу адміністрування.

`--` завершує розбір параметрів: кожен наступний аргумент є операндом.

## OPTIONS

- `-h, -?, --help` — показати власну коротку довідку цієї команди.

## EXAMPLES

- `userdel ada` — вилучити обліковий запис `ada`.

## EXIT STATUS

- `0` — обліковий запис вилучено.
- `1` — база відмовила або не змогла вилучити (наприклад, бракує повноваження, запис невідомий або це останній адміністратор); причину надруковано на стандартний потік помилок.
- `2` — командний рядок не зрозуміло.

## ENVIRONMENT

- `LANG` — бажана локаль для короткої довідки (позначка BCP-47, наприклад `uk-UA`).
