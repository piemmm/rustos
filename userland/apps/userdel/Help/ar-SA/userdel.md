## NAME

userdel — حذف حساب مستخدم

## SYNOPSIS

`userdel [--] NAME`

## DESCRIPTION

يزيل حسابًا واحدًا من قاعدة بيانات المستخدمين. حذف حساب عملية إدارية: ترفض القاعدة أي مُستدعٍ لا يملك قدرة إدارة المستخدمين.

القاعدة هي المرجع في ما يجوز إزالته. ترفض حذف آخر حساب نشط يستطيع إدارة المستخدمين، كي لا يبقى النظام بلا وسيلة لإدارته.

`--` ينهي تحليل الخيارات: كل وسيط بعده معامل.

## OPTIONS

- `-h, -?, --help` — عرض المساعدة المختصرة لهذا الأمر نفسه.

## EXAMPLES

- `userdel ada` — حذف الحساب `ada`.

## EXIT STATUS

- `0` — حُذف الحساب.
- `1` — رفضت القاعدة الحذف أو أخفقت فيه (مثل قدرة ناقصة أو حساب مجهول أو آخر مدير)؛ يُطبع السبب على خرج الخطأ القياسي.
- `2` — لم يُفهم سطر الأوامر.

## ENVIRONMENT

- `LANG` — اللغة المفضلة للمساعدة المختصرة (وسم BCP-47 مثل `ar-SA`).
