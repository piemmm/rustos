## NAME

groupdel — グループを削除する

## SYNOPSIS

`groupdel [--] NAME`

## DESCRIPTION

グループ台帳からグループを一つ取り除きます。グループの削除は管理操作です。ユーザー管理の権能を持たない呼び出し元を台帳は拒否します。

何を取り除けるかを裁定するのは台帳です。まだアカウントが参照しているグループの削除は拒否されるので、存在しないグループを名指すアカウントは生じません。

`--` はオプション解析を終え、以降のすべての引数はオペランドです。

## OPTIONS

- `-h, -?, --help` — このコマンド自身の短いヘルプを表示します。

## EXAMPLES

- `groupdel staff` — グループ `staff` を削除します。

## EXIT STATUS

- `0` — グループを削除しました。
- `1` — 台帳が削除を拒否または失敗しました（権能の欠如、未知のグループ、まだ参照されているグループなど）。理由は標準エラーに出力されます。
- `2` — コマンドラインを解釈できませんでした。

## ENVIRONMENT

- `LANG` — 短いヘルプに使う優先ロケール（`ja-JP` のような BCP-47 タグ）。
