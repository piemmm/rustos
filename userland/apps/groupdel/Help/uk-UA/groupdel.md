## NAME

groupdel — вилучити групу

## SYNOPSIS

`groupdel [--] NAME`

## DESCRIPTION

Вилучає одну групу з реєстру груп. Вилучення групи — адміністративна дія: реєстр відмовляє тому, хто не має повноваження адміністрування користувачів.

Реєстр вирішує, що можна вилучити. Він відмовляє у вилученні групи, на яку ще посилається обліковий запис, щоб жоден запис не називав неіснуючу групу.

`--` завершує розбір параметрів: кожен наступний аргумент є операндом.

## OPTIONS

- `-h, -?, --help` — показати власну коротку довідку цієї команди.

## EXAMPLES

- `groupdel staff` — вилучити групу `staff`.

## EXIT STATUS

- `0` — групу вилучено.
- `1` — реєстр відмовив або не зміг вилучити (наприклад, бракує повноваження, група невідома або на неї ще посилаються); причину надруковано на стандартний потік помилок.
- `2` — командний рядок не зрозуміло.

## ENVIRONMENT

- `LANG` — бажана локаль для короткої довідки (позначка BCP-47, наприклад `uk-UA`).
