## NAME

cp — 파일과 디렉터리 복사하기

## SYNOPSIS

`cp [-finrRvT] [-t dir] [--] source... dest`

## DESCRIPTION

각 원본 피연산자를 목적지로 복사합니다. 원본이 하나이고 목적지가
디렉터리를 가리키지 않으면 원본은 그 정확한 경로로 복사됩니다. 목적지가
기존 디렉터리를 가리킬 때 — 그리고 원본이 둘 이상일 때는 언제나 — 각
원본은 자신의 기본 이름으로 그 디렉터리 *안으로* 복사됩니다.

디렉터리 원본은 `-r`이 있을 때만 복사되며 하위 트리 전체가 재현됩니다.
`-r`이 없으면 디렉터리 피연산자는 거부됩니다. 기존 대상 파일은 기본으로
덮어쓰이고, `-n`에서는 건너뛰며, `-i`에서는 표준 오류 스트림에서
물어봅니다(거절된 질문은 그 복사를 오류 없이 건너뜁니다. 읽을 수 없는
대답은 결코 동의로 취급되지 않습니다).

첫 실패가 이후의 피연산자로 가기 전에 실행을 멈춥니다. `--`는 옵션
해석을 끝내며, 이후의 모든 인수는 경로입니다.

## OPTIONS

- `-r, -R, --recursive` — 디렉터리와 그 내용을 복사합니다.
- `-f, --force` — 대상 파일을 만들 수 없으면 그것을 제거하고 복사를 한
  번 다시 시도합니다.
- `-i, --interactive` — 기존 파일을 덮어쓰기 전에 물어봅니다.
  `y`/`Y`로 시작하는 대답만 동의합니다.
- `-n, --no-clobber` — 기존 파일을 결코 덮어쓰지 않습니다. `-i`와 `-n`
  중 나중 것이 이깁니다.
- `-v, --verbose` — 각 복사를 `'source' -> 'dest'`로 보고합니다.
- `-t dir, --target-directory=dir` — 모든 원본을 `dir` 안으로
  복사합니다. `dir`은 기존 디렉터리여야 합니다. 값은 붙여서(`-tdir`,
  `--target-directory=dir`) 또는 다음 인수로 줍니다.
- `-T, --no-target-directory` — 목적지를 일반 파일로 취급합니다. 원본은
  정확히 하나만 허용됩니다. `-t`와 함께 쓸 수 없습니다.
- `-h, -?, --help` — 이 명령 자체의 짧은 도움말을 표시합니다.

## EXAMPLES

- `cp notes.txt backup.txt` — 파일 하나를 새 이름으로 복사합니다.
- `cp -r Projects Archive` — `Projects` 트리를 `Archive` 안에
  재현합니다(`Archive`가 없으면 `Archive`로).
- `cp -v -t Backup a.txt b.txt` — 두 파일을 모두 `Backup`으로 복사하며
  각 복사를 보고합니다.

## EXIT STATUS

- `0` — 모든 복사가 성공했습니다(`-n`의 건너뜀과 거절된 `-i` 질문은
  실패가 아닙니다).
- `1` — 파일 시스템, 질문 또는 출력 실패. 이유가 표준 오류에
  인쇄됩니다.
- `2` — 명령줄을 이해하지 못했습니다.

## ENVIRONMENT

- `LANG` — 짧은 도움말의 선호 로캘(`ko-KR` 같은 BCP-47 태그).
