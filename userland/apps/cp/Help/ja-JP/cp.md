## NAME

cp — ファイルとディレクトリを複写する

## SYNOPSIS

`cp [-finrRvT] [-t dir] [--] source... dest`

## DESCRIPTION

各ソースオペランドを宛先へ複写します。ソースが一つで、宛先がディレクトリ
を指さない場合、ソースはその正確なパスへ複写されます。宛先が既存のディレ
クトリを指す場合 — そしてソースが複数あるときは常に — 各ソースはそのディ
レクトリの*中へ*、自身の基底名で複写されます。

ディレクトリのソースは `-r` があるときだけ複写され、部分木全体が再現され
ます。`-r` がなければディレクトリオペランドは拒否されます。既存の宛先
ファイルは既定では上書きされ、`-n` では飛ばされ、`-i` では標準エラースト
リーム上で尋ねられます（断られた質問はその複写をエラーなしで飛ばします。
読めない返答が同意として扱われることは決してありません）。

最初の失敗で、後続のオペランドに移る前に実行が止まります。`--` はオプ
ション解析を終え、以降のすべての引数はパスです。

## OPTIONS

- `-r, -R, --recursive` — ディレクトリとその中身を複写する。
- `-f, --force` — 宛先ファイルを作れないとき、それを削除して複写を一度だ
  けやり直す。
- `-i, --interactive` — 既存ファイルを上書きする前に尋ねる。`y`/`Y` で始
  まる返答だけが同意。
- `-n, --no-clobber` — 既存ファイルを決して上書きしない。`-i` と `-n` は
  後に書かれた方が勝つ。
- `-v, --verbose` — 各複写を `'source' -> 'dest'` の形で報告する。
- `-t dir, --target-directory=dir` — すべてのソースを `dir` へ複写する。
  `dir` は既存のディレクトリでなければならない。値は密着形
  （`-tdir`、`--target-directory=dir`）または次の引数として与える。
- `-T, --no-target-directory` — 宛先を普通のファイルとして扱う。許される
  ソースはちょうど一つ。`-t` とは組み合わせられない。
- `-h, -?, --help` — このコマンド自身の短いヘルプを表示する。

## EXAMPLES

- `cp notes.txt backup.txt` — ファイルを新しい名前へ複写する。
- `cp -r Projects Archive` — `Projects` の木を `Archive` の中に再現する
  （`Archive` がなければ `Archive` として）。
- `cp -v -t Backup a.txt b.txt` — 両ファイルを `Backup` へ複写し、各複写
  を報告する。

## EXIT STATUS

- `0` — すべての複写が成功した（`-n` による飛ばしと断られた `-i` の質問
  は失敗ではない）。
- `1` — ファイルシステム・問いかけ・出力の失敗。理由は標準エラーに印字さ
  れる。
- `2` — コマンド行を解釈できなかった。

## ENVIRONMENT

- `LANG` — 短いヘルプの優先ロケール（`ja-JP` のような BCP-47 タグ）。
