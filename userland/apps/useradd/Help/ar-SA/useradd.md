## NAME

useradd — إنشاء حساب مستخدم

## SYNOPSIS

`useradd [-u UID] -g GID [-G GID[,GID...]] [-c COMMENT] [-d HOME] [--] NAME`

## DESCRIPTION

يضيف حسابًا واحدًا إلى قاعدة بيانات المستخدمين. يجب أن يطابق اسم
الدخول `[a-z_][a-z0-9_-]*`؛ والمجموعة الأساسية (`-g`) مطلوبة وكل
إشارة إلى مجموعة أو مستخدم معرّف عشري. إنشاء حساب عملية إدارية: ترفض
قاعدة البيانات مستدعيًا لا يحمل قدرة إدارة المستخدمين.

الحساب المُنشأ **بلا كلمة سر صالحة للاستعمال**: لا تطابقه أي كلمة سر
حتى يضبط مدير واحدة (ولا يمكن تخمين أي منها)، تمامًا كما تنشئ أداة
GNU حسابًا معطلًا. اضبط كلمة سر لاحقًا بأمر `passwd` في أداة `users`.

عند حذف `-u` يُخصص معرّف المستخدم تلقائيًا، واحدًا فوق أعلى معرّف
موجود. وعند حذف `-d` يكون دليل المنزل التخطيط القياسي `/Users/NAME`.
يبدأ الحساب بصدفة النظام الافتراضية وسقف قدرات الجلسة العادي؛ ويوسّعه
مدير لاحقًا بأمر `grant` في أداة `users`.

ينهي `--` تحليل الخيارات: كل معطى لاحق هو معامل.

## OPTIONS

- `-u, --uid UID` — معرّف المستخدم الرقمي؛ يُخصص تلقائيًا عند حذفه
  (واحدًا فوق أعلى معرّف موجود).
- `-g, --gid GID` — معرّف المجموعة الأساسية الرقمي. مطلوب: لا توجد
  سياسة مجموعة افتراضية تُخمَّن.
- `-G, --groups LIST` — معرّفات مجموعات تكميلية رقمية مفصولة بفواصل.
- `-c, --comment TEXT` — تعليق الحساب / اسم العرض الكامل.
- `-d, --home PATH` — دليل المنزل؛ `/Users/NAME` عند حذفه.
- `-h, -?, --help` — عرض المساعدة القصيرة لهذا الأمر نفسه.

## EXAMPLES

- `useradd -g 100 alice` — إنشاء `alice` في المجموعة الأساسية `100`
  بمعرّف مخصص تلقائيًا.
- `useradd -u 1000 -g 100 -G 10,20 -c 'Alice A' alice` — كل الحقول
  مكتوبة.

## EXIT STATUS

- `0` — أُنشئ الحساب.
- `1` — رفضت قاعدة البيانات الإنشاء أو فشلت فيه (مثلًا قدرة مفقودة أو
  معرّف مكرر أو مجموعة مجهولة)؛ يُطبع السبب على الخطأ القياسي.
- `2` — لم يُفهم سطر الأوامر.

## ENVIRONMENT

- `LANG` — المنطقة المفضلة للمساعدة القصيرة (وسم BCP-47 مثل `ar-SA`).
