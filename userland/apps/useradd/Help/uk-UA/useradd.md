## NAME

useradd — створити обліковий запис користувача

## SYNOPSIS

`useradd [-u UID] -g GID [-G GID[,GID...]] [-c COMMENT] [-d HOME] [--] NAME`

## DESCRIPTION

Додає один обліковий запис до бази користувачів. Ім'я входу має
відповідати `[a-z_][a-z0-9_-]*`; основна група (`-g`) є обов'язковою, а
кожне посилання на групу чи користувача — це десятковий ідентифікатор.
Створення облікового запису — адміністративна операція: база відмовляє
викликачеві без права адміністрування користувачів.

Створений обліковий запис **не має придатного пароля**: жоден пароль не
підходить до нього, доки адміністратор не встановить його (і жоден не
можна вгадати) — саме так інструмент GNU створює вимкнений обліковий
запис. Далі встановіть пароль командою `passwd` інструмента `users`.

Якщо `-u` пропущено, ідентифікатор призначається автоматично — на
одиницю більший за найвищий наявний. Якщо `-d` пропущено, домашній
каталог відповідає стандартній схемі `/Users/NAME`. Обліковий запис
запускає типову оболонку системи та звичайну сесійну стелю прав;
адміністратор розширює її згодом командою `grant` інструмента `users`.

`--` завершує розбір параметрів: кожен подальший аргумент — операнд.

## OPTIONS

- `-u, --uid UID` — числовий ідентифікатор користувача; призначається
  автоматично, якщо пропущено (на одиницю більший за найвищий наявний).
- `-g, --gid GID` — числовий ідентифікатор основної групи.
  Обов'язковий: типової групової політики, яку можна вгадати, немає.
- `-G, --groups LIST` — числові ідентифікатори додаткових груп через
  кому.
- `-c, --comment TEXT` — коментар облікового запису / повне ім'я для
  показу.
- `-d, --home PATH` — домашній каталог; `/Users/NAME`, якщо пропущено.
- `-h, -?, --help` — показати коротку довідку цієї команди.

## EXAMPLES

- `useradd -g 100 alice` — створити `alice` в основній групі `100` з
  автоматично призначеним ідентифікатором.
- `useradd -u 1000 -g 100 -G 10,20 -c 'Alice A' alice` — усі поля
  задано явно.

## EXIT STATUS

- `0` — обліковий запис створено.
- `1` — база відмовила у створенні або воно не вдалося (наприклад,
  відсутнє право, повторюваний ідентифікатор чи невідома група);
  причину надруковано в стандартний потік помилок.
- `2` — командний рядок не зрозуміло.

## ENVIRONMENT

- `LANG` — бажана локаль для короткої довідки (мітка BCP-47, як-от
  `uk-UA`).
