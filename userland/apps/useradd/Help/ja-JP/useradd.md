## NAME

useradd — ユーザーアカウントを作る

## SYNOPSIS

`useradd [-u UID] -g GID [-G GID[,GID...]] [-c COMMENT] [-d HOME] [--] NAME`

## DESCRIPTION

ユーザーデータベースにアカウントを一つ追加します。ログイン名は
`[a-z_][a-z0-9_-]*` に合致しなければなりません。主グループ（`-g`）は必須
で、グループやユーザーへの参照はすべて十進の id です。アカウントの作成は
管理操作です。ユーザー管理の権能を持たない呼び出し元をデータベースは拒否
します。

作られたアカウントには**使えるパスワードがありません**。管理者が設定する
まではどんなパスワードも一致せず（推測もできず）、GNU ツールが無効なアカ
ウントを作るのとまったく同じです。あとで `users` ツールの `passwd` コマン
ドでパスワードを設定してください。

`-u` が省かれると、ユーザー id は既存の最大 id の一つ上へ自動的に割り当
てられます。`-d` が省かれると、ホームディレクトリは標準の `/Users/NAME`
配置になります。アカウントはシステム既定のシェルと、通常のセッション権能
の上限で始まります。管理者はあとで `users` ツールの `grant` コマンドで広
げます。

`--` はオプション解析を終え、以降のすべての引数はオペランドです。

## OPTIONS

- `-u, --uid UID` — 数値のユーザー id。省くと自動割り当て（既存の最大 id
  の一つ上）。
- `-g, --gid GID` — 数値の主グループ id。必須。推測すべき既定グループの
  方針はない。
- `-G, --groups LIST` — コンマ区切りの数値の補助グループ id。
- `-c, --comment TEXT` — アカウントの注記／表示用のフルネーム。
- `-d, --home PATH` — ホームディレクトリ。省くと `/Users/NAME`。
- `-h, -?, --help` — このコマンド自身の短いヘルプを表示する。

## EXAMPLES

- `useradd -g 100 alice` — 主グループ `100` に、自動割り当ての id で
  `alice` を作る。
- `useradd -u 1000 -g 100 -G 10,20 -c 'Alice A' alice` — すべての欄を書
  き切る。

## EXIT STATUS

- `0` — アカウントを作成した。
- `1` — データベースが作成を拒否または失敗した（権能の欠如、id の重複、
  未知のグループなど）。理由は標準エラーに印字される。
- `2` — コマンド行を解釈できなかった。

## ENVIRONMENT

- `LANG` — 短いヘルプの優先ロケール（`ja-JP` のような BCP-47 タグ）。
