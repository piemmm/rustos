## NAME

useradd — 사용자 계정 만들기

## SYNOPSIS

`useradd [-u UID] -g GID [-G GID[,GID...]] [-c COMMENT] [-d HOME] [--] NAME`

## DESCRIPTION

사용자 데이터베이스에 계정 하나를 추가합니다. 로그인 이름은
`[a-z_][a-z0-9_-]*`에 맞아야 합니다. 주 그룹(`-g`)은 필수이고, 그룹이나
사용자 참조는 모두 십진 id입니다. 계정 생성은 관리 작업입니다.
데이터베이스는 사용자 관리 능력이 없는 호출자를 거부합니다.

만들어진 계정에는 **쓸 수 있는 비밀번호가 없습니다**. 관리자가 하나를
설정할 때까지 어떤 비밀번호도 맞지 않으며(추측될 수도 없으며), GNU 도구가
비활성 계정을 만드는 것과 정확히 같습니다. 이후 `users` 도구의 `passwd`
명령으로 비밀번호를 설정하십시오.

`-u`를 생략하면 사용자 id는 기존 최고 id보다 하나 위로 자동
할당됩니다. `-d`를 생략하면 홈 디렉터리는 표준 `/Users/NAME` 배치입니다.
계정은 시스템 기본 셸과 통상의 세션 능력 상한으로 시작하며, 관리자가
이후 `users` 도구의 `grant` 명령으로 넓힙니다.

`--`는 옵션 해석을 끝내며, 이후의 모든 인수는 피연산자입니다.

## OPTIONS

- `-u, --uid UID` — 숫자 사용자 id. 생략하면 자동 할당(기존 최고 id보다
  하나 위).
- `-g, --gid GID` — 숫자 주 그룹 id. 필수: 추측할 기본 그룹 정책이
  없습니다.
- `-G, --groups LIST` — 쉼표로 구분된 숫자 보조 그룹 id.
- `-c, --comment TEXT` — 계정 주석 / 전체 표시 이름.
- `-d, --home PATH` — 홈 디렉터리. 생략하면 `/Users/NAME`.
- `-h, -?, --help` — 이 명령 자체의 짧은 도움말을 표시합니다.

## EXAMPLES

- `useradd -g 100 alice` — 주 그룹 `100`에 자동 할당된 id로 `alice`를
  만듭니다.
- `useradd -u 1000 -g 100 -G 10,20 -c 'Alice A' alice` — 모든 필드를
  명시합니다.

## EXIT STATUS

- `0` — 계정이 만들어졌습니다.
- `1` — 데이터베이스가 생성을 거부했거나 실패했습니다(예: 능력 부재,
  중복 id, 알 수 없는 그룹). 이유가 표준 오류에 인쇄됩니다.
- `2` — 명령줄을 이해하지 못했습니다.

## ENVIRONMENT

- `LANG` — 짧은 도움말의 선호 로캘(`ko-KR` 같은 BCP-47 태그).
