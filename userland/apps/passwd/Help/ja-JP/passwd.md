## NAME

passwd — アカウントのパスワードを設定する

## SYNOPSIS

`passwd [--record RECORD] [--] NAME`

## DESCRIPTION

指定したアカウントの保存済みパスワードを置き換えます。パスワードの設定は管理操作です。ユーザー管理の権能を持たない呼び出し元をデータベースは拒否します。

平文のパスワードがシステムコールを渡ることはありません。端末エコーを切って二度尋ね、入力をソルト付き PBKDF2 レコードへハッシュし —
ソルトはカーネルの乱数源から得ます — レコードを送ります。レコードができた瞬間に平文のバッファは両方とも零化されます。

アカウント名は必須です。GNU の `passwd` はオペランドなしで呼び出し元自身のパスワードを変えますが、TAIRiX
ではそれに非特権のセルフサービス経路が要り、それは存在しません。アカウント管理のインタフェースは全体が権能で守られており、そこに「自分のレコード」の例外を彫ることは利便ではなく安全モデルの変更です。

端末を持たない呼び出し元 — 昇格ブローカーの下で標準入力が閉じられる図形プログラム — は自らハッシュし、出来上がったレコードを `--record`
で渡すので、どちら側にも平文は存在しません。レコードは保存前に整形式か検査されます。

`--` はオプション解析を終え、以降のすべての引数はオペランドです。

## OPTIONS

- `--record RECORD` — 出来合いのソルト付き PBKDF2 レコード。尋ねる端末を持たない呼び出し元のためのものです。
- `-h, -?, --help` — このコマンド自身の短いヘルプを表示します。

## EXAMPLES

- `passwd ada` — 二度尋ねてアカウントのパスワードを設定します。

## EXIT STATUS

- `0` — パスワードを置き換えました。
- `1` — データベースが置き換えを拒否または失敗した、二度の入力が一致しなかった、乱数が得られなかった、あるいはレコードが不正でした。理由は標準エラーに出力されます。
- `2` — コマンドラインを解釈できませんでした。

## ENVIRONMENT

- `LANG` — 短いヘルプに使う優先ロケール（`ja-JP` のような BCP-47 タグ）。
