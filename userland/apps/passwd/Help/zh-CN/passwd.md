## NAME

passwd — 设置账户的口令

## SYNOPSIS

`passwd [--record RECORD] [--] NAME`

## DESCRIPTION

替换所指定账户的已存口令。设置口令是管理操作：数据库会拒绝不具备用户管理权能的调用者。

明文口令绝不跨越系统调用。工具在关闭终端回显的情况下询问两次，把所键入内容散列为带盐的 PBKDF2
记录——盐取自内核随机源——并发送该记录；记录一旦生成，两个明文缓冲区立即清零。

账户名是必需的。GNU `passwd` 不带操作数时更改调用者自身的口令；这在 TAIRiX
上需要一条不存在的非特权自助路径：整个账户管理接口都由权能把守，在其中为「你自己的记录」开一个口子是安全模型的改动，而非便利。

没有终端的调用者——图形程序，在提权代理下其标准输入已关闭——自行散列口令，并以 `--record` 交出成品记录，因而两侧都不存在明文。记录在存储前会被检查是否格式良好。

`--` 结束选项解析：其后的每个参数都是操作数。

## OPTIONS

- `--record RECORD` — 已备妥的带盐 PBKDF2 记录，供没有终端可询问的调用者使用。
- `-h, -?, --help` — 显示本命令自身的简短帮助。

## EXAMPLES

- `passwd ada` — 询问两次并设置该账户的口令。

## EXIT STATUS

- `0` — 口令已替换。
- `1` — 数据库拒绝或未能完成替换、两次输入不一致、没有可用随机性，或记录格式有误；原因打印到标准错误。
- `2` — 未能理解命令行。

## ENVIRONMENT

- `LANG` — 简短帮助首选的区域设置（BCP-47 标签，例如 `zh-CN`）。
