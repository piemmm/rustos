## NAME

passwd — задати пароль облікового запису

## SYNOPSIS

`passwd [--record RECORD] [--] NAME`

## DESCRIPTION

Заміщує збережений пароль названого запису. Задання пароля — адміністративна
дія: база відмовляє тому, хто не має повноваження адміністрування
користувачів.

Відкритий пароль ніколи не перетинає системний виклик. Інструмент питає
двічі з вимкненим відлунням термінала, перетворює набране на солений запис
PBKDF2 — сіль береться з джерела випадковості ядра — і надсилає запис;
обидва буфери відкритого тексту обнуляються щойно запис існує.

Ім'я запису обов'язкове. GNU-івський `passwd` без операнда змінює власний
пароль викликача, що в TAIRiX потребувало б непривілейованого
самообслуговування, якого немає: увесь інтерфейс адміністрування захищений
повноваженням, і виняток для «власного запису» був би зміною моделі безпеки,
а не зручністю.

Викликач без термінала — графічна програма, чий стандартний вхід закрито під
посередником підвищення — сам обчислює запис і передає готовий із
`--record`, тож відкритого тексту немає з жодного боку. Перед збереженням
запис перевіряють на правильність будови.

`--` завершує розбір параметрів: кожен наступний аргумент є операндом.

## OPTIONS

- `--record RECORD` — готовий солений запис PBKDF2, для викликача без
  термінала, де питати.
- `-h, -?, --help` — показати власну коротку довідку цієї команди.

## EXAMPLES

- `passwd ada` — спитати двічі й задати пароль запису.

## EXIT STATUS

- `0` — пароль замінено.
- `1` — база відмовила або не змогла замінити, два введення не збіглися,
  випадковості не було, або запис хибно побудовано; причину надруковано на
  стандартний потік помилок.
- `2` — командний рядок не зрозуміло.

## ENVIRONMENT

- `LANG` — бажана локаль для короткої довідки (позначка BCP-47, наприклад `uk-UA`).
