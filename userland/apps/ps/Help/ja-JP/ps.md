## NAME

ps — プロセスを一覧する

## SYNOPSIS

`ps [-e | -A | --all] [-h | -?]`

## DESCRIPTION

システム情報 API を通してプロセスを一覧します。既定では呼び出し元自身の
プロセスだけが一覧されます。サービスはすべての問い合わせ範囲をカーネルが
証明した呼び出し元の身元に照らして適用し、その検査を迂回する経路はありま
せん。

各プロセスは列見出しの下に一行で印字されます。プロセス id（`PID`）、親プ
ロセス id（`PPID`）、所有ユーザーとグループの id（`UID`、`GID`）、スケ
ジューリング状態（`S`）、プロセスが最後に走った CPU（`CPU`）、コマンド名
（`NAME`）です。

`ps` はオペランドを取りません。

## OPTIONS

- `-e, -A, --all` — 呼び出し元自身のものだけでなく、システム上のすべての
  プロセスを一覧する。サービスはこの眺めを `CAP_SYSINFO_GLOBAL` を持つ呼
  び出し元にだけ許す。
- `-h, -?` — このコマンド自身の短いヘルプを表示する。

## EXAMPLES

- `ps` — 自分のプロセスを一覧する。
- `ps -e` — システム上のすべてのプロセスを一覧する。

## EXIT STATUS

- `0` — 一覧を書き出した。
- `1` — サービスが拒否または失敗した、または一覧を届けられなかった。
- `2` — コマンド行を解釈できなかった。

## ENVIRONMENT

- `LANG` — 短いヘルプの優先ロケール（`ja-JP` のような BCP-47 タグ）。
