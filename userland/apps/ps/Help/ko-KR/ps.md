## NAME

ps — 프로세스 나열하기

## SYNOPSIS

`ps [-e | -A | --all] [-h | -?]`

## DESCRIPTION

시스템 정보 API를 통해 프로세스를 나열합니다. 기본값으로는 호출자 자신의
프로세스만 나열됩니다. 서비스는 모든 질의 범위를 커널이 증명한 호출자
신원에 대조하여 적용하며, 그 검사를 우회하는 경로는 없습니다.

각 프로세스는 열 머리글 아래 한 줄로 인쇄됩니다. 프로세스 id(`PID`), 부모
프로세스 id(`PPID`), 소유 사용자와 그룹 id(`UID`, `GID`), 스케줄링
상태(`S`), 프로세스가 마지막으로 실행된 CPU(`CPU`), 명령 이름(`NAME`)
입니다.

`ps`는 피연산자를 받지 않습니다.

## OPTIONS

- `-e, -A, --all` — 호출자 자신의 것만이 아니라 시스템의 모든 프로세스를
  나열합니다. 서비스는 이 보기를 `CAP_SYSINFO_GLOBAL`을 지닌
  호출자에게만 허가합니다.
- `-h, -?` — 이 명령 자체의 짧은 도움말을 표시합니다.

## EXAMPLES

- `ps` — 자신의 프로세스를 나열합니다.
- `ps -e` — 시스템의 모든 프로세스를 나열합니다.

## EXIT STATUS

- `0` — 목록을 썼습니다.
- `1` — 서비스가 거부했거나 실패했거나 목록을 전달할 수 없었습니다.
- `2` — 명령줄을 이해하지 못했습니다.

## ENVIRONMENT

- `LANG` — 짧은 도움말의 선호 로캘(`ko-KR` 같은 BCP-47 태그).
