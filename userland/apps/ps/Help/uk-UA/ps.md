## NAME

ps — вивести список процесів

## SYNOPSIS

`ps [-e | -A | --all] [-h | -?]`

## DESCRIPTION

Виводить список процесів через API системної інформації. Типово
виводяться лише процеси того, хто викликає команду; служба застосовує
кожну область запиту за посвідченою ядром ідентичністю викликача, і
жоден шлях не оминає цю перевірку.

Кожен процес друкується одним рядком під заголовком стовпців:
ідентифікатор процесу (`PID`), ідентифікатор батьківського процесу
(`PPID`), ідентифікатори користувача та групи власника (`UID`, `GID`),
стан планування (`S`), процесор, на якому процес виконувався востаннє
(`CPU`), та назва команди (`NAME`).

`ps` не приймає операндів.

## OPTIONS

- `-e, -A, --all` — вивести всі процеси системи, а не лише процеси
  викликача; служба надає цей перегляд лише викликачу, що має
  `CAP_SYSINFO_GLOBAL`.
- `-h, -?` — показати коротку довідку цієї команди.

## EXAMPLES

- `ps` — вивести власні процеси.
- `ps -e` — вивести всі процеси системи.

## EXIT STATUS

- `0` — список записано.
- `1` — служба відмовила чи зазнала збою, або список не вдалося
  видати.
- `2` — командний рядок не було зрозуміло.

## ENVIRONMENT

- `LANG` — бажана локаль для короткої довідки (тег BCP-47, як-от
  `uk-UA`).
