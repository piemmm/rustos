## NAME

fstree — 全画面ツリー型ファイルマネージャ

## SYNOPSIS

`fstree [ディレクトリ]`

## DESCRIPTION

キーボード操作の全画面セッションでファイルシステムを閲覧します。左側
にディレクトリツリーのペイン、右側に選択中ディレクトリの項目をサイズ
と更新時刻とともに一覧するファイルペインが並びます。セッションは
`ディレクトリ`（省略時はルートビュー `/`）から始まります。

ツリーは遅延読み込みです。ディレクトリの内容は初めて表示または展開さ
れたときにのみ取得されるため、巨大なボリュームの閲覧も実際に開いた
ディレクトリの分しかコストがかかりません。呼び出し側に一覧の権限がな
いディレクトリはその場で拒否され、エラーがメッセージ行に表示されて直
前の表示が保たれます。何も捏造されません。

キー:

- `上`/`下` または `k`/`j` — アクティブなペインのカーソルを移動しま
  す。ツリーカーソルの移動で、新しく選択されたディレクトリがファイル
  ペインに一覧されます。
- `左`/`右` または `h`/`l` — カーソル位置のツリー行を折りたたみ/展開
  します。
- `Enter` — ツリーでは展開を切り替え、ファイルペインでは選択中のディ
  レクトリへ降ります（両ペインが追従します）。
- `Tab` — アクティブなペインを切り替えます。
- `s` — 並べ替えメニューを開きます: `n` 名前、`e` 拡張子、`s` サイズ、
  `m` 更新時刻、`r` 方向反転、`Esc` で取り消し。ディレクトリは常に
  ファイルより前にまとめられます。
- `.` — 両ペインで隠し項目（ドット名）の表示を切り替えます。
- `?` — このヘルプをペインの上に表示します。任意のキーで閉じます。
- `q` — 終了し、端末を復元します。

ステータス行には、一覧中のパス、可視項目数、並べ替え順、基盤ボリュー
ムの空き/総バイト数（システム情報サービスが報告できる場合）、隠し項
目の表示状態が示されます。保存形式が更新時刻を持たないファイルは時刻
列に `-` を表示します。

ファイル操作（コピー、移動、名前変更、削除）、タグ付け、検索、テキス
ト/16 進/逆アセンブルビューアは、このツールの計画の後続段階で届きま
す。

## OPTIONS

- `directory` — セッションの開始ディレクトリ。既定はルートビュー
  `/` です。
- `-h`、`-?` — この文書の短縮形を出力して終了します。

## EXIT STATUS

- `0` — 利用者の `q` でセッションが終了した。
- `1` — 開始ディレクトリを一覧できなかった、または端末経路が失敗した。
- `2` — 引数を解釈できなかった。
