## NAME

fstree — 전체 화면 트리형 파일 관리자

## SYNOPSIS

`fstree [디렉터리]`

## DESCRIPTION

XTree Gold을 본뜬, 키보드로 조작하는 전체 화면 세션에서 파일 시스템을
탐색합니다. 위쪽에 디스크 통계 헤더가, 그 아래에 디렉터리 트리 창이,
다시 그 아래에 선택된 디렉터리의 항목을 크기와 수정 시각과 함께 나열
하는 파일 창이 세로로 놓입니다. 세션은 `디렉터리`(생략 시 루트 뷰
`/`)에서 시작합니다.

트리 창이 주가 됩니다. 커서는 트리 창 안에서 움직이고, 파일 창은 항상
선택된 디렉터리를 보여 줍니다. `Enter`(또는 `Tab`)로 파일 창에 들어가
파일을 다루고, `Esc`(또는 `Tab`)로 트리로 돌아옵니다 — 탐색은 언제나
트리에서 시작합니다.

트리는 지연 방식으로 읽힙니다. 디렉터리의 내용은 처음 표시되거나 펼쳐
질 때에만 가져오므로, 거대한 볼륨을 탐색해도 실제로 연 디렉터리만큼만
비용이 듭니다. 호출자가 나열할 수 없는 디렉터리는 그 자리에서 거부되
어 오류가 메시지 줄에 표시되고 이전 화면이 유지됩니다. 아무것도 지어
내지 않습니다.

키:

- `위`/`아래` 또는 `k`/`j` — 활성 창의 커서를 이동합니다
  (`PageUp`/`PageDown`으로 한 화면씩, `Home`/`End`로 처음/끝으로).
  트리 커서를 이동하면 새로 선택된 디렉터리가 파일 창에 나열됩니다.
- `오른쪽`/`l`/`+` — 트리에서는 선택된 가지를 펼치고(지연 방식으로 읽음),
  파일 창에서는 선택된 디렉터리로 내려갑니다.
- `왼쪽`/`h`/`-` — 트리에서는 선택된 가지를 접거나, 이미 닫혔거나 하위
  디렉터리가 없으면 상위 디렉터리로 올라갑니다. 파일 창에서는 트리로
  돌아갑니다.
- `Enter` — 트리에서는 파일 창으로 들어갑니다. 파일 창에서는 선택된
  항목을 엽니다(디렉터리면 들어가고 파일이면 표시합니다).
- `Esc` — 진행 중인 사용량 집계를 취소합니다. 그 밖에는 파일 창에서
  트리로 돌아갑니다.
- `Tab` — 트리 창과 파일 창을 전환합니다.
- `s` — 정렬 메뉴 열기: `n` 이름, `e` 확장자, `s` 크기, `m` 수정 시각,
  `r` 방향 반전, `Esc` 취소. 디렉터리는 항상 파일보다 앞에 묶입니다.
- `c` — 선택한 항목을 복사합니다. 프롬프트가 대상을 묻습니다. 상대 경
  로 대상은 나열 중인 디렉터리에 놓이며, 기존 디렉터리를 지정하면
  그 안에 원본 이름으로 놓입니다. 디렉터리는 아래 전체와 함께 복사
  됩니다. 자기 자신 위로 복사하거나 디렉터리를 자신의 하위 트리 안
  으로 복사하는 것은 아무것도 쓰이기 전에 거부됩니다.
- `m` — 선택한 항목을 이동합니다. 대상을 묻는 방식은 복사와 같습니다.
  같은 볼륨 안에서는 원자적 이름 바꾸기이고, 볼륨을 넘으면 복사 후
  원본을 제거합니다.
- `r` — 선택한 항목의 이름을 제자리에서 바꿉니다. 프롬프트에는 현재
  이름이 미리 채워집니다.
- `d` — 확인 후 선택한 항목을 삭제합니다. `y`만 진행합니다. 디렉터리
  삭제는 아래 전체를 제거하며, 확인 문구가 그 사실을 알려 줍니다.
- `M` — 나열 중인 디렉터리에 새 디렉터리를 만듭니다. 이름을 묻습니다.
- `a` — 선택한 항목의 허가 비트를 편집합니다. 현재 모드가 미리 채워진
  8진수 프롬프트가 열리며, Enter로 적용하고(소유자만 변경할 수 있으며
  커널은 그 외 모두를 거부합니다) Esc로 취소합니다.
- `t` — 파일 패널의 선택 항목에 태그를 붙이거나 떼고 커서를 한 줄
  내립니다. 반복해 누르면 연속된 항목에 태그를 붙입니다. 태그된
  항목에는 `*`가 붙습니다.
- `T` — 패턴으로 태그합니다. 글로브(`*`, `?`, `[...]`)를 보이는 이름
  과 대조하여 일치하는 항목을 태그 집합에 더합니다.
- `i` — 보이는 항목의 태그를 반전합니다.
- `C` — 모든 태그를 지웁니다.
- `u` — 초점이 놓인 디렉터리 아래의 디스크 사용량을 셉니다. 파일,
  바이트, 디렉터리 수를 백그라운드에서 점진적으로 훑습니다. `Esc`로
  취소하며, 그때까지 센 수치는 유지됩니다.
- `v` — 초점이 놓인 디렉터리 아래 가지를 평탄화합니다. 그 아래 모든
  파일을 하나의 목록으로 만들어 페이지 단위로 채웁니다(`스페이스`가
  다음 페이지를 불러옵니다). 뷰 안에서는 `t`/`T`/`i`/`C`가 행에
  태그를 붙이고, `c`/`m`/`d`가 태그 집합에 대한 일괄 작업을 실행하며,
  `Esc`로 패널로 돌아갑니다. 행 이름은 평탄화된 가지 기준의 상대
  이름입니다.
- `.` — 두 패널에서 숨김 항목(점으로 시작하는 이름) 표시를 전환합니다.
- `?` — 패널 위에 이 도움말을 표시합니다. 아무 키나 누르면 닫힙니다.
- `q` — 종료하고 터미널을 복원합니다.

태그된 항목이 있는 동안 `c`, `m`, `d`는 선택 항목이 아니라 태그 집합
전체에 작용합니다. `c`/`m`은 항목이 놓일 기존 대상 디렉터리를 묻고,
`d`는 일괄 삭제를 확인합니다. 항목은 태그된 순서로 처리되며, 하나의
실패가 나머지를 멈추지 않습니다. 완료 보고는 성공 수를 세고, 보고
화면이 실패를 하나하나 이름으로 밝힙니다 — 일괄 작업이 조용히 부분적으
로 끝나는 일은 없습니다. 성공한 항목의 태그는 해제되고, 실패는 재시도를
위해 태그된 채 남습니다.

복사나 이동이 기존 파일을 덮어쓰려 하면 세션이 파일마다 묻습니다.
`o`는 덮어쓰고, `s`는 건너뛰며(건너뛴 원본은 제자리에 남습니다),
`c`는 남은 단계를 취소합니다 — 일괄 작업에서는 취소가 남은 항목 전부를
버립니다 — 이미 적용된 부분은 그대로 남고, 완료
보고가 결과를 알려 줍니다. 복사 도중의 실패는 쓰다 만 대상을 제거하
고 커널의 오류를 표시합니다. 불완전한 복사가 완전한 것처럼 보이는 일
은 없습니다. 모든 작업은 커널이 승인하며, 거부는 그대로 메시지 줄에
표시되고 아무것도 바뀌지 않습니다.

상태 줄에는 나열 중인 경로, 보이는 항목 수, 정렬 순서, 기반 볼륨의 여
유/전체 바이트(시스템 정보 서비스가 보고할 수 있을 때), 숨김 항목 표시
여부가 나타나며, 태그가 있는 동안에는 태그된 항목 수와 바이트 합계도
보입니다. 저장 형식이 수정 시각을 담지 않는 파일은 시각 열에
`-`를 표시합니다.

검색과 텍스트/16진/역어셈블 뷰어는 이 도구 계획의 이후 단계에서
제공됩니다.

## OPTIONS

- `directory` — 세션이 시작하는 디렉터리. 기본값은 루트 뷰 `/`입니다.
- `-h`, `-?` — 이 문서의 요약을 출력하고 종료합니다.

## EXIT STATUS

- `0` — 사용자의 `q`로 세션이 끝났습니다.
- `1` — 시작 디렉터리를 나열할 수 없었거나 터미널 경로가 실패했습니다.
- `2` — 인자를 이해할 수 없었습니다.
