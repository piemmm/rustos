## NAME

mdadm — RAID アレイを検査・管理する

## SYNOPSIS

`mdadm --create --level=<level> --raid-devices=<count> [--chunk=<blocks>] <device>...`

`mdadm --detail [<array>]`

`mdadm --examine`

`mdadm --add <array> <device>`

`mdadm --remove <array> <device>`

`mdadm --stop <array>`

## DESCRIPTION

アレイコンポーザーがメンバーデバイスから組み立てるソフトウェア RAID
アレイを検査し、管理します。アレイとデバイスの目録はシステム情報 API
を通じて読み取られます——ハードウェアツリーを読むのと同じインター
フェース、同じ `CAP_SYSINFO_HW` の水準です。作成・追加・削除・停止と
いう変更はコンポーザーの制御エンドポイントに送られ、そこが動作する前
に呼び出し元が `CAP_STORAGE_ADMIN` を持つことを確認します。拒否された
場合は標準エラーに報告し、ゼロ以外の終了コードで終わります。何も捏造
せず、いかなる権限も仮定しません。

1 回の呼び出しでモードはちょうど 1 つ指定します。

TAIRiX に `/dev` はないため、Linux の mdadm がデバイスファイルとして
書く 2 つの名前は、ここでは別の書き方になります——意図的で文書化され
た相違です。

- デバイスはハードウェアツリーのノード ID で命名し、`node:<id>` と書
  きます。各レポートが表示する名前と同じです。それ以外の書き方は推測
  せず拒否します。
- アレイは 128 ビットの識別子を 16 進数で表して命名します。32 桁の完
  全な識別子を受け付け、ちょうど 1 つのアレイを指すプレフィックスも受
  け付けます。複数のアレイに一致するプレフィックスは、どれを意図した
  か推測せず拒否します。

TAIRiX は RAID レベル 0、1、5、6、10 と三重パリティを構成します。
RAID4 はないため、`--level=4` はその理由で拒否されます。

簡潔な補助情報——劣化したアレイ、またはアレイ表示に現れない空きデバイ
ス——は標準情報ストリーム（fd 3）に書き出されます。これは任意であり、
主たる出力を変えることはありません。

## OPTIONS

- `-C, --create` — 指定したデバイス上にアレイを作成し、コンポーザーが
  与える識別子を表示します。
- `-D, --detail` — 各アレイの識別子、レベル、健全性、デバイス数、ジオ
  メトリ、および進行中の再構築や検証の位置を報告します。アレイのオペ
  ランドを省くと、すべてのアレイを報告します。
- `-E, --examine` — コンポーザーが保持するすべてのデバイスを一覧しま
  す。スロットと状態を伴うアレイのメンバーと、新しいアレイを作成でき
  る未所属の空きデバイスです。
- `-a, --add` — 空きデバイスをアレイの欠けたスロットに受け入れ、再構築
  します。
- `-r, --remove` — メンバーデバイスをアレイから外します。
- `-S, --stop` — 稼働中のアレイを停止し、そのメンバーを解放します。
- `-l, --level=<level>` — 作成するレベル：`0`/`raid0`/`stripe`、
  `1`/`raid1`/`mirror`、`5`/`raid5`、`6`/`raid6`、`10`/`raid10`、また
  は三重パリティの `tp`/`raid-tp`。
- `-n, --raid-devices=<count>` — 作成するメンバースロットの数。デバイ
  スのオペランド数と等しくなければなりません。
- `-c, --chunk=<blocks>` — 論理ブロック単位のストライプ単位。ストライ
  プ化されたレベルにのみ有効です。
- `-h, -?, --help` — このコマンド自身のヘルプを表示します。
- `-V, --version` — バージョンを表示して終了します。

## EXAMPLES

- `mdadm --create --level=raid5 --raid-devices=3 node:11 node:12 node:13` — 3 台のデバイスで RAID5 アレイを作成。
- `mdadm --detail` — すべてのアレイを報告。
- `mdadm --examine` — メンバーも空きも含め、すべてのデバイスを一覧。
- `mdadm --add 3f2a node:14` — 識別子が `3f2a` で始まるアレイにデバイスを追加。
- `mdadm --stop 3f2a` — そのアレイを停止。

## EXIT STATUS

- `0` — 要求が成功した（またはヘルプを書き出した）。
- `1` — ケイパビリティが拒否された、名前を解決できなかった、コンポー
  ザーが要求を拒否した、または出力を書き出せなかった。
- `2` — コマンド行を解釈できなかった。
