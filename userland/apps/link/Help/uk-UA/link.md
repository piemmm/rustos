## NAME

link — дати файлові друге ім'я

## SYNOPSIS

`link [--] наявне нове`

## DESCRIPTION

Створює жорстке посилання: `нове` стає другим іменем вузла, який `наявне`
вже називає. Обидва імені після цього досягають того самого файлу —
запис через одне видно через інше, бо це один файл, а не копія — і
сховище файлу переживає видалення всіх імен, крім останнього.

Параметрів свідомо немає. `ln` — це інструмент із `-f`, `-i`, `-v`, `-s`,
`-L`/`-P` та формами призначення `-t`/`-T`; тримати їх окремо означає, що
сценарій, який має створити одне жорстке посилання й більше нічого,
отримує інструмент, не здатний замінити ім'я, розгорнути посилання або
створити символьне натомість.

Жодне з імен не розгортається. `наявне` — це вузол **як написано**, тож
підкладене там символьне посилання не може переспрямувати нове ім'я на
свою ціль (`ln -L` — інструмент для розгортальної позиції). `нове` — це
ім'я, що створюється: зайняте відхиляється, а не замінюється.

Кожна відмова говорить про різне:

- нове ім'я вже існує — створення ніколи не замінює ім'я;
- `наявне` — це **каталог**: каталог усюди має точно одне ім'я, тож ніхто
  не може дати йому друге;
- обидва імені на **різних томах**: друге ім'я вузла має бути на томі,
  який його зберігає;
- лічильник імен формату для вузла переповнився б;
- файлова система зберігає **одне ім'я на вузол** — стала властивість
  того формату, а не тимчасовий збій. Там використовуйте `ln -s` для
  символьного посилання.

Потрібні точно два операнди; будь-що інше — помилка використання, і
посилання не створюється. `--` завершує розбір параметрів.

## OPTIONS

- `-?, --help` — показати власну коротку довідку цієї команди.

## EXAMPLES

- `link звіт.txt звіт-копія.txt` — друге ім'я для файлу.
- `link -- -дивне-ім'я друге` — зв'язати ім'я, що починається з дефіса.

## EXIT STATUS

- `0` — посилання створено (або записано коротку довідку).
- `1` — файлова система відмовила у створенні посилання або вивід не
  вдався; причина друкується в стандартний потік помилок.
- `2` — командний рядок не зрозуміло.

## ENVIRONMENT

- `LANG` — бажана локаль для короткої довідки (позначка BCP-47, як-от
  `fr-FR`).
