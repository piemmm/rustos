## NAME

mv — 파일과 디렉터리 옮기기(이름 바꾸기)

## SYNOPSIS

`mv [-finvT] [-t dir] [--] source... dest`

## DESCRIPTION

각 원본 피연산자를 목적지로 옮깁니다. 원본이 하나이고 목적지가 디렉터리를
가리키지 않으면 원본은 그 정확한 경로로 이름이 바뀝니다. 목적지가 기존
디렉터리를 가리킬 때 — 그리고 원본이 둘 이상일 때는 언제나 — 각 원본은
자신의 기본 이름으로 그 디렉터리 *안으로* 옮겨집니다.

한 볼륨 안에서의 이동은 노드의 정체성을 보존하는 원자적 이름 바꾸기입니다.
원본과 목적지가 서로 다른 볼륨에 있는 이동은 원자적일 수 없습니다. 그때는
원본을 목적지로 복사한 뒤 원본을 제거하는 방식으로 대체됩니다(디렉터리는
재귀적으로 재현됩니다).

기존 목적지는 기본으로 덮어쓰이고, `-n`에서는 건너뛰며, `-i`에서는 표준
오류 스트림에서 물어봅니다(거절된 질문은 그 이동을 오류 없이 건너뜁니다.
읽을 수 없는 대답은 결코 동의로 취급되지 않습니다). 첫 실패가 이후의
피연산자로 가기 전에 실행을 멈춥니다. `--`는 옵션 해석을 끝내며, 이후의
모든 인수는 경로입니다.

## OPTIONS

- `-f, --force` — 가로막는 목적지를 제거하고 이름 바꾸기를 다시
  시도합니다. 결코 묻지 않습니다. `-f`, `-i`, `-n` 중 마지막 것이
  이깁니다.
- `-i, --interactive` — 기존 목적지를 덮어쓰기 전에 물어봅니다.
  `y`/`Y`로 시작하는 대답만 동의합니다.
- `-n, --no-clobber` — 기존 목적지를 결코 덮어쓰지 않습니다.
- `-v, --verbose` — 각 이동을 `renamed 'source' -> 'dest'`로
  보고합니다.
- `-t dir, --target-directory=dir` — 모든 원본을 `dir` 안으로
  옮깁니다. `dir`은 기존 디렉터리여야 합니다. 값은 붙여서(`-tdir`,
  `--target-directory=dir`) 또는 다음 인수로 줍니다.
- `-T, --no-target-directory` — 목적지를 일반 파일로 취급합니다. 원본은
  정확히 하나만 허용됩니다. `-t`와 함께 쓸 수 없습니다.
- `-h, -?, --help` — 이 명령 자체의 짧은 도움말을 표시합니다.

## EXAMPLES

- `mv draft.txt final.txt` — 파일 하나의 이름을 바꿉니다.
- `mv -v a.txt b.txt Archive` — 두 파일을 모두 `Archive`로 옮기며 각
  이동을 보고합니다.
- `mv -n new.cfg current.cfg` — 목적지가 아직 없을 때만 파일을
  설치합니다.

## EXIT STATUS

- `0` — 모든 이동이 성공했습니다(`-n`의 건너뜀과 거절된 `-i` 질문은
  실패가 아닙니다).
- `1` — 파일 시스템, 질문 또는 출력 실패. 이유가 표준 오류에
  인쇄됩니다.
- `2` — 명령줄을 이해하지 못했습니다.

## ENVIRONMENT

- `LANG` — 짧은 도움말의 선호 로캘(`ko-KR` 같은 BCP-47 태그).
