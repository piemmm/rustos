## NAME

mv — 移动（重命名）文件和目录

## SYNOPSIS

`mv [-finvT] [-t dir] [--] source... dest`

## DESCRIPTION

把每个来源操作数移动到目的地。只有一个来源、且目的地不指目录时，来源被重
命名为那个确切路径。当目的地指向已存在的目录 — 以及来源多于一个的任何时候
— 每个来源都以其自身的基本名被移动*进*该目录。

同一卷内的移动是保持节点身份的原子重命名。来源与目的地位于不同卷上的移动
无法原子完成：它退而先把来源复制到目的地、再删除来源（目录被递归重现）。

已存在的目的地默认被覆盖，带 `-n` 时被跳过，带 `-i` 时在标准错误流上询问
（被拒绝的询问无错误地跳过该次移动；无法读取的回答绝不被当作同意）。第一
个失败会在任何后续操作数之前停止运行。`--` 结束选项解析：之后的每个参数
都是路径。

## OPTIONS

- `-f, --force` — 删除阻挡的目的地并重试重命名；从不询问。`-f`、`-i` 和
  `-n` 以最后者为准。
- `-i, --interactive` — 覆盖已存在的目的地前询问；只有以 `y`/`Y` 开头的回
  答才算同意。
- `-n, --no-clobber` — 从不覆盖已存在的目的地。
- `-v, --verbose` — 以 `renamed 'source' -> 'dest'` 报告每次移动。
- `-t dir, --target-directory=dir` — 把每个来源移动进 `dir`，它必须是已存
  在的目录。值可紧跟（`-tdir`、`--target-directory=dir`）或作为下一个参
  数。
- `-T, --no-target-directory` — 把目的地当作普通文件；恰好允许一个来源。
  不能与 `-t` 组合。
- `-h, -?, --help` — 显示本命令自身的简短帮助。

## EXAMPLES

- `mv draft.txt final.txt` — 重命名一个文件。
- `mv -v a.txt b.txt Archive` — 把两个文件都移动进 `Archive`，并报告每次
  移动。
- `mv -n new.cfg current.cfg` — 仅当目的地尚不存在时安装文件。

## EXIT STATUS

- `0` — 每次移动都成功（`-n` 的跳过和被拒绝的 `-i` 询问不算失败）。
- `1` — 文件系统、询问或输出失败；原因打印在标准错误上。
- `2` — 无法理解命令行。

## ENVIRONMENT

- `LANG` — 简短帮助的首选区域设置（BCP-47 标签，例如 `zh-CN`）。
