## NAME

head — вивести початок файлів

## SYNOPSIS

`head [option...] [file...]`

## DESCRIPTION

Друкує перші 10 рядків кожного `file` до стандартного виводу. Якщо
`file` більше ніж один, перед кожною частиною друкується заголовок
`==> file <==`. Без `file`, або коли `file` дорівнює `-`, читається
стандартний ввід.

`-n` і `-c` змінюють обсяг виводу: просте число друкує перші `num`
рядків чи байтів; число з початковим `-` друкує все, **крім** останніх
`num` рядків чи байтів. Число може мати суфікс-множник: `b` (512),
`kB` (1000), `K` (1024), `MB`, `M`, `GB`, `G` і так далі для `T`, `P`,
`E`, `Z`, `Y`, `R`, `Q` (окрема літера множить на степені 1024; з `B`
— на степені 1000; з `iB` — на степені 1024).

Історична форма першого аргументу `head -num` (з необов'язковими
множниками `b`/`k`/`m` та літерами `l`/`q`/`v`/`z`) приймається, як в
інструменті GNU.

Про файл, який неможливо прочитати, повідомляється до стандартного
виводу помилок, і виконання продовжується з наступним файлом.

## OPTIONS

- `-c, --bytes <num>` — вивести перші `num` байтів кожного файлу; з
  початковим `-` — усе, крім останніх `num` байтів.
- `-n, --lines <num>` — вивести перші `num` рядків кожного файлу; з
  початковим `-` — усе, крім останніх `num` рядків.
- `-q, --quiet, --silent` — ніколи не друкувати заголовки
  `==> file <==`.
- `-v, --verbose` — завжди друкувати заголовки `==> file <==`.
- `-z, --zero-terminated` — рядки розділяються NUL замість символу
  нового рядка.
- `-h, -?` — показати коротку довідку цієї команди.

## EXAMPLES

- `head log.txt` — вивести перші 10 рядків `log.txt`.
- `head -n 3 a b` — вивести перші 3 рядки `a` та `b`, кожен під своїм
  заголовком.
- `head -c 1K image` — вивести перші 1024 байти `image`.
- `head -n -1 notes` — вивести `notes` без останнього рядка.

## EXIT STATUS

- `0` — кожен файл виведено (або записано коротку довідку).
- `1` — файл не вдалося прочитати, або вивід не вдалося доставити.
- `2` — командний рядок не зрозуміло.

## ENVIRONMENT

- `LANG` — бажана локаль для короткої довідки (тег BCP-47, наприклад
  `uk-UA`).
