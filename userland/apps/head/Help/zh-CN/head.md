## NAME

head — 输出文件的开头部分

## SYNOPSIS

`head [option...] [file...]`

## DESCRIPTION

把每个 `file` 的前 10 行打印到标准输出。有多个 `file` 时，每部分之前都有
一个 `==> file <==` 头。没有 `file` 或 `file` 为 `-` 时，读取标准输入。

`-n` 和 `-c` 改变打印多少：普通计数打印前 `num` 行或字节；以 `-` 开头的计
数打印**除**最后 `num` 行或字节之外的全部内容。计数可带乘数后缀：`b`
（512）、`kB`（1000）、`K`（1024）、`MB`、`M`、`GB`、`G`，以及依此类推的
`T`、`P`、`E`、`Z`、`Y`、`R`、`Q`（单独字母按 1024 的幂相乘；带 `B` 按
1000 的幂；带 `iB` 按 1024 的幂）。

历史性的第一参数形式 `head -num`（可带结尾的 `b`/`k`/`m` 乘数和
`l`/`q`/`v`/`z` 字母）与 GNU 工具一样被接受。

无法读取的文件在标准错误上报告，运行随即继续处理下一个文件。

## OPTIONS

- `-c, --bytes <num>` — 打印每个文件的前 `num` 个字节；以 `-` 开头时，为
  除最后 `num` 个字节之外的全部。
- `-n, --lines <num>` — 打印每个文件的前 `num` 行；以 `-` 开头时，为除最
  后 `num` 行之外的全部。
- `-q, --quiet, --silent` — 从不打印 `==> file <==` 头。
- `-v, --verbose` — 总是打印 `==> file <==` 头。
- `-z, --zero-terminated` — 行以 NUL 而非换行符分隔。
- `-h, -?` — 显示本命令自身的简短帮助。

## EXAMPLES

- `head log.txt` — 打印 `log.txt` 的前 10 行。
- `head -n 3 a b` — 打印 `a` 和 `b` 各自的前 3 行，各在其头之下。
- `head -c 1K image` — 打印 `image` 的前 1024 个字节。
- `head -n -1 notes` — 打印去掉最后一行的 `notes`。

## EXIT STATUS

- `0` — 每个文件都已打印（或简短帮助已写出）。
- `1` — 某个文件无法读取，或输出无法送达。
- `2` — 无法理解命令行。

## ENVIRONMENT

- `LANG` — 简短帮助的首选区域设置（BCP-47 标签，例如 `zh-CN`）。
