## NAME

head — ファイルの先頭部分を出力する

## SYNOPSIS

`head [option...] [file...]`

## DESCRIPTION

各 `file` の先頭 10 行を標準出力へ印字します。`file` が複数あれば、各部分
の前に `==> file <==` の見出しが付きます。`file` がない場合や `file` が
`-` の場合は標準入力を読みます。

`-n` と `-c` は印字する量を変えます。素の数なら先頭の `num` 行またはバイ
トを印字し、先頭に `-` を付けた数なら最後の `num` 行またはバイトを**除い
た**すべてを印字します。数には乗数の接尾辞を付けられます。`b`（512）、
`kB`（1000）、`K`（1024）、`MB`、`M`、`GB`、`G`、以下同様に `T`、`P`、
`E`、`Z`、`Y`、`R`、`Q`（単独の文字は 1024 の累乗、`B` 付きは 1000 の累
乗、`iB` 付きは 1024 の累乗で掛けます）。

歴史的な第一引数形式 `head -num`（末尾に `b`/`k`/`m` の乗数や
`l`/`q`/`v`/`z` の文字を付けられる）も、GNU ツールと同じく受け付けられま
す。

読めないファイルは標準エラーに報告され、実行は次のファイルへ続きます。

## OPTIONS

- `-c, --bytes <num>` — 各ファイルの先頭 `num` バイトを印字する。先頭が
  `-` なら、最後の `num` バイトを除くすべて。
- `-n, --lines <num>` — 各ファイルの先頭 `num` 行を印字する。先頭が `-`
  なら、最後の `num` 行を除くすべて。
- `-q, --quiet, --silent` — `==> file <==` の見出しを決して印字しない。
- `-v, --verbose` — `==> file <==` の見出しを常に印字する。
- `-z, --zero-terminated` — 行の区切りを改行ではなく NUL にする。
- `-h, -?` — このコマンド自身の短いヘルプを表示する。

## EXAMPLES

- `head log.txt` — `log.txt` の先頭 10 行を印字する。
- `head -n 3 a b` — `a` と `b` それぞれの先頭 3 行を、各見出しの下に印字
  する。
- `head -c 1K image` — `image` の先頭 1024 バイトを印字する。
- `head -n -1 notes` — 最後の行を除いた `notes` を印字する。

## EXIT STATUS

- `0` — すべてのファイルを印字した（または短いヘルプを書いた）。
- `1` — ファイルを読めなかった、または出力を届けられなかった。
- `2` — コマンド行を解釈できなかった。

## ENVIRONMENT

- `LANG` — 短いヘルプの優先ロケール（`ja-JP` のような BCP-47 タグ）。
