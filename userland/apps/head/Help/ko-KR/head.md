## NAME

head — 파일의 첫 부분 출력하기

## SYNOPSIS

`head [option...] [file...]`

## DESCRIPTION

각 `file`의 첫 10행을 표준 출력에 인쇄합니다. `file`이 여럿이면 각 부분
앞에 `==> file <==` 머리글이 붙습니다. `file`이 없거나 `file`이 `-`이면
표준 입력을 읽습니다.

`-n`과 `-c`는 얼마나 인쇄할지 바꿉니다. 그냥 쓴 수는 처음 `num` 행 또는
바이트를 인쇄하고, 앞에 `-`를 붙여 쓴 수는 마지막 `num` 행 또는 바이트를
**제외한** 전부를 인쇄합니다. 수에는 곱수 접미사를 붙일 수 있습니다.
`b`(512), `kB`(1000), `K`(1024), `MB`, `M`, `GB`, `G`, 그리고 `T`, `P`,
`E`, `Z`, `Y`, `R`, `Q`도 같은 식입니다(문자 하나만 쓰면 1024의 거듭제곱,
`B`가 붙으면 1000의 거듭제곱, `iB`가 붙으면 1024의 거듭제곱으로
곱합니다).

역사적인 첫 인수 형식 `head -num`(끝에 `b`/`k`/`m` 곱수와
`l`/`q`/`v`/`z` 문자를 붙일 수 있음)도 GNU 도구처럼 받아들여집니다.

읽을 수 없는 파일은 표준 오류에 보고되고 실행은 다음 파일로 계속됩니다.

## OPTIONS

- `-c, --bytes <num>` — 각 파일의 처음 `num` 바이트를 인쇄합니다. 앞에
  `-`가 붙으면 마지막 `num` 바이트를 제외한 전부입니다.
- `-n, --lines <num>` — 각 파일의 처음 `num` 행을 인쇄합니다. 앞에 `-`가
  붙으면 마지막 `num` 행을 제외한 전부입니다.
- `-q, --quiet, --silent` — `==> file <==` 머리글을 결코 인쇄하지
  않습니다.
- `-v, --verbose` — `==> file <==` 머리글을 항상 인쇄합니다.
- `-z, --zero-terminated` — 행이 줄 바꿈 대신 NUL로 구분됩니다.
- `-h, -?` — 이 명령 자체의 짧은 도움말을 표시합니다.

## EXAMPLES

- `head log.txt` — `log.txt`의 첫 10행을 인쇄합니다.
- `head -n 3 a b` — `a`와 `b` 각각의 첫 3행을 각 머리글 아래에
  인쇄합니다.
- `head -c 1K image` — `image`의 처음 1024바이트를 인쇄합니다.
- `head -n -1 notes` — 마지막 행을 뺀 `notes`를 인쇄합니다.

## EXIT STATUS

- `0` — 모든 파일을 인쇄했습니다(또는 짧은 도움말을 썼습니다).
- `1` — 파일을 읽을 수 없었거나 출력을 전달할 수 없었습니다.
- `2` — 명령줄을 이해하지 못했습니다.

## ENVIRONMENT

- `LANG` — 짧은 도움말의 선호 로캘(`ko-KR` 같은 BCP-47 태그).
