## NAME

lsusb — 발견된 USB 장치 목록 표시

## SYNOPSIS

`lsusb [-v] [-t] [-d [<vendor>]:[<product>]] [-s [[<bus>]:][<devnum>]]`

## DESCRIPTION

발견된 USB 인터페이스마다 한 줄씩, 인터페이스의 버스 번호와 장치
번호, `vendor:product` 식별자, 제조사 이름과 제품 이름을 표시합니다.
인벤토리는 하드웨어 트리(시스템의 유일한 장치 인벤토리)이며, 시스템
정보 API를 통해 읽습니다. 여기에는 `CAP_SYSINFO_HW` 능력이 필요하며,
거부되면 표준 오류로 이유가 보고되고 그 대신 아무것도 표시되지
않습니다.

이름은 이 명령이 자체 번들 안에 포함하는, 검증된 공개 USB ID
데이터베이스 스냅숏에서 가져옵니다. 데이터베이스에 이름이 없는 장치는
숫자 형식 `ID vvvv:pppp`만 표시되며 결코 지어내지 않습니다. 그런
장치의 수는 표준 정보 스트림(fd 3)에 기록됩니다. 포함된 테이블이
없거나 검증에 실패하면, 목록은 순수 식별자로 낮춰지고 그 이유가 표준
오류에 표시됩니다. 인벤토리 자체는 계속 표시됩니다.

RustOS에는 Linux의 버스/장치 번호 레지스트리가 없습니다. 장치의 버스
번호는 해당 컨트롤러의 하드웨어 트리 상 안정적인 노드 번호이고, 장치
번호는 자신의 노드 번호이며, `-s`는 그 노드 번호를 선택합니다(Linux
`lsusb`와의 의도적이고 문서화된 차이). 인벤토리는 *인터페이스*마다 한
노드를 기록하므로, 다중 인터페이스 장치는 인터페이스마다 한 번씩
표시됩니다.

## OPTIONS

- `-v` — 각 장치 다음에 인터페이스의 클래스, 서브클래스, 프로토콜
  (`bInterfaceClass`, `bInterfaceSubClass`, `bInterfaceProtocol`)을
  USB 클래스 테이블의 이름과 함께 표시합니다.
- `-t` — 장치를 컨트롤러와 버스 아래 트리로 표시합니다.
- `-d [<vendor>]:[<product>]` — 지정한 제조사/제품 식별자(16진수)와
  일치하는 장치만 표시합니다. 생략된 절반은 아무것에나 일치합니다.
- `-s [[<bus>]:][<devnum>]` — 지정한 컨트롤러(버스) 및/또는 장치 노드
  번호(10진수)와 일치하는 장치만 표시합니다. 콜론 없는 값은 장치
  번호 하나입니다.
- `-?, --help` — 이 명령의 짧은 도움말을 표시합니다.

## EXAMPLES

- `lsusb` — 발견된 모든 USB 장치를 이름과 함께 표시.
- `lsusb -v` — 위와 같으나 각 인터페이스의 클래스 정보 포함.
- `lsusb -s 2:` — 컨트롤러 노드 2 아래의 모든 장치.
- `lsusb -d 046d:` — 제조사 `046d`(Logitech)의 모든 장치.
- `lsusb -t` — 버스 토폴로지 아래의 장치.

## EXIT STATUS

- `0` — 목록(또는 짧은 도움말)이 기록되었습니다.
- `1` — 하드웨어 트리 조회가 거부되었거나 실패했거나, 출력을 기록할
  수 없었습니다.
- `2` — 명령줄을 이해할 수 없었습니다.

## ENVIRONMENT

- `LANG` — 짧은 도움말의 선호 로캘(`ko-KR` 같은 BCP-47 태그).
