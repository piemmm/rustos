## NAME

lsusb — 列出已发现的 USB 设备

## SYNOPSIS

`lsusb [-v] [-t] [-d [<vendor>]:[<product>]] [-s [[<bus>]:][<devnum>]]`

## DESCRIPTION

为每个已发现的 USB 设备打印一行，内容包括该设备的总线号和设备号、
`vendor:product` 标识符，以及厂商名和产品名。清单来自硬件树——系统
唯一的设备清单——通过系统信息 API 读取，需要 `CAP_SYSINFO_HW` 能力；
若被拒绝，原因将报告到标准错误，且不会伪造任何列表。

名称来自本命令自带软件包内的、经审查的公共 USB ID 数据库快照。数据
库未命名的标识只显示其数字形式 `ID vvvv:pppp`，绝不虚构；此类设备的
数量会记录在标准信息流（fd 3）上。若自带的表缺失或未通过校验，列表
将退化为纯标识符，并在标准错误上说明原因——清单本身仍会列出。

RustOS 没有 Linux 的总线/设备号注册表：总线号和设备号是对当前清单从 1
开始的小序号（总线按发现顺序，设备按每条总线上的列出顺序），在拓扑不
变时保持稳定，`-s` 选择的就是这些显示的号码（相对 Linux `lsusb` 的一
处有意且已记录的差异）。清单为每个*接口*记录一个条目：同一物理设备的
各接口按主机控制器报告的设备地址归组，因此多接口设备只列出一次。

## OPTIONS

- `-v` — 在每个设备之后列出其每个接口的类、子类和协议
  （`bInterfaceClass`、`bInterfaceSubClass`、`bInterfaceProtocol`），
  并附上 USB 类表中的名称。
- `-t` — 以树状显示各总线、其上的设备以及每个设备的接口类。
- `-d [<vendor>]:[<product>]` — 只列出与给定厂商/产品标识（十六进
  制）匹配的设备；省略的一半匹配任意值。
- `-s [[<bus>]:][<devnum>]` — 只列出与给定总线号和/或设备号（十进制，
  即列表中显示的号码）匹配的设备；不带冒号的值仅为设备号。
- `-?, --help` — 显示本命令自身的简短帮助。

## EXAMPLES

- `lsusb` — 每个已发现的 USB 设备，带名称。
- `lsusb -v` — 同上，并附每个接口的类标识。
- `lsusb -s 2:` — 总线 2 上的每个设备。
- `lsusb -d 046d:` — 厂商 `046d`（Logitech）的每个设备。
- `lsusb -t` — 按总线拓扑显示设备。

## EXIT STATUS

- `0` — 列表（或简短帮助）已写出。
- `1` — 硬件树查询被拒绝或失败，或输出无法写出。
- `2` — 无法理解命令行。

## ENVIRONMENT

- `LANG` — 简短帮助的首选区域设置（如 `zh-CN` 的 BCP-47 标签）。
