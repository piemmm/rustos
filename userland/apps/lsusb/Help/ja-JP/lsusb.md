## NAME

lsusb — 検出された USB デバイスを一覧表示する

## SYNOPSIS

`lsusb [-v] [-t] [-d [<vendor>]:[<product>]] [-s [[<bus>]:][<devnum>]]`

## DESCRIPTION

検出された USB デバイスごとに 1 行、そのデバイスの
バス番号とデバイス番号、`vendor:product` 識別子、ベンダー名と製品名を
表示します。インベントリはハードウェアツリー（システム唯一のデバイス
インベントリ）で、システム情報 API を通じて読み取られます。これには
`CAP_SYSINFO_HW` ケイパビリティが必要です。拒否された場合は標準エラー
出力に理由が報告され、代わりに何も表示されません。

名前は、このコマンドが自身のバンドル内に同梱する、検証済みの公開 USB
ID データベースのスナップショットに由来します。データベースに名前が
ないデバイスは数値形式 `ID vvvv:pppp` のみで表示され、決して捏造され
ません。そのようなデバイスの数は標準情報ストリーム（fd 3）に記録され
ます。同梱テーブルが欠落しているか検証に失敗した場合、一覧は生の識別
子に縮退し、その理由が標準エラー出力に示されます。インベントリ自体は
引き続き表示されます。

RustOS には Linux のバス/デバイス番号レジストリはありません。バス番号と
デバイス番号は、現在のインベントリに対する 1 から始まる小さな連番です
（バスは検出順、デバイスは各バス上の表示順）。トポロジーが変わらない
限り安定しており、`-s` はこれらの表示された番号を選択します（Linux の
`lsusb` からの意図的で文書化された相違です）。インベントリは*インター
フェイス*ごとに 1 エントリを記録しますが、同一の物理デバイスのインター
フェイスはホストコントローラーが報告したデバイスアドレスでグループ化さ
れるため、複数インターフェイスのデバイスは 1 回だけ表示されます。

## OPTIONS

- `-v` — 各デバイスの後に、その各インターフェイスのクラス・サブクラ
  ス・プロトコル（`bInterfaceClass`、`bInterfaceSubClass`、
  `bInterfaceProtocol`）を USB クラステーブルの名前とともに表示
  します。
- `-t` — 各バス、その上のデバイス、各デバイスのインターフェイスクラ
  スをツリーとして表示します。
- `-d [<vendor>]:[<product>]` — 指定されたベンダー/製品識別子
  （16 進数）に一致するデバイスのみ表示します。省略された半分は任意
  に一致します。
- `-s [[<bus>]:][<devnum>]` — 指定されたバス番号および/またはデバイス
  番号（10 進数、一覧に表示される番号）に一致するデバイスのみ表示
  します。コロンのない値はデバイス番号のみです。
- `-?, --help` — このコマンド自身の短いヘルプを表示します。

## EXAMPLES

- `lsusb` — 検出されたすべての USB デバイスを名前付きで表示。
- `lsusb -v` — 同上、各インターフェイスのクラス識別付き。
- `lsusb -s 2:` — バス 2 上のすべてのデバイス。
- `lsusb -d 046d:` — ベンダー `046d`（Logitech）のすべてのデバイス。
- `lsusb -t` — バストポロジーの下のデバイス。

## EXIT STATUS

- `0` — 一覧（または短いヘルプ）が書き出されました。
- `1` — ハードウェアツリーの照会が拒否または失敗したか、出力を書き
  込めませんでした。
- `2` — コマンドラインを解釈できませんでした。

## ENVIRONMENT

- `LANG` — 短いヘルプの優先ロケール（`ja-JP` のような BCP-47 タグ）。
