## NAME

widgets — Reactive Alloy ウィジェットギャラリー

## SYNOPSIS

`widgets`

## DESCRIPTION

TAIRiX の共有 GUI コントロールを、それぞれ専用のタブでひとつずつ紹介するデスク
トップウィンドウを開きます。ボタン、セレクター、値コントロール、テキストフィー
ルド、選択コントロール、コレクション、バー、フィードバック面、ウィンドウコント
ロールが対象です。各タブはその系統のいくつかのバリエーション（役割・状態・値の
違い）を示し、各コントロールの完全な挙動を一か所で見て操作できます。

タブの切り替えは、タブ列をクリックするか、`Left`・`Right`・`Home`・`End` キーと
`Enter` で行います。ウィジェットをクリックすると操作できます。トグルは切り替わ
り、スライダーは動き、テキストフィールドはキャレットを受け取り、コンボボックス
は開きます。クリックしたウィジェットはキーボードフォーカスを保持するため、矢印
キー・`Enter`・`Space`・入力文字がそれを操作します。`Tab` と `Shift+Tab` はタブ
列とウィジェットの間でフォーカスを移動します。

ギャラリーはデスクトップのスタートメニューから、またはシェルから名前で起動しま
す。実行中のグラフィカルセッションが必要です。なければウィンドウチャネルに到達
できず、ギャラリーは標準エラーストリームに拒否を報告して終了します。

## EXIT STATUS

正常に閉じた場合はゼロ。ウィンドウチャネルまたは共有フレーム領域が拒否された場
合は非ゼロ（理由は標準エラーストリームに示されます）。
