## NAME

widgets — Reactive Alloy 위젯 갤러리

## SYNOPSIS

`widgets`

## DESCRIPTION

TAIRiX의 모든 공유 GUI 컨트롤을 각각의 탭에서 보여 주는 데스크톱 창을 엽니다.
버튼, 선택기, 값 컨트롤, 텍스트 필드, 선택 컨트롤, 컬렉션, 바, 피드백 표면, 창
컨트롤이 대상입니다. 각 탭은 해당 계열의 여러 변형(서로 다른 역할, 상태, 값)을
보여 주어, 각 컨트롤의 전체 동작을 한곳에서 보고 조작할 수 있습니다.

탭 막대를 클릭하거나 `Left`, `Right`, `Home`, `End` 키와 `Enter`로 탭을
전환합니다. 위젯을 클릭하면 상호작용할 수 있습니다. 토글은 전환되고, 슬라이더는
움직이고, 텍스트 필드는 캐럿을 받고, 콤보 상자는 열립니다. 클릭한 위젯은 키보드
포커스를 유지하므로 화살표 키, `Enter`, `Space`, 입력한 문자가 그것을 조작합니다.
`Tab`과 `Shift+Tab`은 탭 막대와 위젯 사이에서 포커스를 이동합니다.

갤러리는 데스크톱의 프로그램 라이브러리(작업 표시줄의 `Library`
버튼)에서 또는 셸에서 이름으로 실행합니다. 실행 중인 그래픽 세션이
필요합니다. 없으면 창 채널에 접근할 수 없으며, 갤러리는 표준 오류
스트림에 거부를 보고하고 종료합니다.

## EXIT STATUS

정상 종료 후에는 0, 창 채널이나 공유 프레임 영역이 거부되면 0이 아닙니다(사유는
표준 오류 스트림에 표시됩니다).
