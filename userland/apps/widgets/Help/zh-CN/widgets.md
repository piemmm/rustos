## NAME

widgets — Reactive Alloy 控件陈列室

## SYNOPSIS

`widgets`

## DESCRIPTION

打开一个桌面窗口，在各自的标签页中演示 TAIRiX 的每个共享图形控件：按钮、选择
器、数值控件、文本框、选择控件、集合、条栏、反馈界面和窗口控件。每个标签页展示
其所属族的多种变体——不同的角色、状态和取值——以便在同一处即可看到并操作每个控
件的完整行为。

单击标签栏或使用 `Left`、`Right`、`Home` 和 `End` 键以及 `Enter` 切换标签页。单
击控件即可与之交互：开关会翻转，滑块会移动，文本框会获得光标，组合框会展开。被
单击的控件会保留键盘焦点，因此方向键、`Enter`、`Space` 和键入的字符便可操控它；
`Tab` 和 `Shift+Tab` 在标签栏与控件之间移动焦点。

陈列室可从桌面开始菜单启动，或在 shell 中按名称启动。它需要正在运行的图形会话：
若没有，窗口通道将无法访问，陈列室会在标准错误流上报告拒绝并退出。

## EXIT STATUS

正常关闭后为零；当窗口通道或共享帧区域被拒绝时为非零（原因会在标准错误流上说
明）。
