## NAME

rmdir — 空のディレクトリを削除する

## SYNOPSIS

`rmdir [-pv] [--ignore-fail-on-non-empty] [--] directory...`

## DESCRIPTION

各ディレクトリオペランドを順に削除します。削除されるのは**空のディレクト
リ**だけです。ファイル（およびディレクトリ以外のもの）や中身のあるディレ
クトリはファイルシステム自身が原子的に拒否するため、その場所で別の何かが
アンリンクされることは決してありません。ファイルには `rm` を、中身のある
ツリーには `rm -r` を使ってください。

`-p` があれば各オペランドの祖先も、内側から順に削除されます。
`rmdir -p a/b/c` は `a/b/c`、次に `a/b`、次に `a` を削除します。パスの裸
のルート（`/` や `Home:/` のようなエイリアスルート）の削除が求められるこ
とはありません。

`--ignore-fail-on-non-empty` があれば「ディレクトリが空でない」という拒否
はエラーになりません — そのオペランド（または `-p` の上向きの歩み）はそこ
で止まるだけです。それ以外の拒否は容認されません。最初の本物の失敗で、後
続のオペランドに移る前に実行が止まります。`--` はオプション解析を終え、以
降のすべての引数はパスです。

## OPTIONS

- `-p, --parents` — 各オペランドの祖先も、内側から順に削除する。
- `-v, --verbose` — 各削除の試みを `rmdir: removing directory, 'dir'`
  の形で報告する。
- `--ignore-fail-on-non-empty` — 空でないディレクトリはエラーではない。
  `-p` では上向きの歩みがそこで止まる。
- `-h, -?` — このコマンド自身の短いヘルプを表示する（`--help` も可）。

## EXAMPLES

- `rmdir Scratch` — 空のディレクトリを一つ削除する。
- `rmdir -p Projects/os/build` — 内側から順に連鎖を削除する。
- `rmdir -p --ignore-fail-on-non-empty a/b` — `a/b` を削除し、それで空に
  なるなら `a` も削除する。

## EXIT STATUS

- `0` — すべての削除が成功した（`--ignore-fail-on-non-empty` が容認した
  拒否は失敗ではない）。
- `1` — ファイルシステムまたは出力の失敗。理由は標準エラーに印字される。
- `2` — コマンド行を解釈できなかった。

## ENVIRONMENT

- `LANG` — 短いヘルプの優先ロケール（`ja-JP` のような BCP-47 タグ）。
