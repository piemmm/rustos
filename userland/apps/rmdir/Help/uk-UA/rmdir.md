## NAME

rmdir — вилучення порожніх каталогів

## SYNOPSIS

`rmdir [-pv] [--ignore-fail-on-non-empty] [--] каталог...`

## DESCRIPTION

Вилучає кожен каталог-операнд по черзі. Вилучається лише **порожній
каталог**: файлова система сама атомарно відмовляє файлу (чи будь-чому
іншому) та непорожньому каталогу, тож ніщо інше ніколи не буде
вилучено замість нього. Для файлів використовуйте `rm`, для непорожніх
дерев — `rm -r`.

З `-p` вилучаються також предки кожного операнда, від найглибшого до
найзовнішнього: `rmdir -p a/b/c` вилучає `a/b/c`, потім `a/b`, потім
`a`. Голий корінь шляху (`/` або корінь псевдоніма на кшталт
`Home:/`) ніколи не зачіпається.

З `--ignore-fail-on-non-empty` відмова «каталог не порожній» не є
помилкою — операнд (або підйом `-p`) просто зупиняється там. Жодна
інша відмова не толерується. Перша справжня невдача зупиняє виконання
перед будь-яким наступним операндом. `--` завершує розбір параметрів:
кожен наступний аргумент — це шлях.

## OPTIONS

- `-p, --parents` — вилучати також предків кожного операнда, від
  найглибшого до найзовнішнього.
- `-v, --verbose` — повідомляти про кожну спробу вилучення як
  `rmdir: removing directory, 'кат'`.
- `--ignore-fail-on-non-empty` — непорожній каталог не є помилкою; з
  `-p` підйом зупиняється там.
- `-h, -?` — показати коротку довідку цієї команди (також `--help`).

## EXAMPLES

- `rmdir Scratch` — вилучити один порожній каталог.
- `rmdir -p Projects/os/build` — вилучити ланцюжок, від найглибшого до
  найзовнішнього.
- `rmdir -p --ignore-fail-on-non-empty a/b` — вилучити `a/b`, а також
  `a`, якщо після цього він стане порожнім.

## EXIT STATUS

- `0` — кожне вилучення вдалося (відмова, толерована
  `--ignore-fail-on-non-empty`, не є невдачею).
- `1` — помилка файлової системи чи виводу; причину надруковано в
  стандартний потік помилок.
- `2` — командний рядок не розпізнано.

## ENVIRONMENT

- `LANG` — бажана локаль для короткої довідки (тег BCP-47, наприклад
  `uk-UA`).
