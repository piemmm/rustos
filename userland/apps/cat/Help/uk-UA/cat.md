## NAME

cat — з'єднати файли у стандартний вивід

## SYNOPSIS

`cat [-AbeEnstTuv] [--] [file...]`

## DESCRIPTION

Читає кожен файловий операнд по черзі та записує його байти у
стандартний вивід. Операнд `-` позначає стандартний ввід, а без
операндів стандартний ввід є єдиним джерелом.

Операнд також може бути типізованим посиланням на ресурс, як-от
`sys:random`: воно відкривається через системний резолвер ресурсів (з
перевіркою повноважень), а не через файлову систему — `cat sys:random`
виводить випадкові байти. Некоректне посилання в зареєстрованому
просторі імен є помилкою і ніколи не стає ім'ям файлу.

З `-n` рядки виводу нумеруються неперервно через усі джерела, тож
рядок, що охоплює два джерела, нумерується рівно один раз — коли
з'являється його перший байт. `-b` нумерує лише непорожні рядки та
має пріоритет над `-n`. `-s` прибирає повторювані суміжні порожні
рядки; прибраний рядок не записується й не нумерується.

Опції позначення роблять невидимі байти видимими: `-E` друкує `$`
перед кожним переведенням рядка, `-T` друкує TAB як `^I`, а `-v`
друкує інші керівні байти як `^X`, а байти поза ASCII — у нотації
`M-`. `-e`, `-t` і `-A` — звичні комбінації `-vE`, `-vT` і `-vET`.

Джерело, яке неможливо прочитати, зупиняє команду до того, як буде
торкнуто будь-яке наступне джерело; вже записані байти залишаються
записаними.

## OPTIONS

- `-A, --show-all` — еквівалент `-vET`.
- `-b, --number-nonblank` — нумерувати непорожні рядки виводу; має
  пріоритет над `-n`.
- `-e` — еквівалент `-vE`.
- `-E, --show-ends` — друкувати `$` наприкінці кожного рядка.
- `-n, --number` — нумерувати рядки виводу неперервно через усі
  джерела.
- `-s, --squeeze-blank` — прибирати повторювані суміжні порожні
  рядки.
- `-t` — еквівалент `-vT`.
- `-T, --show-tabs` — друкувати символи TAB як `^I`.
- `-u` — приймається та ігнорується; вивід і так небуферизований.
- `-v, --show-nonprinting` — використовувати нотацію `^` та `M-` для
  керівних байтів і байтів поза ASCII, окрім переведення рядка та
  TAB.
- `-h, -?` — показати коротку довідку цієї команди.

## EXAMPLES

- `cat notes.txt` — записати `notes.txt` у стандартний вивід.
- `cat a.txt - b.txt` — записати `a.txt`, потім стандартний ввід,
  потім `b.txt`.
- `cat -n log.txt` — пронумерувати кожен рядок виводу.
- `cat -bs draft.txt` — пронумерувати непорожні рядки та стиснути
  серії порожніх рядків.
- `cat -A config.txt` — зробити видимими кінці рядків, табуляції та
  керівні байти.
- `cat -- -n` — записати файл із назвою `-n`.

## EXIT STATUS

- `0` — кожне джерело записано.
- `1` — джерело не вдалося прочитати, або вивід не вдалося доставити.
- `2` — командний рядок не зрозуміло.

## ENVIRONMENT

- `LANG` — бажана локаль для короткої довідки (тег BCP-47, наприклад
  `uk-UA`).
