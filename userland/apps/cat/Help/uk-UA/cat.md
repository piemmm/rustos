## NAME

cat — об'єднати файли у стандартний вивід

## SYNOPSIS

`cat [-n] [--] [file...]`

## DESCRIPTION

Читає кожен файловий операнд по черзі та записує його байти у
стандартний вивід. Операнд `-` позначає стандартний ввід, а без
операндів стандартний ввід є єдиним джерелом.

З `-n` рядки виводу нумеруються неперервно через усі джерела, тож
рядок, що розділений між двома джерелами, нумерується рівно один раз —
коли з'являється його перший байт.

Джерело, яке не вдається прочитати, зупиняє команду до того, як буде
торкнуте будь-яке наступне джерело; вже записані байти лишаються
записаними.

## OPTIONS

- `-n, --number` — нумерувати рядки виводу, неперервно через усі
  джерела.
- `-h, -?` — показати коротку довідку цієї команди.

## EXAMPLES

- `cat notes.txt` — записати `notes.txt` у стандартний вивід.
- `cat a.txt - b.txt` — записати `a.txt`, потім стандартний ввід,
  потім `b.txt`.
- `cat -n log.txt` — пронумерувати кожен рядок виводу.
- `cat -- -n` — записати файл з іменем `-n`.

## EXIT STATUS

- `0` — кожне джерело було записано.
- `1` — джерело не вдалося прочитати, або вивід не вдалося доставити.
- `2` — командний рядок не було зрозуміло.

## ENVIRONMENT

- `LANG` — бажана локаль для короткої довідки (тег BCP-47, наприклад
  `uk-UA`).
