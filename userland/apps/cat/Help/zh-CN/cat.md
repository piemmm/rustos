## NAME

cat — 把文件连接到标准输出

## SYNOPSIS

`cat [-AbeEnstTuv] [--] [file...]`

## DESCRIPTION

按顺序读取每个文件操作数，并把其字节写到标准输出。操作数 `-` 表示标准输
入；没有操作数时，标准输入是唯一的来源。

操作数也可以是类型化的资源引用，例如 `sys:random`：它通过系统的能力检查资源解析器打开，而不是通过文件系统 — `cat
sys:random` 会输出随机字节。已注册命名空间中格式错误的引用是错误，绝不会退回为文件名。

有 `-n` 时，输出行跨所有来源连续编号，因此横跨两个来源的一行只在其第一个
字节出现时编号一次。`-b` 只给非空行编号并覆盖 `-n`。`-s` 抑制相邻重复的空
行，被抑制的行既不写出也不编号。

标记选项让不可见的字节现形：`-E` 在每个换行符前打印 `$`，`-T` 把 TAB 打印
为 `^I`，`-v` 把其他控制字节打印为 `^X`、把非 ASCII 字节打印为 `M-` 记
法。`-e`、`-t` 和 `-A` 是惯用组合 `-vE`、`-vT` 和 `-vET`。

无法读取的来源会在触及任何后续来源之前停止命令；已写出的字节保持原样。

## OPTIONS

- `-A, --show-all` — 等价于 `-vET`。
- `-b, --number-nonblank` — 给非空输出行编号；覆盖 `-n`。
- `-e` — 等价于 `-vE`。
- `-E, --show-ends` — 在每行末尾打印 `$`。
- `-n, --number` — 给输出行编号，跨所有来源连续。
- `-s, --squeeze-blank` — 抑制相邻重复的空行。
- `-t` — 等价于 `-vT`。
- `-T, --show-tabs` — 把 TAB 字符打印为 `^I`。
- `-u` — 接受并忽略；输出本来就不缓冲。
- `-v, --show-nonprinting` — 对控制字节和非 ASCII 字节使用 `^` 和 `M-`
  记法，换行符和 TAB 除外。
- `-h, -?` — 显示本命令自身的简短帮助。

## EXAMPLES

- `cat notes.txt` — 把 `notes.txt` 写到标准输出。
- `cat a.txt - b.txt` — 先写 `a.txt`，再写标准输入，再写 `b.txt`。
- `cat -n log.txt` — 给每个输出行编号。
- `cat -bs draft.txt` — 给非空行编号并压缩空行串。
- `cat -A config.txt` — 让行尾、制表符和控制字节现形。
- `cat -- -n` — 写出名为 `-n` 的文件。

## EXIT STATUS

- `0` — 每个来源都已写出。
- `1` — 某个来源无法读取，或输出无法送达。
- `2` — 无法理解命令行。

## ENVIRONMENT

- `LANG` — 简短帮助的首选区域设置（BCP-47 标签，例如 `zh-CN`）。
