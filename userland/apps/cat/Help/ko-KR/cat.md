## NAME

cat — 파일들을 표준 출력으로 이어 붙이기

## SYNOPSIS

`cat [-AbeEnstTuv] [--] [file...]`

## DESCRIPTION

각 파일 피연산자를 순서대로 읽어 그 바이트를 표준 출력에 씁니다.
피연산자 `-`는 표준 입력을 가리키고, 피연산자가 없으면 표준 입력이 유일한
원천입니다.

피연산자는 `sys:random` 같은 형식화된 리소스 참조일 수도 있습니다. 파일 시스템이 아니라 기능 검사를 거치는 시스템
리소스 해석기를 통해 열리며, `cat sys:random` 은 무작위 바이트를 출력합니다. 등록된 네임스페이스의 잘못된 참조는
오류이며 파일 이름으로 대체되지 않습니다.

`-n`이 있으면 출력 행이 모든 원천에 걸쳐 연속으로 번호 매겨지므로, 두
원천에 걸친 행은 그 첫 바이트가 나타날 때 정확히 한 번 번호가 붙습니다.
`-b`는 비어 있지 않은 행에만 번호를 매기며 `-n`을 무시합니다. `-s`는
인접한 반복 빈 행을 억제하고, 억제된 행은 쓰이지도 번호 매겨지지도
않습니다.

표시 옵션들은 보이지 않는 바이트를 보이게 합니다. `-E`는 각 줄 바꿈 앞에
`$`를 인쇄하고, `-T`는 TAB을 `^I`로 인쇄하며, `-v`는 그 밖의 제어 바이트를
`^X`로, 비 ASCII 바이트를 `M-` 표기로 인쇄합니다. `-e`, `-t`, `-A`는 흔한
조합인 `-vE`, `-vT`, `-vET`입니다.

읽을 수 없는 원천은 이후의 어떤 원천도 건드리기 전에 명령을 멈춥니다.
이미 쓰인 바이트는 그대로 남습니다.

## OPTIONS

- `-A, --show-all` — `-vET`와 동등합니다.
- `-b, --number-nonblank` — 비어 있지 않은 출력 행에 번호를 매깁니다.
  `-n`을 무시합니다.
- `-e` — `-vE`와 동등합니다.
- `-E, --show-ends` — 각 행 끝에 `$`를 인쇄합니다.
- `-n, --number` — 모든 원천에 걸쳐 연속으로 출력 행에 번호를 매깁니다.
- `-s, --squeeze-blank` — 인접한 반복 빈 행을 억제합니다.
- `-t` — `-vT`와 동등합니다.
- `-T, --show-tabs` — TAB 문자를 `^I`로 인쇄합니다.
- `-u` — 받아들여지고 무시됩니다. 출력은 이미 버퍼링되지 않습니다.
- `-v, --show-nonprinting` — 제어 바이트와 비 ASCII 바이트에 `^`와 `M-`
  표기를 씁니다. 줄 바꿈과 TAB은 예외입니다.
- `-h, -?` — 이 명령 자체의 짧은 도움말을 표시합니다.

## EXAMPLES

- `cat notes.txt` — `notes.txt`를 표준 출력에 씁니다.
- `cat a.txt - b.txt` — `a.txt`, 그다음 표준 입력, 그다음 `b.txt`를
  씁니다.
- `cat -n log.txt` — 모든 출력 행에 번호를 매깁니다.
- `cat -bs draft.txt` — 비어 있지 않은 행에 번호를 매기고 빈 행 연속을
  압축합니다.
- `cat -A config.txt` — 행 끝, 탭, 제어 바이트를 보이게 합니다.
- `cat -- -n` — `-n`이라는 이름의 파일을 씁니다.

## EXIT STATUS

- `0` — 모든 원천을 썼습니다.
- `1` — 원천을 읽을 수 없었거나 출력을 전달할 수 없었습니다.
- `2` — 명령줄을 이해하지 못했습니다.

## ENVIRONMENT

- `LANG` — 짧은 도움말의 선호 로캘(`ko-KR` 같은 BCP-47 태그).
