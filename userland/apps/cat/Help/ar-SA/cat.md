## NAME

cat — وصل الملفات إلى الخرج القياسي

## SYNOPSIS

`cat [-AbeEnstTuv] [--] [file...]`

## DESCRIPTION

يقرأ كل معطى ملف بالترتيب ويكتب بايتاته إلى الخرج القياسي. المعطى `-`
يسمي الدخل القياسي، وبدون معطى يكون الدخل القياسي هو المصدر الوحيد.

مع `-n` تُرقَّم أسطر الخرج ترقيمًا متصلًا عبر كل المصادر، فالسطر الممتد
عبر مصدرين يُرقَّم مرة واحدة بالضبط، حين يظهر أول بايت منه. `-b` يرقّم
الأسطر غير الفارغة فقط ويتغلب على `-n`. `-s` يكبت الأسطر الفارغة
المتجاورة المكررة، والسطر المكبوت لا يُكتب ولا يُرقَّم.

خيارات الوسم تُظهر البايتات الخفية: `-E` يطبع `$` قبل كل سطر جديد،
و`-T` يطبع TAB على هيئة `^I`، و`-v` يطبع بايتات التحكم الأخرى على هيئة
`^X` والبايتات غير ASCII بترميز `M-`. أما `-e` و`-t` و`-A` فهي
التركيبات المعتادة `-vE` و`-vT` و`-vET`.

المصدر الذي يتعذر قراءته يوقف الأمر قبل لمس أي مصدر لاحق؛ وتبقى
البايتات المكتوبة سلفًا مكتوبة.

## OPTIONS

- `-A, --show-all` — مكافئ لـ `-vET`.
- `-b, --number-nonblank` — ترقيم أسطر الخرج غير الفارغة؛ يتغلب على
  `-n`.
- `-e` — مكافئ لـ `-vE`.
- `-E, --show-ends` — طباعة `$` في نهاية كل سطر.
- `-n, --number` — ترقيم أسطر الخرج ترقيمًا متصلًا عبر كل المصادر.
- `-s, --squeeze-blank` — كبت الأسطر الفارغة المتجاورة المكررة.
- `-t` — مكافئ لـ `-vT`.
- `-T, --show-tabs` — طباعة أحرف TAB على هيئة `^I`.
- `-u` — يُقبل ويُتجاهل؛ الخرج غير مخزَّن مؤقتًا أصلًا.
- `-v, --show-nonprinting` — استعمال ترميزي `^` و`M-` لبايتات التحكم
  والبايتات غير ASCII، عدا سطر التغذية وTAB.
- `-h, -?` — عرض المساعدة القصيرة لهذا الأمر نفسه.

## EXAMPLES

- `cat notes.txt` — كتابة `notes.txt` إلى الخرج القياسي.
- `cat a.txt - b.txt` — كتابة `a.txt` ثم الدخل القياسي ثم `b.txt`.
- `cat -n log.txt` — ترقيم كل سطر خرج.
- `cat -bs draft.txt` — ترقيم الأسطر غير الفارغة وضغط سلاسل الفراغ.
- `cat -A config.txt` — إظهار نهايات الأسطر وعلامات الجدولة وبايتات
  التحكم.
- `cat -- -n` — كتابة الملف المسمى `-n`.

## EXIT STATUS

- `0` — كُتب كل مصدر.
- `1` — تعذّرت قراءة مصدر، أو تعذّر إيصال الخرج.
- `2` — لم يُفهم سطر الأوامر.

## ENVIRONMENT

- `LANG` — المنطقة المفضلة للمساعدة القصيرة (وسم BCP-47 مثل `ar-SA`).
