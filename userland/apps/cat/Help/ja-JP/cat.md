## NAME

cat — ファイルを連結して標準出力へ書く

## SYNOPSIS

`cat [-AbeEnstTuv] [--] [file...]`

## DESCRIPTION

各ファイルオペランドを順に読み、そのバイトを標準出力へ書き出します。オペ
ランド `-` は標準入力を指し、オペランドがなければ標準入力が唯一の入力源で
す。

オペランドは `sys:random`
のような型付きリソース参照でもかまいません。ファイルシステムではなく、権限検査付きのリソースリゾルバで開かれます — `cat
sys:random` は乱数バイトを出力します。登録済み名前空間内の不正な参照はエラーであり、ファイル名として扱われることはありません。

`-n` があれば、出力行はすべての入力源を通して連続的に番号付けされます。二
つの入力源にまたがる行は、その最初のバイトが現れたときにちょうど一度だけ
番号が付きます。`-b` は空でない行だけに番号を付け、`-n` に優先します。
`-s` は連続する空行の繰り返しを抑え、抑えられた行は書かれも番号付けもされ
ません。

マーカーオプションは見えないバイトを見えるようにします。`-E` は各改行の前
に `$` を印字し、`-T` は TAB を `^I` として印字し、`-v` は他の制御バイトを
`^X` として、非 ASCII バイトを `M-` 記法で印字します。`-e`、`-t`、`-A` は
いつもの組み合わせ `-vE`、`-vT`、`-vET` です。

読めない入力源があると、後続の入力源に触れる前にコマンドが止まります。す
でに書かれたバイトはそのまま残ります。

## OPTIONS

- `-A, --show-all` — `-vET` と同等。
- `-b, --number-nonblank` — 空でない出力行に番号を付ける。`-n` に優先す
  る。
- `-e` — `-vE` と同等。
- `-E, --show-ends` — 各行の末尾に `$` を印字する。
- `-n, --number` — 出力行に、すべての入力源を通して連続的に番号を付ける。
- `-s, --squeeze-blank` — 連続する空行の繰り返しを抑える。
- `-t` — `-vT` と同等。
- `-T, --show-tabs` — TAB 文字を `^I` として印字する。
- `-u` — 受け付けて無視する。出力はもともとバッファリングされていない。
- `-v, --show-nonprinting` — 制御バイトと非 ASCII バイトに `^` と `M-` の
  記法を使う。改行と TAB は除く。
- `-h, -?` — このコマンド自身の短いヘルプを表示する。

## EXAMPLES

- `cat notes.txt` — `notes.txt` を標準出力へ書く。
- `cat a.txt - b.txt` — `a.txt`、次に標準入力、次に `b.txt` を書く。
- `cat -n log.txt` — すべての出力行に番号を付ける。
- `cat -bs draft.txt` — 空でない行に番号を付け、空行の連なりを圧縮する。
- `cat -A config.txt` — 行末・タブ・制御バイトを見えるようにする。
- `cat -- -n` — `-n` という名前のファイルを書く。

## EXIT STATUS

- `0` — すべての入力源を書き出した。
- `1` — 入力源を読めなかった、または出力を届けられなかった。
- `2` — コマンド行を解釈できなかった。

## ENVIRONMENT

- `LANG` — 短いヘルプの優先ロケール（`ja-JP` のような BCP-47 タグ）。
