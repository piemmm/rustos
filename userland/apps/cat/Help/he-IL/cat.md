## NAME

cat — שרשור קבצים לפלט התקני

## SYNOPSIS

`cat [-AbeEnstTuv] [--] [file...]`

## DESCRIPTION

קורא כל פרמטר קובץ לפי הסדר וכותב את הבייטים שלו לפלט התקני. הפרמטר `-`
מציין את הקלט התקני, ובלי פרמטר הקלט התקני הוא המקור היחיד.

עם `-n` שורות הפלט ממוספרות ברציפות על פני כל המקורות, כך ששורה
המשתרעת על שני מקורות ממוספרת בדיוק פעם אחת, כשהבייט הראשון שלה מופיע.
`-b` ממספר רק שורות שאינן ריקות וגובר על `-n`. `-s` מדכא שורות ריקות
סמוכות חוזרות, ושורה מדוכאת אינה נכתבת ואינה ממוספרת.

אפשרויות הסימון הופכות בייטים בלתי נראים לגלויים: `-E` מדפיס `$` לפני
כל מעבר שורה, `-T` מדפיס TAB כ-`^I`, ו-`-v` מדפיס בייטי בקרה אחרים
כ-`^X` ובייטים שאינם ASCII בסימון `M-`. `-e`, `-t` ו-`-A` הם הצירופים
הרגילים `-vE`, `-vT` ו-`-vET`.

מקור שלא ניתן לקרוא עוצר את הפקודה לפני שנוגעים בכל מקור מאוחר יותר;
הבייטים שכבר נכתבו נשארים כתובים.

## OPTIONS

- `-A, --show-all` — שקול ל-`-vET`.
- `-b, --number-nonblank` — מספור שורות פלט שאינן ריקות; גובר על `-n`.
- `-e` — שקול ל-`-vE`.
- `-E, --show-ends` — הדפסת `$` בסוף כל שורה.
- `-n, --number` — מספור שורות הפלט, ברציפות על פני כל המקורות.
- `-s, --squeeze-blank` — דיכוי שורות ריקות סמוכות חוזרות.
- `-t` — שקול ל-`-vT`.
- `-T, --show-tabs` — הדפסת תווי TAB כ-`^I`.
- `-u` — מתקבל ומתעלמים ממנו; הפלט ממילא אינו נאגר.
- `-v, --show-nonprinting` — שימוש בסימוני `^` ו-`M-` לבייטי בקרה
  ולבייטים שאינם ASCII, פרט למעבר שורה ול-TAB.
- `-h, -?` — הצגת העזרה הקצרה של פקודה זו עצמה.

## EXAMPLES

- `cat notes.txt` — כתיבת `notes.txt` לפלט התקני.
- `cat a.txt - b.txt` — כתיבת `a.txt`, אחר כך הקלט התקני, אחר כך
  `b.txt`.
- `cat -n log.txt` — מספור כל שורת פלט.
- `cat -bs draft.txt` — מספור השורות שאינן ריקות ודחיסת רצפי הריק.
- `cat -A config.txt` — הפיכת סופי שורות, טאבים ובייטי בקרה לגלויים.
- `cat -- -n` — כתיבת הקובץ ששמו `-n`.

## EXIT STATUS

- `0` — כל מקור נכתב.
- `1` — לא ניתן היה לקרוא מקור, או שלא ניתן היה למסור את הפלט.
- `2` — שורת הפקודה לא הובנה.

## ENVIRONMENT

- `LANG` — האזור המועדף לעזרה הקצרה (תג BCP-47 כגון `he-IL`).
