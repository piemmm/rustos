## NAME

view — 画像と文書のグラフィカルビューア

## SYNOPSIS

`view`

## DESCRIPTION

画像または文書を表示するデスクトップウィンドウを開きます。文書を伴って起動
された場合（ファイルマネージャからの起動、または画像を開いた場合）はその
ファイルを表示し、単独で起動された場合はデスクトップセッションの信頼された
ファイル選択画面に選択を依頼します。

ビューアはファイルシステムに対する権能をいっさい保持しません。自力では何も
開けず、一覧できず、読み取れません。セッションがビューアに代わって自らの
識別のもとで参照し、利用者が選んだそのファイルだけが、一度限り・読み取り
専用でビューアに委譲されます。ファイルはビューアの内部では復号されません。
そのバイト列はファイルシステムへの到達手段をまったく持たない別の作業
プロセスへ送られるため、不正な形式のファイルや敵対的なファイルが、ビューアの
到達しうるものへ到達することはありません。

対応形式は JPEG、PNG、SVG、GIF、TIFF、WEBP、BMP、ICO、および RISC OS Sprite
です。復号器が拒んだファイルは、その理由をウィンドウ内と標準エラー出力に
述べます。ウィンドウが空白のまま残されることはなく、画像が捏造されることも
ありません。

複数の文書を同時に見ることは、複数のビューアを開くことです。二枚の画像を
並べて見比べるには二枚目を開きます。ウィンドウを閉じると、そのビューアが
終了します。

上端のツールバーには順に、縮小、拡大、ウィンドウに合わせる、実寸、前の項目、
次の項目、左回転、右回転、鏡像、アニメーションの再生と一時停止、情報パネルが
並びます。その末端には連続的な倍率スライダがあります。下端の状態行は、文書の
名前、形式、画素寸法、表示中の項目、長さ、倍率を述べます。

画像がウィンドウより大きいときは、画像をドラッグして内部を移動できます。その
間、キャンバスの縁にスクロールバーが現れます。画像の上でホイールを回すと
平行移動します。画像上の副ボタン押下でビューアのメニューが開きます。この
メニューはデスクトップセッションが描きます。

透明部分は市松模様の上に表示されるため、透明な画像は背後の色ではなく透明と
して読み取れます。

* `+` — 一段拡大する
* `-` — 一段縮小する
* `0` — 画像全体をウィンドウに合わせる
* `1` — 実寸、画像の一画素を画面の一画素に
* `2` — 画像の幅を合わせる
* `[` / `]` — 左または右へ四分の一回転
* `M` — 左右を鏡像にする
* `I` — 情報パネルの表示を切り替える
* `Space` — アニメーションを再生または一時停止する
* `O` — 別の文書を選ぶ
* `Page Up` / `Page Down` — 前または次の項目
* `Home` / `End` — 最初または最後の項目
* 矢印キー — 画像内を移動する
* `Escape` — ウィンドウを閉じる

## OPTIONS

`-h`, `-?`, `--help`
: このヘルプを標準出力に書き出して終了します。

## EXIT STATUS

正常に閉じた場合はゼロ。ウィンドウチャネル、共有フレーム領域、または
デスクトップセッションが拒まれた場合は非ゼロで、理由は標準エラー出力に
述べられます。
