## NAME

view — 图形化图片与文档查看器

## SYNOPSIS

`view`

## DESCRIPTION

打开一个桌面窗口，显示一张图片或一份文档。若在启动时带有文档——由文件管理器
启动，或通过打开一张图片启动——它就显示该文件；若单独启动，它会请求桌面会话
的可信文件选择器选择一个。

查看器不持有任何文件系统能力：它自身无法打开、列举或读取任何东西。会话以其
自身身份代为浏览，只有用户所选的那一个文件会被委派给查看器，一次性且只读。
该文件从不在查看器内部解码：其字节被送往一个独立的工作进程，该进程对文件系统
毫无触及，因此格式错误或含有恶意的文件无法触及查看器所能触及的任何东西。

受支持的格式为 JPEG、PNG、SVG、GIF、TIFF、WEBP、BMP、ICO 与 RISC OS Sprite。
解码器拒绝的文件会在窗口中并在标准错误流上说明其原因；窗口从不留白，也从不
凭空生成图像。

同时查看多份文档即为多个查看器：并排比较两张图片就是打开第二张。关闭一个窗口
即结束其查看器。

顶部工具栏依次为：缩小、放大、适应窗口、实际大小、上一项、下一项、向左旋转、
向右旋转、镜像、播放或暂停动画，以及信息面板。其尾端为一个连续的缩放滑块。
底部状态行说明文档的名称、格式、像素尺寸、所显示的条目、长度与放大倍数。

当图片大于窗口时，拖动图片可在其中移动；在此期间画布边缘会出现滚动条。在图片
上转动滚轮可平移。在图片上进行次要按压会打开查看器的菜单，该菜单由桌面会话
绘制。

透明部分以棋盘格显示，使透明图片读作透明，而非其背后的颜色。

* `+` — 放大一档
* `-` — 缩小一档
* `0` — 使整张图片适应窗口
* `1` — 实际大小，一个图片像素对应一个屏幕像素
* `2` — 使图片宽度适应窗口
* `[` / `]` — 向左或向右旋转四分之一圈
* `M` — 左右镜像
* `I` — 显示或隐藏信息面板
* `Space` — 播放或暂停动画
* `O` — 选择另一份文档
* `Page Up` / `Page Down` — 上一项或下一项
* `Home` / `End` — 第一项或最后一项
* 方向键 — 在图片中移动
* `Escape` — 关闭窗口

## OPTIONS

`-h`, `-?`, `--help`
: 将本帮助写至标准输出并退出。

## EXIT STATUS

正常关闭后为零。当窗口通道、共享帧区域或桌面会话被拒绝时为非零；原因会在标准
错误流上说明。
