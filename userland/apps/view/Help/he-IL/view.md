## NAME

view — מציג גרפי לתמונות ולמסמכים

## SYNOPSIS

`view`

## DESCRIPTION

פותח חלון בשולחן העבודה המציג תמונה או מסמך. אם הופעל עם מסמך — מתוך מנהל
הקבצים, או בפתיחת תמונה — הוא מציג את הקובץ ההוא; אם הופעל לבדו, הוא מבקש
מבורר הקבצים המהימן של הפעלת שולחן העבודה לבחור אחד.

למציג אין כל יכולת במערכת הקבצים: אין הוא יכול לפתוח, לפרט או לקרוא דבר
בעצמו. ההפעלה מעיינת בשמו תחת זהותה היא, ורק הקובץ שהמשתמש בחר מואצל לו —
פעם אחת בלבד ולקריאה בלבד. הקובץ לעולם אינו מפוענח בתוך המציג: הבתים שלו
נשלחים לתהליך עבודה נפרד שאין לו כל הישג במערכת הקבצים, ולפיכך קובץ פגום או
עוין אינו יכול להשיג דבר ממה שהמציג משיג.

התסדירים הנתמכים הם JPEG, PNG, SVG, GIF, TIFF, WEBP, BMP, ICO
ו‑RISC OS Sprite. קובץ שהמפענח דוחה מנמק את סירובו בחלון ובזרם השגיאות
התקני; החלון לעולם אינו נותר ריק, ותמונה לעולם אינה מומצאת.

כמה מסמכים בעת ובעונה אחת הם כמה מציגים: להשוות שתי תמונות זו לצד זו הוא
לפתוח את השנייה. סגירת חלון מסיימת את המציג שלו.

סרגל הכלים שבראש נושא, לפי הסדר: הקטנה, הגדלה, התאמה לחלון, גודל אמיתי,
הרשומה הקודמת, הרשומה הבאה, סיבוב שמאלה, סיבוב ימינה, שיקוף, ניגון או
השהיה של הנפשה, ולוח המידע. מחוון תקריב רציף יושב בקצהו האחרון. שורת המצב
שבתחתית מנקבת את שם המסמך, תסדירו, גודלו בפיקסלים, הרשומה המוצגת, אורכו
ומידת ההגדלה.

גררו את התמונה כדי לנוע בתוכה כשהיא גדולה מן החלון; כל עוד היא כזאת מופיעים
פסי גלילה בשולי הבד. סובבו את הגלגלת מעל התמונה כדי להסיטה. הקשה משנית על
התמונה פותחת את תפריט המציג, שהפעלת שולחן העבודה מציירת.

שקיפות מוצגת על גבי לוח משבצות, כדי שתמונה שקופה תיקרא כשקופה ולא כצבע
שמאחוריה.

* `+` — הגדלה בדרגה אחת
* `-` — הקטנה בדרגה אחת
* `0` — התאמת התמונה כולה לחלון
* `1` — גודל אמיתי, פיקסל תמונה אחד לכל פיקסל מסך
* `2` — התאמת רוחב התמונה
* `[` / `]` — רבע סיבוב שמאלה או ימינה
* `M` — שיקוף משמאל לימין
* `I` — הצגת לוח המידע או הסתרתו
* `Space` — ניגון הנפשה או השהייתה
* `O` — בחירת מסמך אחר
* `Page Up` / `Page Down` — הרשומה הקודמת או הבאה
* `Home` / `End` — הרשומה הראשונה או האחרונה
* מקשי החצים — תנועה בתוך התמונה
* `Escape` — סגירת החלון

## OPTIONS

`-h`, `-?`, `--help`
: כתיבת עזרה זו אל הפלט התקני ויציאה.

## EXIT STATUS

אפס לאחר סגירה נקייה. שונה מאפס כאשר ערוץ החלון, אזור המסגרת המשותף או
הפעלת שולחן העבודה סורבו; הסיבה מנוקבת בזרם השגיאות התקני.
