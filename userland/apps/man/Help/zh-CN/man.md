## NAME

man — 显示命令的帮助文档

## SYNOPSIS

`man [-h | -?] <command> [topic]`

## DESCRIPTION

渲染命令的应用程序包所附带的帮助文档；如果存在翻译，则以您的语言显示。

每个 RustOS 程序都是一个携带 `Help/` 树的应用程序包：每种语言下，每个命令
或主题各有一份结构化文档。`man` 解析 `<command>` 的方式与 shell 完全相同 —
先查系统应用商店，再查 `PATH` 中的目录 — 因此所显示的页面始终描述 shell 用
同一个词会运行的那个程序。以 `.app` 结尾的词直接指名程序包。当商店和
`PATH` 都不包含该词时，`man` 会递归搜索应用商店 — 先是 `/Apps`，然后是您
主目录中的 `Apps` 文件夹 — 因此即使程序包被收纳在嵌套的文件夹里也仍能被找
到；搜索绝不会查看另一个程序包的内部，并且最浅层的匹配获胜。

文档按环境变量 `LANG` 中的区域设置选取，其次回退到另一地区的同一语言，最
后回退到规范的英文文档。当页面未以所请求的语言显示时，`man` 会在咨询流
（fd 3）上注明这次替换；页面本身绝不会混杂多种语言。

在交互式控制台上，页面按屏显示：空格翻页，回车前进一行，`q` 停止。当输出
被重定向或控制台尺寸未知时，整页连续输出。

## OPTIONS

- `-h, -?` — 显示本命令自身的简短帮助。

## EXAMPLES

- `man ps` — 显示 `ps` 的页面。
- `man top keys` — 显示 `top` 程序包中的 `keys` 主题。
- `man files.app` — 直接指名程序包。

## EXIT STATUS

- `0` — 页面已显示。
- `1` — 未找到命令或其帮助文档，或页面无法送达。
- `2` — 无法理解命令行。

## ENVIRONMENT

- `LANG` — 首选的区域设置（BCP-47 标签，例如 `zh-CN`）。
- `PATH` — 在系统应用商店之后，用于查找 `<command>.app` 程序包的额外目录。
- `HOME` — 指名您自己的 `Apps` 文件夹，用于递归程序包搜索。
