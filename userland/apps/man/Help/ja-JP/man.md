## NAME

man — コマンドのヘルプ文書を表示する

## SYNOPSIS

`man [-h | -?] <command> [topic]`

## DESCRIPTION

コマンドのアプリケーションバンドルが同梱するヘルプ文書を表示します。翻訳
がある場合はあなたの言語で表示されます。

TAIRiX のすべてのプログラムは `Help/` ツリーを持つアプリケーションバンドル
です。言語ごとに、コマンドまたはトピックあたり一つの構造化文書を収めます。
`man` はシェルとまったく同じ順序で `<command>` を解決します — まず
固定ストア接頭部 `/System/Commands`、`/System/Applications`、
`<home>/Commands`、`<home>/Applications`、次に `PATH` 上のディレクトリ —
したがって表示されるページは、同じ語でシェルが実行するプログラムを常に説明
します。`PATH` がこの接頭部を並べ替えることも上書きすることもできません。
語尾の `.app` はバンドルを直接指名します。そのいずれにも語が見つからない
ときは、`man` がアプリストアを再帰的に探索します — まず `/Apps`、次に
ホームの `Commands` と `Applications` フォルダ — そのため入れ子のフォルダ
に整理されたバンドルも見つかります。探索は他のバンドルの内部を決して覗か
ず、最も浅い一致が優先されます。

文書は環境変数 `LANG` のロケールに従って選ばれ、次に別地域の同じ言語へ、最
後に正準の英語文書へフォールバックします。要求した言語でページが表示されな
かったときは、`man` が助言ストリーム（fd 3）にその置き換えを記します。ペー
ジ自体が複数言語の混在になることはありません。

対話型コンソールでは、ページは一画面ずつ表示されます。スペースで次の画面、
リターンで一行進み、`q` で終了します。出力がリダイレクトされているか、コン
ソールの寸法が不明な場合は、ページ全体が連続して出力されます。

## OPTIONS

- `-h, -?` — このコマンド自身の短いヘルプを表示する。

## EXAMPLES

- `man ps` — `ps` のページを表示する。
- `man top keys` — `top` バンドルの `keys` トピックを表示する。
- `man files.app` — バンドルを直接指名する。

## EXIT STATUS

- `0` — ページを表示した。
- `1` — コマンドまたはそのヘルプ文書が見つからない、またはページを届けら
  れなかった。
- `2` — コマンド行を解釈できなかった。

## ENVIRONMENT

- `LANG` — 優先ロケール（`ja-JP` のような BCP-47 タグ）。
- `PATH` — 固定ストア接頭部の後に `<command>.app` バンドルを探す追加
  ディレクトリ。
- `HOME` — 再帰バンドル探索のための、あなた自身の `Commands` と
  `Applications` フォルダを指名する。
