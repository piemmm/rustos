## NAME

false — לא לעשות דבר, בכישלון

## SYNOPSIS

`false [ignored arguments]`

## DESCRIPTION

מסיים במצב `1` תוך התעלמות מכל ארגומנט. תסריטים משתמשים בו בכל מקום שבו
נדרשת פקודה שנכשלת תמיד — כתנאי שקר תמידי או ככישלון מכוון.

רק ארגומנט **ראשון** של `-h`, `-?` או `--help` מכובד (המיקום שבו `false`
של GNU מכבד את `--help`); בכל מיקום מאוחר יותר האסימונים הללו מתעלמים
כמו כל השאר. בשונה מ-`false --help` של GNU, שעדיין מסיים ב-`1`, עזרה
קצרה שסופקה מסיימת כאן ב-`0` — מוסכמת העזרה הקצרה של TAIRiX.

## OPTIONS

- `-h, -?` — (כארגומנט ראשון בלבד) הצגת העזרה הקצרה של פקודה זו עצמה.

## EXAMPLES

- `false` — להיכשל.
- `until false; do …; done` — הרצת הגוף פעם אחת (התנאי תמיד שקר).

## EXIT STATUS

- `1` — תמיד (זו כל מטרת הכלי).
- `0` — עזרה קצרה שהתבקשה סופקה.

## ENVIRONMENT

- `LANG` — האזור המועדף לעזרה הקצרה (תג BCP-47 כגון `he-IL`).
