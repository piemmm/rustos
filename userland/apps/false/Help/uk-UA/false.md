## NAME

false — нічого не робити, безуспішно

## SYNOPSIS

`false [ігноровані аргументи]`

## DESCRIPTION

Завершується зі статусом `1`, ігноруючи всі аргументи. Скрипти
використовують його всюди, де потрібна команда, що завжди зазнає
невдачі, — як завжди хибна умова чи навмисна відмова.

Враховується лише **перший** аргумент `-h`, `-?` або `--help` (позиція,
в якій GNU `false` враховує `--help`); у будь-якій пізнішій позиції ці
слова ігноруються, як і все інше. На відміну від GNU `false --help`,
який усе одно завершується з `1`, надана коротка довідка тут
завершується з `0` — це домовленість короткої довідки TAIRiX.

## OPTIONS

- `-h, -?` — (лише як перший аргумент) показати коротку довідку цієї
  команди.

## EXAMPLES

- `false` — зазнати невдачі.
- `until false; do …; done` — виконати тіло один раз (умова завжди
  хибна).

## EXIT STATUS

- `1` — завжди (це і є призначення інструмента).
- `0` — запитану коротку довідку надано.

## ENVIRONMENT

- `LANG` — бажана локаль для короткої довідки (позначка BCP-47, як-от
  `uk-UA`).
