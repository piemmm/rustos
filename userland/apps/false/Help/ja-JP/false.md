## NAME

false — 何もせず、失敗する

## SYNOPSIS

`false [ignored arguments]`

## DESCRIPTION

すべての引数を無視して、状態 `1` で終了します。常に失敗するコマンドが必要
な場面 — 常に偽の条件、意図的な失敗 — でスクリプトが使います。

**最初の**引数としての `-h`、`-?`、`--help` だけが受け付けられます（GNU の
`false` が `--help` を受け付ける位置です）。それ以降の位置では、これらの語
も他のすべてと同様に無視されます。なお `1` で終了する GNU の
`false --help` と異なり、ここでは短いヘルプの表示に成功すると `0` で終了し
ます — TAIRiX の短いヘルプの規約です。

## OPTIONS

- `-h, -?` — （最初の引数のときのみ）このコマンド自身の短いヘルプを表示す
  る。

## EXAMPLES

- `false` — 失敗する。
- `until false; do …; done` — 本体を一度だけ実行する（条件は常に偽）。

## EXIT STATUS

- `1` — 常に（それがこのツールの目的そのものです）。
- `0` — 要求された短いヘルプを表示した。

## ENVIRONMENT

- `LANG` — 短いヘルプの優先ロケール（`ja-JP` のような BCP-47 タグ）。
