## NAME

false — لا تفعل شيئًا، وتفشل

## SYNOPSIS

`false [ignored arguments]`

## DESCRIPTION

يخرج بالحالة `1` متجاهلًا كل المعطيات. تستخدمه البرامج النصية حيثما لزم أمر
يفشل دائمًا — كشرط خاطئ دائمًا أو فشل متعمّد.

لا يُقبل إلا معطى **أول** من `-h` أو `-?` أو `--help` (وهو الموضع الذي يقبل
فيه `false` من GNU الخيار `--help`)؛ وفي أي موضع لاحق تُتجاهل هذه الرموز
مثل كل شيء آخر. وبخلاف `false --help` من GNU الذي يخرج مع ذلك بالحالة `1`،
فإن المساعدة القصيرة المقدَّمة هنا تخرج بالحالة `0` — وهذا عرف TAIRiX
للمساعدة القصيرة.

## OPTIONS

- `-h, -?` — (كمعطى أول فقط) عرض المساعدة القصيرة لهذا الأمر نفسه.

## EXAMPLES

- `false` — الفشل.
- `until false; do …; done` — تشغيل الجسم مرة واحدة (الشرط خاطئ دائمًا).

## EXIT STATUS

- `1` — دائمًا (وهذا هو غرض الأداة كله).
- `0` — قُدِّمت مساعدة قصيرة مطلوبة.

## ENVIRONMENT

- `LANG` — المنطقة المفضلة للمساعدة القصيرة (وسم BCP-47 مثل `ar-SA`).
