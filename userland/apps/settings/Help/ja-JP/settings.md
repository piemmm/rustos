## NAME

settings — デスクトップとこのマシンを設定する

## SYNOPSIS

`settings`

## DESCRIPTION

このシステムが持つ設定のカテゴリーをすべて並べたデスクトップウィンドウを開きま
す。マシンの素性、デスクトップの見た目、画面、ネットワーク、操作に使う装置、利用
しているアカウント、保持しているボリュームです。サイドバーでカテゴリーを選ぶと、
そのペインが表示されます。

Settings 自身は何の権限も持ちません。変更はいずれも、利用者自身の設定を所有する
デスクトップセッションへの要求か、その保存先をすでに書き込んでいるコマンドを再認
証して実行するかのどちらかです。ここから権限を昇格させる手立てはありません。

このシステムが担えないカテゴリーは、そのことをはっきり述べ、担うために何が必要か
を挙げます。担えるものの、この版がまだ操作部を描いていないカテゴリーは、代わりに
その設定がどこで読まれ、どこで設定されるかを示します。何も変えない操作部は決して
表示しません。

サイドバー上部の検索欄に入力すると、語が届くカテゴリーと設定に絞り込まれます。
`Tab` と `Shift+Tab` は検索欄、位置の履歴、サイドバー、ペインの間で移動し、`Up`
と `Down` はサイドバーをたどり、`Enter` はその行を開きます。幅が足りないウィンド
ウはサイドバーを落とし、そのとき位置の履歴の先頭がカテゴリーを一覧します。

デスクトップのシステムメニューの *Settings…* 行から、プログラムライブラリから、
またはシェルから名前で起動します。動作中のグラフィカルセッションが必要です。それ
がなければウィンドウチャネルに到達できず、標準エラー出力に拒否の理由を述べて終了
します。

## EXIT STATUS

正常に閉じたときは 0。ウィンドウチャネルまたは共有フレーム領域が拒否されたときは
非 0（理由は標準エラー出力に示されます）。
