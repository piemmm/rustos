## NAME

lspci — 検出された PCI/PCIe デバイスを一覧表示する

## SYNOPSIS

`lspci [-n | -nn] [-v] [-t] [-d [<vendor>]:[<device>]] [-s <node>]`

## DESCRIPTION

検出された PCI/PCIe ファンクションごとに 1 行、小さな一覧番号、その
ファンクションのクラス、ベンダー名とデバイス名を表示
します。目録はハードウェアツリー——システム唯一のデバイス目録——であ
り、システム情報 API を通じて読み取られ、`CAP_SYSINFO_HW` ケイパビリ
ティが必要です。拒否された場合は標準エラーに理由が報告され、代わりに
何も表示されません。

名前は、このコマンド自身のバンドルに同梱された、検証済みの公開 PCI
ID データベースのスナップショットに由来します。データベースが名前を
持たない識別子は数値形式（`Vendor 8086`、`Device 2922`、
`Class 0106`）で表示され、決して捏造されません。そのようなデバイスの
数は標準情報ストリーム（fd 3）に記録されます。同梱テーブルが見つから
ない、または検証に失敗した場合、一覧は数値 ID に劣化し、理由が標準エ
ラーに報告されます——目録自体は引き続き表示されます。

TAIRiX は PCI の `bus:device.function` アドレスを記録しません。代わり
に、一覧される各デバイスにはバス順で割り当てられる小さく安定した番号
が付与され、`#<n>` として表示され、`-s` はその番号を選択します（Linux
の `lspci` からの意図的で文書化された相違です）。この番号はハードウェ
アツリーの内部ノード ID では *ありません*。ノード ID は予約された空間
に由来し、大きく無意味な値になりえます。`-k`（カーネルドライバ）
ビューはまだ提供されません。システムはドライバ結合レコードを公開して
おらず、`lspci` はシステムが実際に記録しているものだけを報告します。

## OPTIONS

- `-n` — 数値 ID のみ：クラスコードと 16 進の `vendor:device`。
- `-nn` — 名前に続けて数値 ID を角括弧で表示。
- `-v` — 各ファンクションの後に、そのノードが宣言するリソース
  （MMIO ウィンドウ、IRQ ライン、I/O ポート、DMA 制約）を一覧表示
  ——ツリーに記録されたケイパビリティ付与要求であり、実行時状態では
  ありません。
- `-t` — ファンクションをバス親の下にツリーとして表示。中間のバス行
  はそのクラスとマッチキーの識別情報を示し、`-v`（`-tv`）ではその
  宣言されたリソースも表示します。
- `-d [<vendor>]:[<device>]` — 指定したベンダー/デバイス ID
  （16 進）に一致するファンクションのみ表示。省略した半分は任意に
  一致します。
- `-s <node>` — 指定した一覧番号（一覧に表示される 10 進の `#<n>`）を
  持つファンクションのみ表示。
- `-?, --help` — このコマンド自身の短いヘルプを表示。

## EXAMPLES

- `lspci` — 検出されたすべての PCI ファンクションを名前付きで。
- `lspci -nn` — 同上、数値 ID を併記。
- `lspci -v -s 7` — デバイス `#7` の行と宣言されたリソース。
- `lspci -d 1af4:` — ベンダー `1af4`（virtio）の各ファンクション。
- `lspci -t` — バストポロジーの下にファンクションを表示。

## EXIT STATUS

- `0` — 一覧（または短いヘルプ）を書き出した。
- `1` — ハードウェアツリーの照会が拒否・失敗した、または出力を書き
  出せなかった。
- `2` — コマンド行を解釈できなかった。

## ENVIRONMENT

- `LANG` — 短いヘルプに使う優先ロケール（`ja-JP` のような BCP-47
  タグ）。
