## NAME

lspci — 列出已发现的 PCI/PCIe 设备

## SYNOPSIS

`lspci [-n | -nn] [-v] [-t] [-d [<vendor>]:[<device>]] [-s <node>]`

## DESCRIPTION

为每个已发现的 PCI/PCIe 功能输出一行：该功能的硬件树节点编号、类别，
以及厂商与设备名称。清单来源于硬件树——系统唯一的设备清单——通过系统
信息 API 读取，需要 `CAP_SYSINFO_HW` 能力；被拒绝时会在标准错误上报
告原因，并且不会伪造任何列表。

名称来自本命令自身软件包内携带的、经过审核的公共 PCI 标识数据库快
照。数据库未命名的标识以数字形式显示（`Vendor 8086`、`Device 2922`、
`Class 0106`），绝不虚构；此类设备的数量会记录在标准信息流（fd 3）
上。若随附的表缺失或未通过校验，列表会退化为数字标识，并在标准错误
上说明原因——清单本身仍会列出。

TAIRiX 不记录 PCI 的 `bus:device.function` 地址：功能的稳定地址是其
硬件树节点编号，显示为 `#<node>`，`-s` 按该编号选择（这是相对 Linux
`lspci` 的有意且已记录的差异）。`-k`（内核驱动）视图尚未提供：系统
还未发布驱动绑定记录，`lspci` 只报告系统真正记录的内容。

## OPTIONS

- `-n` — 仅数字标识：类别代码与十六进制的 `vendor:device`。
- `-nn` — 名称之后以方括号附上数字标识。
- `-v` — 在每个功能之后列出其节点声明的资源（MMIO 窗口、IRQ 线、
  I/O 端口、DMA 约束）——树中记录的能力授予请求，而非实时状态。
- `-t` — 以总线父节点为层级，将功能渲染为树。
- `-d [<vendor>]:[<device>]` — 仅列出匹配给定厂商/设备标识
  （十六进制）的功能；省略的一半匹配任意值。
- `-s <node>` — 仅列出具有给定硬件树节点编号（十进制）的功能。
- `-?, --help` — 显示本命令自身的简短帮助。

## EXAMPLES

- `lspci` — 每个已发现的 PCI 功能，带名称。
- `lspci -nn` — 同上，并附数字标识。
- `lspci -v -s 7` — 节点 7 的行及其声明的资源。
- `lspci -d 1af4:` — 厂商 `1af4`（virtio）的每个功能。
- `lspci -t` — 按总线拓扑显示各功能。

## EXIT STATUS

- `0` — 已写出列表（或简短帮助）。
- `1` — 硬件树查询被拒绝或失败，或输出无法写出。
- `2` — 无法理解命令行。

## ENVIRONMENT

- `LANG` — 简短帮助的首选区域设置（BCP-47 标签，如 `zh-CN`）。
