## NAME

host — تحليل اسم عبر DNS

## SYNOPSIS

`host [-t type] name|address`

## DESCRIPTION

يحلّل اسم نطاق إلى عناوينه باستخدام المُحلّل الجذعي للنظام ويطبع كل إجابة في سطر
مستقل. بدون `-t` يُستعلَم عن سجلات `A` (IPv4) و`AAAA` (IPv6) معًا؛ ويقصر
`-t type` البحث على نوع واحد.

تُقرأ خوادم DNS التكرارية المطلوب الاستعلام منها من إعداد المضيف عبر واجهة
معلومات النظام — وهي نفس المجموعة الفعّالة التي تبلّغ عنها قراءة
`state:net/resolver/servers` — ويُتحقَّق من كل إجابة قبل عرض أي عنوان. لا يوجد
`/etc/resolv.conf` ولا ملف مضيفين محلي.

المعامل الذي يكون عنوان IPv4 أو IPv6 حرفيًا يعني بحثًا **عكسيًا**: يُعاد كتابته
إلى اسم `in-addr.arpa` أو `ip6.arpa` المقابل للعنوان، ويصير نوع السجل الافتراضي
`PTR`، ويُطبع السجل الموجود على هيئة
`<reverse-name> domain name pointer <name>.`

تُدعم فقط السجلات `A` و`AAAA` و`PTR`؛ أما الأنواع الأخرى (`MX` و`TXT` وغيرها)
فتُرفض بدلًا من معاملتها بصمت كأنها `A`. الاسم غير الموجود يطبع
`Host <name> not found: 3(NXDOMAIN)`؛ وعند تعذّر الوصول إلى أي خادم يبلّغ `host`
عن انتهاء المهلة على مخرج الخطأ القياسي.

## OPTIONS

- `-t, --type` — نوع سجل DNS المطلوب الاستعلام عنه: `A` أو `AAAA` أو `PTR`
  (دون تمييز حالة الأحرف). بدونه يُستعلَم عن `A` و`AAAA` للاسم، وعن `PTR`
  للعنوان.
- `-?, --help` — إظهار التعليمات المختصرة الخاصة بهذا الأمر.

## EXAMPLES

- `host example.com` — عناوين IPv4 وIPv6 للاسم.
- `host -t AAAA example.com` — عناوين IPv6 فقط.
- `host 10.0.2.2` — الاسم الذي يعود إليه ذلك العنوان.

## EXIT STATUS

- `0` — عُثر على عنوان واحد على الأقل (أو كُتبت التعليمات المختصرة).
- `1` — لم يُحلَّل الاسم إلى أي عنوان (إجابة سلبية أو انتهاء مهلة أو فشل
  المُحلّل).
- `2` — لم يُفهَم سطر الأوامر، أو تعذّرت كتابة المخرجات.

## ENVIRONMENT

- `LANG` — اللغة المحلية المفضّلة للتعليمات المختصرة (وسم BCP-47 مثل `fr-FR`).
