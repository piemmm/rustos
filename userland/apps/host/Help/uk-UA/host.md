## NAME

host — розв'язати ім'я через DNS

## SYNOPSIS

`host [-t type] name`

## DESCRIPTION

Розв'язує доменне ім'я в його адреси за допомогою системного заглушкового
резолвера й друкує кожну відповідь окремим рядком. Без `-t` запитуються як
записи `A` (IPv4), так і `AAAA` (IPv6); `-t type` обмежує пошук одним.

Рекурсивні DNS-сервери для запиту читаються з конфігурації хоста через API
системної інформації — той самий активний набір, який показує зчитування
`state:net/resolver/servers` — і кожна відповідь перевіряється, перш ніж
показати адресу. Немає `/etc/resolv.conf` і немає локального файлу вузлів.

Підтримуються лише адресні записи `A` та `AAAA`; інші типи (`MX`, `TXT`
тощо) відхиляються, а не тихо трактуються як `A`. Неіснуюче ім'я друкує
`Host <name> not found: 3(NXDOMAIN)`; коли жоден сервер недосяжний, `host`
повідомляє про перевищення часу очікування у стандартний потік помилок.

## OPTIONS

- `-t, --type` — тип DNS-запису для запиту: `A` або `AAAA` (без урахування
  регістру). Без цього запитуються обидва.
- `-?, --help` — показати власну коротку довідку цієї команди.

## EXAMPLES

- `host example.com` — адреси IPv4 та IPv6 імені.
- `host -t AAAA example.com` — лише адреси IPv6.

## EXIT STATUS

- `0` — знайдено принаймні одну адресу (або записано коротку довідку).
- `1` — ім'я не розв'язалося в жодну адресу (негативна відповідь,
  перевищення часу очікування або збій резолвера).
- `2` — командний рядок не зрозуміло, або не вдалося записати вивід.

## ENVIRONMENT

- `LANG` — бажана локаль для короткої довідки (мітка BCP-47, така як
  `fr-FR`).
