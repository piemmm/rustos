## NAME

host — פענוח שם דרך DNS

## SYNOPSIS

`host [-t type] name|address`

## DESCRIPTION

מפענח שם מתחם לכתובותיו באמצעות פותר ה-stub של המערכת ומדפיס כל תשובה בשורה
נפרדת. ללא `-t` נשלחות שאילתות הן לרשומות `A` (IPv4) והן ל-`AAAA` (IPv6);
`-t type` מגביל את החיפוש לאחת.

שרתי ה-DNS הרקורסיביים שיש לשאול נקראים מתצורת המארח דרך ממשק מידע המערכת —
אותה קבוצה פעילה שקריאת `state:net/resolver/servers` מדווחת עליה — וכל תשובה
מאומתת לפני הצגת כתובת. אין `/etc/resolv.conf` ואין קובץ מארחים מקומי.

אופרנד שהוא כתובת IPv4 או IPv6 מפורשת הוא חיפוש **הפוך**: הוא נכתב מחדש כשם
`in-addr.arpa` או `ip6.arpa` שהכתובת ממופה אליו, סוג הרשומה שברירת המחדל הופך
`PTR`, ורשומה שנמצאה מודפסת כ־`<reverse-name> domain name pointer <name>.`

נתמכות רק הרשומות `A`, `AAAA` ו-`PTR`; סוגים אחרים (`MX`, `TXT` וכן הלאה)
נדחים במקום שיטופלו בשקט כ-`A`. שם שאינו קיים מדפיס
`Host <name> not found: 3(NXDOMAIN)`; וכאשר לא ניתן להגיע לאף שרת, `host`
מדווח על פסק זמן בפלט השגיאה התקני.

## OPTIONS

- `-t, --type` — סוג רשומת ה-DNS שיש לשאול: `A`, `AAAA` או `PTR` (ללא הבחנה
  בין אותיות רישיות). בלעדיו נשאלות `A` ו-`AAAA` עבור שם, ו-`PTR` עבור
  כתובת.
- `-?, --help` — הצגת העזרה הקצרה של פקודה זו.

## EXAMPLES

- `host example.com` — כתובות ה-IPv4 וה-IPv6 של השם.
- `host -t AAAA example.com` — כתובות IPv6 בלבד.
- `host 10.0.2.2` — השם שאליו כתובת זו ממופה חזרה.

## EXIT STATUS

- `0` — נמצאה לפחות כתובת אחת (או שנכתבה העזרה הקצרה).
- `1` — השם לא פוענח לאף כתובת (תשובה שלילית, פסק זמן או כשל בפותר).
- `2` — שורת הפקודה לא הובנה, או שלא ניתן היה לכתוב את הפלט.

## ENVIRONMENT

- `LANG` — האזור המועדף לעזרה הקצרה (תג BCP-47 כגון `fr-FR`).
