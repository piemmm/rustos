## NAME

ln — 创建符号链接

## SYNOPSIS

`ln -s [-finvT] [-t dir] [--] target... [link_name]`

## DESCRIPTION

为每个目标创建一个指向它的符号链接。只有一个操作数时，链接在工作目录中
以目标自身的名称创建。有两个操作数时，若第二个是目录（或指向目录的链接，
除非给了 `-n`）则链接创建在其中，否则它就是链接的名称。有三个或更多时，
最后一个必须已经是目录。

目标按**原样**存储，从不解析：它可以是相对的，可以含有 `..`，也可以什么
都不指向，因此链接可以合理地悬空。存储之前仍会检查它的语法，所以任何解析
器都无法走通的目标会被拒绝。创建链接不授予对其所指对象的任何权限——之后
每次使用都在你自己的身份下逐段授权。

若链接名称已被占用，除非 `-f` 或 `-i` 要求替换，否则拒绝；替换会先**移除**
该名称，因此不会有任何东西穿过原本就在那里的链接作用到它所指的对象。目录
永远不会被替换。

首次失败会在处理任何后续目标之前停止运行；已创建的链接保留。`--` 结束选项
解析：其后每个参数都是操作数。

本系统没有硬链接，因此 `-s` 是必需的：没有它 `ln` 无可创建，它会如实说明，
而不是创建一个符号链接——那是不同的对象。仅用于硬链接的选项 `-L`、`-P`、
`-d` 和 `-F` 因同样的原因被拒绝。`-b`/`-S` 被拒绝是因为没有备份机制可以调用；
`-r` 被拒绝是因为计算相对于链接自身目录的目标需要本系统不提供的规范化解析
——一旦涉及链接，词法解析会指向另一个对象。

## OPTIONS

- `-s, --symbolic` — 创建符号链接。必需：见上文。
- `-f, --force` — 移除已存在的链接名称，然后创建链接。
- `-i, --interactive` — 移除已存在的链接名称之前询问；只有以 `y`/`Y`
  开头的回答表示同意。`-f` 与 `-i` 中较晚的一个生效。
- `-n, --no-dereference` — 把指向目录的符号链接目标视为它同时也是的普通
  名称，而不是创建链接的目录。
- `-v, --verbose` — 以 `'link' -> 'target'` 的形式报告每个已创建的链接。
- `-t dir, --target-directory=dir` — 在 `dir` 中创建每个链接，`dir`
  必须已经是目录。取值可紧随其后（`-tdir`、`--target-directory=dir`）
  或作为下一个参数。
- `-T, --no-target-directory` — 把目标视为链接名称，而绝不视为要填充的
  目录；恰好两个操作数。不能与 `-t` 同用。
- `-h, -?, --help` — 显示本命令自带的简短帮助。

## EXAMPLES

- `ln -s /System/Commands/ls.app tools/ls` — 将一个名称链接到一个应用包。
- `ln -s ../shared/notes.txt` — 在此处以相对目标链接 `notes.txt`。
- `ln -sv -t Links a.txt b.txt` — 把两个文件都链接进 `Links`，并报告每个
  链接。
- `ln -sfn /Storage/media Music` — 把已存在的 `Music` 链接改指向新目录，
  即替换该链接而不是链接到它内部。

## EXIT STATUS

- `0` — 所有链接均已创建（或已写出简短帮助）；对 `-i` 的否定回答不算失败。
- `1` — 其他任何情况，原因写在标准错误上。未被理解的命令行同样以 `1` 退出。

## ENVIRONMENT

- `LANG` — 简短帮助偏好的区域设置（BCP-47 标签，例如 `fr-FR`）。
