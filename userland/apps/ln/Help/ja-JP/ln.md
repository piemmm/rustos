## NAME

ln — シンボリックリンクを作成する

## SYNOPSIS

`ln -s [-finvT] [-t dir] [--] target... [link_name]`

## DESCRIPTION

各ターゲットを指すシンボリックリンクを作成します。オペランドが 1 つの
ときは、ターゲット自身の名前で作業ディレクトリにリンクを作ります。2 つ
のときは、2 番目がディレクトリ（あるいは `-n` を与えない限りディレクトリ
へのリンク）ならその中に作り、そうでなければそれがリンクの名前になります。
3 つ以上のときは、最後のオペランドがすでにディレクトリでなければなりません。

ターゲットは**そのまま**保存され、決して解決されません。相対でもよく、
`..` を含んでもよく、何も指していなくてもよいので、リンクは正当に宙ぶらりん
になり得ます。保存前に文法だけは検査されるため、どの解決器も辿れない
ターゲットは拒否されます。リンクの作成は、それが指すものに対する権限を
何も与えません。以降の利用はそのたびに、あなた自身の識別のもとで構成要素
ごとに認可されます。

リンク名がすでに使われている場合、`-f` または `-i` が置き換えを指示しない
限り拒否されます。置き換えはまずその名前を**削除**するので、すでにそこに
あったリンクを通ってその指す先に作用することはありません。ディレクトリが
置き換えられることはありません。

最初の失敗で、以降のターゲットに進む前に実行を止めます。すでに作られた
リンクはそのまま残ります。`--` はオプション解析を終わらせ、以降の引数は
すべてオペランドになります。

このシステムにはハードリンクがないため `-s` は必須です。`-s` がなければ
`ln` に作るものはなく、別の物であるシンボリックリンクを作る代わりに、その
ことを述べます。ハードリンク専用のオプション `-L`、`-P`、`-d`、`-F` も
同じ理由で拒否されます。`-b`/`-S` は呼び出すバックアップ機構が存在しない
ため、`-r` はリンク自身のディレクトリからの相対ターゲットの計算に、この
システムが提供しない正規化解決が必要なため拒否されます。字句的な解決では、
リンクが絡んだ途端に別の物を指してしまいます。

## OPTIONS

- `-s, --symbolic` — シンボリックリンクを作成する。必須（上記参照）。
- `-f, --force` — 既存のリンク名を削除してからリンクを作成する。
- `-i, --interactive` — 既存のリンク名を削除する前に確認する。`y`/`Y`
  で始まる返答のみが同意となる。`-f` と `-i` は後に指定した方が効く。
- `-n, --no-dereference` — ディレクトリへのシンボリックリンクである
  行き先を、リンクを作るディレクトリではなく、それが同時にそうである
  ただの名前として扱う。
- `-v, --verbose` — 作成した各リンクを `'link' -> 'target'` の形で報告する。
- `-t dir, --target-directory=dir` — 各リンクを `dir` に作成する。`dir`
  はすでにディレクトリでなければならない。値は続けて（`-tdir`、
  `--target-directory=dir`）または次の引数として与える。
- `-T, --no-target-directory` — 行き先をリンク名として扱い、埋めるべき
  ディレクトリとしては扱わない。オペランドは正確に 2 つ。`-t` とは併用
  できない。
- `-h, -?, --help` — このコマンド自身の短いヘルプを表示する。

## EXAMPLES

- `ln -s /System/Commands/ls.app tools/ls` — 名前をバンドルにリンクする。
- `ln -s ../shared/notes.txt` — 相対ターゲットで `notes.txt` をここに
  リンクする。
- `ln -sv -t Links a.txt b.txt` — 両方のファイルを `Links` にリンクし、
  各リンクを報告する。
- `ln -sfn /Storage/media Music` — 既存の `Music` リンクを新しい
  ディレクトリに向け直す。中にリンクを作るのではなくリンク自体を
  置き換える。

## EXIT STATUS

- `0` — すべてのリンクが作成された（または短いヘルプが書き出された）。
  `-i` を断ったことは失敗ではない。
- `1` — それ以外。理由は標準エラーに出る。理解できないコマンド行も `1`
  で終了する。

## ENVIRONMENT

- `LANG` — 短いヘルプに使うロケール（`fr-FR` のような BCP-47 タグ）。
