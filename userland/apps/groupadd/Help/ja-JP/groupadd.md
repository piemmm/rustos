## NAME

groupadd — グループを作る

## SYNOPSIS

`groupadd [-g GID] [--] NAME`

## DESCRIPTION

グループ台帳にグループを一つ追加します。グループ名は
`[a-z_][a-z0-9_-]*` に合致しなければならず、id は十進の値です。グループ
の作成は管理操作です。ユーザー管理の権能を持たない呼び出し元を台帳は拒否
します。

`-g` が省かれると、グループ id は既存の最大 id の一つ上へ自動的に割り当
てられます。すでに使われている id の要求は拒否されます。衝突の裁定者は台
帳です。

`--` はオプション解析を終え、以降のすべての引数はオペランドです。

## OPTIONS

- `-g, --gid GID` — 数値のグループ id。省くと自動割り当て（既存の最大 id
  の一つ上）。
- `-h, -?, --help` — このコマンド自身の短いヘルプを表示する。

## EXAMPLES

- `groupadd staff` — 自動割り当ての id で `staff` を作る。
- `groupadd -g 100 staff` — id `100` で `staff` を作る。

## EXIT STATUS

- `0` — グループを作成した。
- `1` — 台帳が作成を拒否または失敗した（権能の欠如や id の重複など）。理
  由は標準エラーに印字される。
- `2` — コマンド行を解釈できなかった。

## ENVIRONMENT

- `LANG` — 短いヘルプの優先ロケール（`ja-JP` のような BCP-47 タグ）。
