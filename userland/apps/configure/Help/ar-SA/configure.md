## NAME

configure — قراءة إعدادات النظام وقت الإقلاع وضبطها

## SYNOPSIS

`configure [<key> [<value>]]`

## DESCRIPTION

يسرد ويعرض ويضبط إعدادات مخزن الضبط في
`/System/Settings/Configuration/system.conf`. بدون معاملات يُسرد كل
إعداد مع قيمته الحالية؛ وبمفتاح وحده تُعرض قيمة ذلك الإعداد؛ وبمفتاح
وقيمة يُغيَّر الإعداد.

يقيم المخزن على وحدة تخزين الجذر المشفّرة ويقرؤه مستهلكوه بعد فك قفل
نظام ملفات الجذر؛ لذا يسري التغيير عند التشغيل التالي لمستهلكه
(`os.loginType`: تسجيل دخول الإقلاع التالي).

مجموعة المفاتيح مغلقة: يُرفض المفتاح المجهول، أو القيمة الخارجة عن
مجموعة مفتاحها، مع بيان الخيارات الصحيحة ودون أي تغيير. تغييرُ إعدادٍ
يعيد كتابة المخزن بصيغته القياسية ويتطلب صلاحية الكتابة على
`/System/Settings` — يستطيع الحساب العادي قراءة الإعدادات لكن لا
يستطيع تغييرها.

- `os.loginType` — ‏`text` أو `graphical`: نوع الجلسة الذي تبدؤه خدمة
  تسجيل الدخول للمستخدم المُصادَق عليه. يبدأ `text` (الافتراضي) صدفة
  الحساب — ويمكن دائمًا بدء سطح المكتب عند الطلب بالأمر `desktop`؛
  ويبدأ `graphical` جلسة سطح المكتب مباشرة بعد المصادقة عندما يكون
  سطح مكتب مثبتًا، ويعود إلى النص عند غيابه.

## OPTIONS

- `-h, -?` — عرض المساعدة الموجزة لهذا الأمر.

## EXAMPLES

- `configure` — سرد كل الإعدادات.
- `configure os.loginType` — عرض نوع الجلسة الافتراضي.
- `configure os.loginType graphical` — الإقلاع إلى تسجيل الدخول
  الرسومي.

## EXIT STATUS

- `0` — اكتمل السرد أو القيمة أو المساعدة الموجزة أو التغيير.
- `1` — تعذّرت قراءة المخزن أو كتابته (مثلًا لا يجوز للمنادي تغيير
  إعدادات النظام)، أو تعذّر تسليم الخرج.
- `2` — لم تُفهم سطر الأوامر، أو المفتاح مجهول، أو القيمة خارج مجموعة
  المفتاح.

## ENVIRONMENT

- `LANG` — اللغة المفضّلة للمساعدة الموجزة (وسم BCP-47 مثل `fr-FR`).
