## NAME

configure — 부팅 시 시스템 구성을 읽고 설정하기

## SYNOPSIS

`configure [<key> [<value>]]`

## DESCRIPTION

`/System/Settings/Configuration/system.conf`에 있는 구성 저장소의
설정을 나열·표시·변경합니다. 피연산자가 없으면 각 설정이 현재 값과
함께 나열되고, 키만 주면 그 설정의 값이 표시되며, 키와 값을 주면
설정이 변경됩니다.

저장소는 암호화된 루트 볼륨에 있으며 루트 파일 시스템이 잠금
해제된 뒤에 소비자가 읽습니다. 따라서 변경은 해당 소비자가 다음에
시작될 때 적용됩니다(`os.loginType`: 다음 부팅의 로그인).

키 집합은 닫혀 있습니다. 알 수 없는 키나 키 집합 밖의 값은 유효한
선택지를 알리며 거부되고 아무것도 바꾸지 않습니다. 설정 변경은
저장소를 정준 형식으로 다시 쓰며 `/System/Settings`에 대한 쓰기
권한이 필요합니다. 일반 계정은 설정을 읽을 수 있지만 바꿀 수는
없습니다.

- `os.loginType` — `text` 또는 `graphical`: 로그인 서비스가 부팅
  기본값으로 제시하는 세션 유형. `text`(기본값)는 텍스트를 기본으로
  하는 세션 선택 질문을 유지하고, `graphical`은 데스크톱이 설치된
  경우 인증 후 데스크톱 세션을 바로 시작하며 없으면 텍스트로
  물러납니다.

## OPTIONS

- `-h, -?` — 이 명령의 짧은 도움말을 표시합니다.

## EXAMPLES

- `configure` — 모든 설정을 나열합니다.
- `configure os.loginType` — 기본 세션 유형을 표시합니다.
- `configure os.loginType graphical` — 그래픽 로그인으로 부팅합니다.

## EXIT STATUS

- `0` — 나열, 값, 짧은 도움말 또는 변경이 완료되었습니다.
- `1` — 저장소를 읽거나 쓸 수 없었거나(예: 호출자가 시스템 설정을
  바꿀 수 없음) 출력을 전달할 수 없었습니다.
- `2` — 명령줄을 이해하지 못했거나, 키를 알 수 없거나, 값이 키 집합
  밖에 있습니다.

## ENVIRONMENT

- `LANG` — 짧은 도움말의 선호 로케일(`fr-FR` 같은 BCP-47 태그).
