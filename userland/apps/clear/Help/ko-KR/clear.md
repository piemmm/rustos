## NAME

clear — 터미널 화면 지우기

## SYNOPSIS

`clear [-x]`

## DESCRIPTION

커서를 왼쪽 위 모서리로 옮기고 전체 표시를 지우는 시퀀스를 써서 빈 화면을
남깁니다. 어떤 시퀀스를 쓸지는 `TERM`에 지정된 터미널이 결정합니다. 지울
수 없는 터미널(알 수 없는 `TERM`은 「dumb」 기준선으로 격하됩니다)에서는
터미널이 쓰레기로 표시할 바이트를 출력하는 대신 명령이 실패합니다.

RustOS 콘솔은 스크롤백을 보관하지 않으므로 지울 스크롤백이 없습니다.
`-x`(스크롤백을 보존하는 GNU 옵션)는 스크립트 호환을 위해 받아들여지지만
아무것도 바꾸지 않습니다.

## OPTIONS

- `-x` — GNU 호환을 위해 받아들여집니다. RustOS 콘솔은 스크롤백을 보관하지
  않으므로 있으나 없으나 출력이 동일합니다.
- `-h, -?` — 이 명령 자체의 짧은 도움말을 표시합니다.

## EXAMPLES

- `clear` — 화면을 지웁니다.

## EXIT STATUS

- `0` — 지우기 시퀀스를 썼습니다.
- `1` — 터미널이 지울 수 없거나 출력을 전달할 수 없었습니다.
- `2` — 명령줄을 이해하지 못했습니다.

## ENVIRONMENT

- `TERM` — 그 지우기 시퀀스를 쓰는 터미널.
- `LANG` — 짧은 도움말의 선호 로캘(`ko-KR` 같은 BCP-47 태그).
