## NAME

clear — очистити екран термінала

## SYNOPSIS

`clear [-x]`

## DESCRIPTION

Записує послідовність, що переміщує курсор у верхній лівий кут і стирає
весь вміст екрана, залишаючи його порожнім. Яка саме послідовність буде
записана, визначає термінал, названий у `TERM`; термінал, що не вміє
очищати (невідомий `TERM` знижується до мінімального профілю), змушує
команду завершитися з помилкою замість друкувати байти, які термінал
показав би як сміття.

Консолі RustOS не зберігають історію прокручування, тож стирати її
нема потреби: `-x` (опція GNU, що зберігає історію) приймається для
сумісності зі скриптами й нічого не змінює.

## OPTIONS

- `-x` — приймається для сумісності з GNU; консоль RustOS не зберігає
  історії, тому вивід однаковий з нею і без неї.
- `-h, -?` — показати коротку довідку цієї команди.

## EXAMPLES

- `clear` — очистити екран.

## EXIT STATUS

- `0` — послідовність очищення записано.
- `1` — термінал не вміє очищати, або вивід не вдалося доставити.
- `2` — командний рядок не зрозуміло.

## ENVIRONMENT

- `TERM` — термінал, чию послідовність очищення буде записано.
- `LANG` — бажана локаль для короткої довідки (позначка BCP-47, як-от
  `uk-UA`).
