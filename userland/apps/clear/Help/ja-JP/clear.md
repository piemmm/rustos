## NAME

clear — 端末の画面を消去する

## SYNOPSIS

`clear [-x]`

## DESCRIPTION

カーソルを左上隅へ移動し、表示全体を消去するシーケンスを書き出して、空の画
面を残します。どのシーケンスを書くかは `TERM` に指定された端末が決めます。
消去できない端末（未知の `TERM` は「dumb」の基準線に格下げされます）では、
端末がゴミとして描画するバイト列を出す代わりに、コマンドは失敗します。

RustOS のコンソールはスクロールバックを持たないため、消すべきスクロール
バックは存在しません。`-x`（スクロールバックを保持する GNU のオプション）
はスクリプト互換のために受け付けられますが、何も変えません。

## OPTIONS

- `-x` — GNU 互換のために受け付けられる。RustOS のコンソールはスクロール
  バックを持たないため、有無にかかわらず出力は同一。
- `-h, -?` — このコマンド自身の短いヘルプを表示する。

## EXAMPLES

- `clear` — 画面を消去する。

## EXIT STATUS

- `0` — 消去シーケンスを書き出した。
- `1` — 端末が消去できない、または出力を届けられなかった。
- `2` — コマンド行を解釈できなかった。

## ENVIRONMENT

- `TERM` — その消去シーケンスを書き出す端末。
- `LANG` — 短いヘルプの優先ロケール（`ja-JP` のような BCP-47 タグ）。
