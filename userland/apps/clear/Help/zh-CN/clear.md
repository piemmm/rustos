## NAME

clear — 清除终端屏幕

## SYNOPSIS

`clear [-x]`

## DESCRIPTION

写出把光标移到左上角并擦除整个显示的序列，留下一个空屏幕。写出哪个序列由
`TERM` 命名的终端决定；无法清屏的终端（未知的 `TERM` 会退化为「dumb」基
线）会使命令失败，而不是打印终端会显示为乱码的字节。

RustOS 控制台不保留回滚缓冲区，因此没有回滚可清除：`-x`（GNU 中保留回滚的
选项）为脚本兼容而被接受，但不改变任何行为。

## OPTIONS

- `-x` — 为 GNU 兼容而接受；RustOS 控制台不保留回滚，因此带与不带它的输出
  完全相同。
- `-h, -?` — 显示本命令自身的简短帮助。

## EXAMPLES

- `clear` — 清屏。

## EXIT STATUS

- `0` — 清屏序列已写出。
- `1` — 终端无法清屏，或输出无法送达。
- `2` — 无法理解命令行。

## ENVIRONMENT

- `TERM` — 写出其清屏序列的终端。
- `LANG` — 简短帮助的首选区域设置（BCP-47 标签，例如 `zh-CN`）。
