## NAME

whoami — 現在のユーザーのアカウント名を印字する

## SYNOPSIS

`whoami`

## DESCRIPTION

このプロセスの識別情報に対応するユーザー名を印字し、改行を付けます。
それ以外は何も出力しません。

RustOS に `/etc/passwd` はありません。ユーザー識別子はカーネルが呼び
出しプロセスについて保持する記録から得られ、対応するアカウント名はシ
ステム情報 API の公開アカウントディレクトリから得られます。ディレク
トリにその識別子の名前がなければ、コマンドは
`cannot find name for user ID <uid>` を報告して失敗します。

このコマンドはオペランドを受け付けません。引数は `extra operand` エ
ラーです。

## OPTIONS

- `-h, -?` — このコマンド自身の短いヘルプを表示する。
- `--` — オプション解析を終える。以降のどの引数も余分なオペランドの
  まま（`whoami` は何も受け付けない）。

## EXAMPLES

- `whoami` — コマンドを実行しているアカウントの名前を印字する。

## EXIT STATUS

- `0` — 名前（または要求された短いヘルプ）を書き出した。
- `1` — 識別情報の読み取り、ディレクトリの照会、または出力に失敗し
  た。あるいはディレクトリにそのユーザー識別子の名前がない。
- `2` — コマンド行を理解できなかった。

## ENVIRONMENT

- `LANG` — 短いヘルプの優先ロケール（`ja-JP` のような BCP-47 タグ）。
