## NAME

whoami — הדפסת שם החשבון של המשתמש הנוכחי

## SYNOPSIS

`whoami`

## DESCRIPTION

מדפיס את שם המשתמש המשויך לזהות של תהליך זה, ואחריו מעבר שורה — ותו
לא.

ל־TAIRiX אין `/etc/passwd`: מזהה המשתמש מגיע מהרשומה שהליבה מחזיקה על
התהליך הקורא, ושם החשבון התואם מגיע מספריית החשבונות הציבורית של
ממשק מידע המערכת. אם הספרייה אינה מכילה שם עבור המזהה, הפקודה מדווחת
`cannot find name for user ID <uid>` ונכשלת.

הפקודה אינה מקבלת אופרנדים; כל ארגומנט הוא שגיאת `extra operand`.

## OPTIONS

- `-h, -?` — הצגת העזרה הקצרה של פקודה זו עצמה.
- `--` — סיום ניתוח האפשרויות; כל ארגומנט מאוחר יותר נשאר אופרנד
  מיותר (`whoami` אינה מקבלת אף אחד).

## EXAMPLES

- `whoami` — הדפסת שם החשבון שמריץ את הפקודה.

## EXIT STATUS

- `0` — השם (או העזרה הקצרה שהתבקשה) נכתב.
- `1` — קריאת הזהות, שאילתת הספרייה או הפלט נכשלו, או שהספרייה אינה
  מכילה שם עבור מזהה המשתמש.
- `2` — שורת הפקודה לא הובנה.

## ENVIRONMENT

- `LANG` — האזור המועדף לעזרה הקצרה (תג BCP-47 כגון `he-IL`).
