## NAME

whoami — вивести назву облікового запису поточного користувача

## SYNOPSIS

`whoami`

## DESCRIPTION

Виводить ім'я користувача, пов'язане з ідентичністю цього процесу,
після якого йде перехід на новий рядок — і більше нічого.

У RustOS немає `/etc/passwd`: ідентифікатор користувача походить із
запису, який ядро веде про процес-викликач, а відповідна назва
облікового запису — з відкритого каталогу облікових записів API
системної інформації. Якщо каталог не містить назви для цього
ідентифікатора, команда повідомляє
`cannot find name for user ID <uid>` і завершується з помилкою.

Команда не приймає операндів; аргумент — це помилка `extra operand`.

## OPTIONS

- `-h, -?` — показати коротку довідку цієї команди.
- `--` — завершити розбір параметрів; будь-який подальший аргумент усе
  одно є зайвим операндом (`whoami` не приймає жодного).

## EXAMPLES

- `whoami` — вивести назву облікового запису, від імені якого виконано
  команду.

## EXIT STATUS

- `0` — назву (або запитану коротку довідку) записано.
- `1` — не вдалося прочитати ідентичність, опитати каталог або
  виконати вивід, або каталог не містить назви для ідентифікатора
  користувача.
- `2` — командний рядок не зрозуміло.

## ENVIRONMENT

- `LANG` — бажана локаль для короткої довідки (BCP-47-мітка, як-от
  `fr-FR`).
