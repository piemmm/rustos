## NAME

whoami — 현재 사용자의 계정 이름을 출력한다

## SYNOPSIS

`whoami`

## DESCRIPTION

이 프로세스의 신원에 연결된 사용자 이름을 출력하고 줄 바꿈을 덧붙입
니다. 그 밖에는 아무것도 출력하지 않습니다.

TAIRiX에는 `/etc/passwd`가 없습니다. 사용자 식별자는 커널이 호출 프
로세스에 대해 보관하는 기록에서 오고, 그에 대응하는 계정 이름은 시스
템 정보 API의 공개 계정 디렉터리에서 옵니다. 디렉터리에 해당 식별자
의 이름이 없으면 명령은
`cannot find name for user ID <uid>`를 보고하고 실패합니다.

이 명령은 피연산자를 받지 않습니다. 인수는 `extra operand` 오류입니
다.

## OPTIONS

- `-h, -?` — 이 명령 자신의 짧은 도움말을 표시한다.
- `--` — 옵션 해석을 끝낸다. 이후의 어떤 인수도 여전히 남는 피연산자
  다(`whoami`는 아무것도 받지 않는다).

## EXAMPLES

- `whoami` — 명령을 실행하는 계정의 이름을 출력한다.

## EXIT STATUS

- `0` — 이름(또는 요청된 짧은 도움말)을 썼다.
- `1` — 신원 읽기, 디렉터리 조회 또는 출력이 실패했거나, 디렉터리에
  해당 사용자 식별자의 이름이 없다.
- `2` — 명령줄을 이해하지 못했다.

## ENVIRONMENT

- `LANG` — 짧은 도움말의 선호 로캘(`ko-KR` 같은 BCP-47 태그).
