## NAME

wc — 各ファイルの改行数・単語数・バイト数を印字する

## SYNOPSIS

`wc [option...] [file...]`

`wc [option...] --files0-from <file>`

## DESCRIPTION

各 `file` について行数（改行文字の数）、単語数、バイト数を数え、一行にま
とめてファイル名を添えて印字します。`file` がない場合や `file` が `-` の
場合は標準入力を読みます（オペランドなしの形では名前を印字しません）。入
力が複数あれば、`--total` の選択に従って最後に `total` の行を印字します。

セレクタ `-l`、`-w`、`-m`、`-c`、`-L` はどの数を印字するかを選びます。ど
れもなければ、改行数・単語数・バイト数を印字します。数は常に固定の順序 —
行、単語、文字、バイト、最大行幅 — で並びます。単語は空白でない文字の最長
の連なりです。`-m` は UTF-8 の文字を数えます（有効な UTF-8 でないバイトは
バイトとしては数えられ、文字としては数えられません）。`-L` は各行の表示幅
を端末の桁数で測り、タブは次の 8 の倍数まで進みます。

`--files0-from <file>` は NUL 区切りのオペランド一覧を `file` から読みま
す（`-` は標準入力の意味）。`file` オペランドとは組み合わせられません。

読めない入力は標準エラーに報告され、実行は次の入力へ続きます。

## OPTIONS

- `-c, --bytes` — バイト数を印字する。
- `-m, --chars` — 文字数を印字する。
- `-l, --lines` — 改行数を印字する。
- `-w, --words` — 単語数を印字する。
- `-L, --max-line-length` — 行の最大表示幅を印字する。
- `--files0-from <file>` — NUL 区切りのオペランド一覧を `file` から読む
  （`-` は標準入力から読む）。
- `--total <when>` — `total` 行を印字する時機。`auto`（既定。入力が複数
  のときだけ）、`always`、`only`（合計だけをラベルなしで）、`never`。
- `-h, -?` — このコマンド自身の短いヘルプを表示する。

## EXAMPLES

- `wc notes.txt` — `notes.txt` の行数・単語数・バイト数を印字する。
- `wc -l a b` — `a` と `b` の行数、そして合計を印字する。
- `wc -L table.txt` — `table.txt` の最も広い行を端末の桁数で印字する。
- `wc -c --total=only a b` — 合算したバイト数だけを印字する。

## EXIT STATUS

- `0` — すべての入力を数えた（または短いヘルプを書いた）。
- `1` — 入力を読めなかった、または出力を届けられなかった。
- `2` — コマンド行を解釈できなかった。

## ENVIRONMENT

- `LANG` — 短いヘルプの優先ロケール（`ja-JP` のような BCP-47 タグ）。
