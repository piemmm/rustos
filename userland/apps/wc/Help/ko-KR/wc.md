## NAME

wc — 각 파일의 줄 바꿈, 단어, 바이트 수 인쇄하기

## SYNOPSIS

`wc [option...] [file...]`

`wc [option...] --files0-from <file>`

## DESCRIPTION

각 `file`의 행 수(줄 바꿈 문자 수), 단어 수, 바이트 수를 세어 한 줄에
파일 이름과 함께 인쇄합니다. `file`이 없거나 `file`이 `-`이면 표준 입력을
읽습니다(피연산자 없는 형식에서는 이름이 인쇄되지 않습니다). 입력이
여럿이면 `--total`의 선택에 따라 마지막 `total` 행이 인쇄됩니다.

선택자 `-l`, `-w`, `-m`, `-c`, `-L`은 어떤 수를 인쇄할지 고릅니다. 아무
것도 없으면 행, 단어, 바이트 수가 인쇄됩니다. 수는 항상 고정된 순서 — 행,
단어, 문자, 바이트, 최대 행 너비 — 로 나타납니다. 단어는 공백이 아닌
문자의 최대 연속입니다. `-m`은 UTF-8 문자를 셉니다(유효한 UTF-8이 아닌
바이트는 바이트로는 세지만 문자로는 세지 않습니다). `-L`은 각 행의 표시
너비를 터미널 열로 재며, 탭은 다음 8의 배수까지 나아갑니다.

`--files0-from <file>`은 NUL로 구분된 피연산자 목록을 `file`에서
읽습니다(`-`는 표준 입력을 뜻합니다). `file` 피연산자와 함께 쓸 수
없습니다.

읽을 수 없는 입력은 표준 오류에 보고되고 실행은 다음 입력으로
계속됩니다.

## OPTIONS

- `-c, --bytes` — 바이트 수를 인쇄합니다.
- `-m, --chars` — 문자 수를 인쇄합니다.
- `-l, --lines` — 줄 바꿈 수를 인쇄합니다.
- `-w, --words` — 단어 수를 인쇄합니다.
- `-L, --max-line-length` — 행의 최대 표시 너비를 인쇄합니다.
- `--files0-from <file>` — NUL로 구분된 피연산자 목록을 `file`에서
  읽습니다(`-`는 표준 입력에서 읽습니다).
- `--total <when>` — `total` 행을 인쇄할 때: `auto`(기본값: 입력이 둘
  이상일 때만), `always`, `only`(합계만, 이름표 없이), `never`.
- `-h, -?` — 이 명령 자체의 짧은 도움말을 표시합니다.

## EXAMPLES

- `wc notes.txt` — `notes.txt`의 행, 단어, 바이트 수를 인쇄합니다.
- `wc -l a b` — `a`와 `b`의 행 수, 그다음 합계를 인쇄합니다.
- `wc -L table.txt` — `table.txt`의 가장 넓은 행을 터미널 열로
  인쇄합니다.
- `wc -c --total=only a b` — 합산된 바이트 수만 인쇄합니다.

## EXIT STATUS

- `0` — 모든 입력을 세었습니다(또는 짧은 도움말을 썼습니다).
- `1` — 입력을 읽을 수 없었거나 출력을 전달할 수 없었습니다.
- `2` — 명령줄을 이해하지 못했습니다.

## ENVIRONMENT

- `LANG` — 짧은 도움말의 선호 로캘(`ko-KR` 같은 BCP-47 태그).
