## NAME

ss — 列出打开的套接字

## SYNOPSIS

`ss [option...]`

## DESCRIPTION

列出系统中打开的套接字，每个套接字一行：传输协议、连接状态、接收与发送
队列的深度、本地与对端的 `address:port`，以及（配合 `-p`）拥有该套接字
的进程。

这些行来自系统信息 API 的套接字清单，网络栈将其作为一次特权且经审计的
查询来应答：它会给出每个主体的套接字以及每个连接的对端，因此列出全部
套接字需要 `CAP_SYSINFO_GLOBAL`。系统没有 `/proc/net`；不具备该能力的
会话会被告知，`ss` 随即退出，而不会打印空表。

默认情况下清单显示已连接、非监听的套接字。`-l` 只显示监听套接字，`-a`
两者都显示；被隐藏的监听者数量记录在标准信息流（fd 3）上，绝不写入表中。
`-t` 与 `-u` 限定协议，`-4`/`-6` 限定地址族；若都不给出，则显示所有协议
与地址族。端口与地址始终为数字（TAIRiX 没有服务名数据库），因此 `-n`
虽被接受但始终生效。未指定的地址打印为 `*`，未绑定的端口打印为 `*`；
IPv6 地址置于方括号内，使 `:port` 分隔符不产生歧义。

`ss` 只接受选项。iproute2 的过滤表达式语法（状态与地址过滤）尚未实现，
因此裸操作数是用法错误，而不是被静默忽略的参数。

## OPTIONS

- `-t, --tcp` — 显示 TCP 套接字。若既无 `-t` 也无 `-u`，则显示两种
  协议。
- `-u, --udp` — 显示 UDP 套接字。
- `-a, --all` — 显示监听与已连接的套接字。
- `-l, --listening` — 只显示监听套接字。
- `-n, --numeric` — 不解析服务名。在 TAIRiX 上始终生效；为熟悉起见而
  接受。
- `-p, --processes` — 增加拥有进程一列（`pid=N`）。
- `-4, --ipv4` — 将清单限定为 IPv4 套接字。
- `-6, --ipv6` — 将清单限定为 IPv6 套接字。
- `-H, --no-header` — 抑制标题行。
- `-?, --help` — 显示本命令自身的简短帮助。

## EXAMPLES

- `ss` — 已连接、非监听的套接字。
- `ss -a` — 每一个套接字，无论监听或已连接。
- `ss -l` — 仅监听套接字。
- `ss -tlp` — 监听中的 TCP 套接字，附拥有进程。
- `ss -u4` — IPv4 上的 UDP 套接字。

## EXIT STATUS

- `0` — 已生成清单（或已写出简短帮助）。
- `1` — 套接字查询被拒绝或失败，或无法写出输出。
- `2` — 未能理解命令行。

## ENVIRONMENT

- `LANG` — 简短帮助所首选的区域设置（形如 `fr-FR` 的 BCP-47 标签）。
