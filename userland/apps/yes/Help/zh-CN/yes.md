## NAME

yes — 反复输出一行文本

## SYNOPSIS

`yes [string...]`

## DESCRIPTION

把它的操作数用单个空格连接后 — 若没有给出则用 `y` — 加上换行符，一遍又一
遍地写出，直到输出不再接受字节（管道被关闭）或进程被终止。它的历史职责是
向提问的命令喂送肯定回答；现代职责是充当廉价的重复文本来源。

选项扫描在第一个操作数处停止，因此 `yes a -x` 打印 `a -x`。位于操作数之前
的未知选项是错误；要打印看起来像选项的字符串，请写 `yes -- -x`。

## OPTIONS

- `-h, -?` — 显示本命令自身的简短帮助。
- `--` — 结束选项解析；之后的每个参数都是操作数。

## EXAMPLES

- `yes` — 打印 `y` 直到被中断。
- `yes hello world` — 打印 `hello world` 直到被中断。
- `yes -- -x` — 打印 `-x`（在 `--` 之后，操作数可以看起来像选项）。

## EXIT STATUS

- `0` — 请求的简短帮助已送达。
- `1` — 输出不再接受字节（本工具唯一的停止条件）。
- `2` — 无法理解命令行。

## ENVIRONMENT

- `LANG` — 简短帮助的首选区域设置（BCP-47 标签，例如 `zh-CN`）。
