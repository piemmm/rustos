## NAME

yes — 一行のテキストを繰り返し出力する

## SYNOPSIS

`yes [string...]`

## DESCRIPTION

オペランドを単一の空白でつないだもの — 何も与えられなければ `y` — に改行を
付けて、出力がバイトを受け付けなくなる（パイプが閉じられる）かプロセスが終
了させられるまで、何度も書き出します。歴史的な役目は、問い合わせてくるコマ
ンドに肯定の答えを与え続けること。現代の役目は、繰り返しテキストの安価な供
給源であることです。

オプションの走査は最初のオペランドで止まるため、`yes a -x` は `a -x` を印
字します。オペランドより前の未知のオプションはエラーです。オプションのよう
に見える文字列を印字するには `yes -- -x` と書きます。

## OPTIONS

- `-h, -?` — このコマンド自身の短いヘルプを表示する。
- `--` — オプション解析を終える。以降のすべての引数はオペランド。

## EXAMPLES

- `yes` — 中断されるまで `y` を印字する。
- `yes hello world` — 中断されるまで `hello world` を印字する。
- `yes -- -x` — `-x` を印字する（`--` の後では、オペランドはオプションの
  ように見えてもよい）。

## EXIT STATUS

- `0` — 要求された短いヘルプを表示した。
- `1` — 出力がバイトを受け付けなくなった（このツール唯一の停止条件）。
- `2` — コマンド行を解釈できなかった。

## ENVIRONMENT

- `LANG` — 短いヘルプの優先ロケール（`ja-JP` のような BCP-47 タグ）。
