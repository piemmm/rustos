## NAME

yes — 한 줄의 텍스트를 반복해서 출력하기

## SYNOPSIS

`yes [string...]`

## DESCRIPTION

피연산자들을 단일 공백으로 이어 — 아무것도 주어지지 않으면 `y`를 — 줄
바꿈과 함께, 출력이 더 이상 바이트를 받지 않거나(닫힌 파이프) 프로세스가
종료될 때까지 계속 써냅니다. 역사적 역할은 물어보는 명령에 긍정의 답을
공급하는 것이고, 현대의 역할은 반복 텍스트의 값싼 공급원이 되는 것입니다.

옵션 스캔은 첫 번째 피연산자에서 멈추므로 `yes a -x`는 `a -x`를
인쇄합니다. 피연산자 앞의 알 수 없는 옵션은 오류입니다. 옵션처럼 보이는
문자열을 인쇄하려면 `yes -- -x`라고 쓰십시오.

## OPTIONS

- `-h, -?` — 이 명령 자체의 짧은 도움말을 표시합니다.
- `--` — 옵션 해석을 끝냅니다. 이후의 모든 인수는 피연산자입니다.

## EXAMPLES

- `yes` — 중단될 때까지 `y`를 인쇄합니다.
- `yes hello world` — 중단될 때까지 `hello world`를 인쇄합니다.
- `yes -- -x` — `-x`를 인쇄합니다(`--` 뒤에서는 피연산자가 옵션처럼
  보여도 됩니다).

## EXIT STATUS

- `0` — 요청된 짧은 도움말이 제공되었습니다.
- `1` — 출력이 더 이상 바이트를 받지 않았습니다(이 도구의 유일한 중지
  조건).
- `2` — 명령줄을 이해하지 못했습니다.

## ENVIRONMENT

- `LANG` — 짧은 도움말의 선호 로캘(`ko-KR` 같은 BCP-47 태그).
