## NAME

sapper — 清扫雷区而不触雷

## SYNOPSIS

`sapper`

## DESCRIPTION

打开一个桌面窗口，其中是一片被覆盖的方格。有些格子下面埋着地雷。每揭开一个不是
地雷的格子，它都会显示自己周围八格中有多少颗雷，仅凭这些数字就足以推断出雷的位
置。把所有非雷格子都揭开即为获胜；揭到一颗雷，本局结束。

你揭开的第一个格子始终安全，它周围的八格也一样，因此开局这一手绝不会输，而且总
能开出一片可供推理的区域。

单击被覆盖的格子将其揭开。用次键单击可插上旗子，再按一次是问号（若已启用），再
按一次则清除标记。插旗的格子受到保护：单击它不会有任何反应。

格子揭开之后，它的数字就能替你干活。若某个数字周围的旗子数量已与它相符，单击它
即可一次揭开其余相邻格。若它周围被覆盖的格子恰好与数字相同，用次键单击即可一次
性全部插旗。中键的作用与主键相同，在格子的任意位置皆可。

左侧计数器显示还剩多少颗雷未找到，即雷数减去已插的旗数；若插旗多于雷数，它会变
为负值。右侧的计时器在你揭开第一个格子时开始，本局结束时停止。两者之间的按钮开
始新的一局，它的表情说明当前这局的结果。

方向键在棋盘上移动一个环。`Space` 揭开环内的格子，若该格已揭开则执行和弦操作。
`F` 标记该格，`Shift+F` 为它所有被覆盖的相邻格插旗，`N` 开始新的一局，`1`、`2`
和 `3` 分别选择初级、中级和高级棋盘。同样的选项以及问号设置都在游戏的图标栏菜单
中。

三种标准棋盘上的最佳时间会在各次会话之间保留。自定义尺寸的棋盘不保留成绩，因为
两个这样的棋盘从来不是同一局游戏。

本游戏可从桌面程序库的 Games 分类启动，也可在 shell 中按名称启动。它需要一个正在
运行的图形会话：没有会话时窗口通道无法访问，游戏会在标准错误流上说明拒绝原因并退
出。

## EXIT STATUS

正常关闭后为零；当窗口通道或共享帧区域被拒绝时为非零（原因会写在标准错误流上）。
