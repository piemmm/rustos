## NAME

sapper — 地雷に触れずに地雷原を片づける

## SYNOPSIS

`sapper`

## DESCRIPTION

伏せられたマスの盤面をもつデスクトップウィンドウを開きます。いくつかのマスには地
雷が隠れています。地雷でないマスを開くと、そのマスは周囲八マスのうち何個が地雷か
を示し、その数字だけで地雷の位置を導けます。地雷でないマスをすべて開けば勝ち、地
雷を開けばそこで終わりです。

最初に開くマスは必ず安全で、その周囲八マスも同様です。したがって初手で負けること
はなく、必ず推理の足がかりとなる領域が開きます。

伏せられたマスをクリックすると開きます。副ボタンでクリックすると旗が立ち、もう一
度で疑問符（有効な場合）、さらにもう一度で印が消えます。旗の立ったマスは保護され
ており、クリックしても何も起きません。

マスが開いたあとは、その数字に働いてもらえます。旗の数がすでに一致している数字を
クリックすると、残りの隣接マスが一度に開きます。伏せられた隣接マスがちょうど数字
と同じ数のときに副ボタンでクリックすると、それらすべてに一度で旗が立ちます。中ボ
タンはマスのどこからでも主ボタンと同じ働きをします。

左のカウンターは、残りの地雷数から立てた旗の数を引いた値を表示します。地雷より多
くの旗を立てると負の値になります。右の時計は最初にマスを開いた時点で動き出し、対
局が終わると止まります。その間のボタンは新しい対局を始め、その表情が現在の対局の
結末を伝えます。

方向キーは盤上のリングを動かします。`Space` はリング内のマスを開き、すでに開いてい
る場合はコードします。`F` はそのマスに印をつけ、`Shift+F` は伏せられた隣接マスすべ
てに旗を立て、`N` は新しい対局を始め、`1`、`2`、`3` は初級・中級・上級の盤面を選び
ます。同じ選択肢と疑問符の設定は、ゲームのアイコンバーメニューにもあります。

三つの標準盤面それぞれの自己最短時間はセッションをまたいで記憶されます。自分で決
めた大きさの盤面は記録を残しません。そのような盤面は二つとして同じ対局にならない
からです。

ゲームはデスクトップのプログラムライブラリの Games から、またはシェルから名前で起
動します。動作中のグラフィカルセッションが必要です。それがない場合はウィンドウチ
ャネルに到達できず、ゲームは標準エラー出力に拒否の理由を示して終了します。

## EXIT STATUS

正常に閉じた場合はゼロ。ウィンドウチャネルまたは共有フレーム領域が拒否された場合
は非ゼロ（理由は標準エラー出力に示されます）。
