## NAME

reset — 터미널을 정상 상태로 복원하기

## SYNOPSIS

`reset`

## DESCRIPTION

충돌한 전체 화면 프로그램이 남길 수 있는 상태를 되돌립니다. 먼저 입력
규율을 대화형 기본값으로 복원합니다(입력한 문자가 다시 에코됩니다). 그런
다음 복원 시퀀스를 씁니다. 대체 화면에서 나오고, 커서를 표시하고, 색과
속성을 재설정하고, 스크롤 영역을 재설정하고, 마지막으로 커서를 홈으로
옮기고 표시를 지웁니다.

어떤 조작을 쓸지는 `TERM`에 지정된 터미널이 결정합니다. 터미널이 이해하지
못하는 조작은 생략됩니다. 아무 제어 수단도 없는 터미널(알 수 없는 `TERM`은
「dumb」 기준선으로 격하됩니다)은 입력 규율 복원만 받습니다.

## OPTIONS

- `-h, -?` — 이 명령 자체의 짧은 도움말을 표시합니다.

## EXAMPLES

- `reset` — 전체 화면 프로그램이 충돌한 뒤 터미널을 복원합니다.

## EXIT STATUS

- `0` — 터미널이 복원되었습니다.
- `1` — 출력을 전달할 수 없었습니다.
- `2` — 명령줄을 이해하지 못했습니다.

## ENVIRONMENT

- `TERM` — 그 복원 시퀀스를 쓰는 터미널.
- `LANG` — 짧은 도움말의 선호 로캘(`ko-KR` 같은 BCP-47 태그).
