## NAME

reset — повернути термінал до нормального стану

## SYNOPSIS

`reset`

## DESCRIPTION

Скасовує стан, який може залишити по собі повноекранна програма, що
аварійно завершилася. Спершу дисципліна введення повертається до
інтерактивного усталеного значення (набрані символи знову видно).
Потім записується послідовність відновлення: вийти з альтернативного
екрана, показати курсор, скинути кольори й атрибути, скинути область
прокручування і, нарешті, перемістити курсор у верхній лівий кут та
стерти екран.

Які операції буде записано, визначає термінал, названий у `TERM`;
операція, якої термінал не розуміє, пропускається. Термінал зовсім без
керування (невідомий `TERM` знижується до мінімального профілю)
отримує лише відновлення дисципліни введення.

## OPTIONS

- `-h, -?` — показати коротку довідку цієї команди.

## EXAMPLES

- `reset` — відновити термінал після аварії повноекранної програми.

## EXIT STATUS

- `0` — термінал відновлено.
- `1` — вивід не вдалося доставити.
- `2` — командний рядок не зрозуміло.

## ENVIRONMENT

- `TERM` — термінал, чию послідовність відновлення буде записано.
- `LANG` — бажана локаль для короткої довідки (позначка BCP-47, як-от
  `uk-UA`).
