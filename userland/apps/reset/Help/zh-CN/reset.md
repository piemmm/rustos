## NAME

reset — 把终端恢复到正常状态

## SYNOPSIS

`reset`

## DESCRIPTION

撤销崩溃的全屏程序可能留下的状态。首先把输入规程恢复为交互式默认值（键入
的字符重新回显）。然后写出恢复序列：离开备用屏幕、显示光标、重置颜色与属
性、重置滚动区域，最后把光标移回原位并擦除显示。

写出哪些操作由 `TERM` 命名的终端决定；终端不理解的操作会被省略。完全没有
控制序列的终端（未知的 `TERM` 会退化为「dumb」基线）只得到输入规程的恢复。

## OPTIONS

- `-h, -?` — 显示本命令自身的简短帮助。

## EXAMPLES

- `reset` — 在全屏程序崩溃后恢复终端。

## EXIT STATUS

- `0` — 终端已恢复。
- `1` — 输出无法送达。
- `2` — 无法理解命令行。

## ENVIRONMENT

- `TERM` — 写出其恢复序列的终端。
- `LANG` — 简短帮助的首选区域设置（BCP-47 标签，例如 `zh-CN`）。
