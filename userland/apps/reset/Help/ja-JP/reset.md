## NAME

reset — 端末を正常な状態に戻す

## SYNOPSIS

`reset`

## DESCRIPTION

クラッシュした全画面プログラムが残しうる状態を元に戻します。まず入力の規律
を対話的な既定値へ戻します（打鍵した文字が再びエコーされます）。次に復元
シーケンスを書き出します。代替画面を離れ、カーソルを表示し、色と属性をリ
セットし、スクロール領域をリセットし、最後にカーソルをホームへ移動して表示
を消去します。

どの操作を書き出すかは `TERM` に指定された端末が決めます。端末が理解しない
操作は省かれます。制御手段をまったく持たない端末（未知の `TERM` は「dumb」
の基準線に格下げされます）には、入力規律の復元だけが行われます。

## OPTIONS

- `-h, -?` — このコマンド自身の短いヘルプを表示する。

## EXAMPLES

- `reset` — 全画面プログラムがクラッシュした後に端末を復元する。

## EXIT STATUS

- `0` — 端末を復元した。
- `1` — 出力を届けられなかった。
- `2` — コマンド行を解釈できなかった。

## ENVIRONMENT

- `TERM` — その復元シーケンスを書き出す端末。
- `LANG` — 短いヘルプの優先ロケール（`ja-JP` のような BCP-47 タグ）。
