## NAME

sleep — 時間間隔の合計だけ一時停止する

## SYNOPSIS

`sleep NUMBER[SUFFIX]...`

## DESCRIPTION

指定した間隔の合計だけ一時停止し、その後終了します。

各 `NUMBER` は浮動小数点値で、1 文字の `SUFFIX` がそれを拡大します。`s`
は秒（既定）、`m` は分、`h` は時間、`d` は日です。複数のオペランドは
加算されるため、`sleep 1m 30s` は 90 秒間一時停止します。`inf`（または
`infinity`）はプロセスが終了させられるまで一時停止します。

シェル自身の計時とは異なり、`sleep` はプロセッサの外で眠ります。タスクは
間隔が経過するまで待避され、コアを空回りさせることは決してありません。

負の値、`nan`、未知のサフィックス、または数値の後の余分な文字は
`invalid time interval` です。オペランドを一切与えないのは
`missing operand` です。

このコマンドはシステムのバージョンを表示しません。TAIRiX にはそのような
文字列がないため、GNU `sleep` とは異なり `--version` オプションは
ありません。

## OPTIONS

- `-h, -?` — このコマンド自身の短いヘルプを表示する。
- `--` — オプションの解析を終了する。以降の引数はすべてオペランド。

## EXAMPLES

- `sleep 5` — 5 秒間一時停止する。
- `sleep 1.5h` — 90 分間一時停止する。
- `sleep 1m 30s` — 90 秒間一時停止する（オペランドは加算される）。
- `sleep inf` — プロセスが終了させられるまで一時停止する。

## EXIT STATUS

- `0` — 間隔が経過した、または要求された短いヘルプが書き出された。
- `1` — 短いヘルプの書き出しに失敗した。
- `2` — コマンド行を理解できなかった（未知のオプション、オペランドの
  欠落、または無効な時間間隔）。

## ENVIRONMENT

- `LANG` — 短いヘルプの優先ロケール（`fr-FR` のような BCP-47 タグ）。
