## NAME

df — звітувати про використання простору файловими системами

## SYNOPSIS

`df [option...] [file...]`

## DESCRIPTION

Звітує, один рядок на змонтовану файлову систему, про розмір тому,
використаний простір, доступний простір, відсоток використання та
точку монтування. З операндами `file` натомість звітує про файлову
систему, що містить кожен операнд (один рядок на файлову систему,
скільки б операндів вона не покривала).

Числа походять зі списку монтувань API системної інформації, як
кожен драйвер змонтованої файлової системи повідомляє власний облік.
Типово звіт приховує монтування без власної місткості (синтетичні
прив'язки подання системи) та додаткові монтування вже переліченого
тому; `-a` показує все, а кількість прихованих записів занотовується
у стандартний інформаційний потік (fd 3), ніколи в таблицю.

Розміри друкуються в блоках по 1024 байти, якщо параметр одиниці не
вибере інше; пізніший параметр одиниці замінює попередній, а
кількість блоків округлюється вгору. Файлова система, чий формат
виділяє інодi на вимогу, звітує нульові показники інодiв з `-i` —
чесна відповідь «не відстежується».

Операнд `file`, що не існує або є відносним шляхом (точки монтування
абсолютні; `df` ніколи не вгадує розв'язання), повідомляється в
стандартний потік помилок, і звіт триває з рештою. Параметри GNU
`--output`, `--sync` і `--no-sync` ще не доступні.

## OPTIONS

- `-a, --all` — включити безмісткісні та дубльовані монтування, які
  типово приховуються.
- `-T, --print-type` — додати стовпець типу файлової системи.
- `-t, --type <type>` — звітувати лише про файлові системи типу
  `type` (повторюване).
- `-x, --exclude-type <type>` — пропустити файлові системи типу
  `type` (повторюване).
- `-i, --inodes` — звітувати про кількість інодiв замість
  використання блоків.
- `-P, --portability` — переносний формат POSIX (заголовки
  `1024-blocks` і `Capacity`).
- `-l, --local` — обмежити звіт локальними файловими системами
  (сьогодні кожне монтування TAIRiX: нічого не відфільтровується).
- `--total` — додати рядок з позначкою `total`, що підсумовує
  показані числа.
- `-k` — блоки по 1024 байти (типово).
- `-h, --human-readable` — зручні розміри в степенях 1024 (`1.0K`,
  `23M`).
- `-H, --si` — зручні розміри в степенях 1000 (`1.0k`, `23M`).
- `-B, --block-size <size>` — звітувати в блоках по `size` байтів
  (`512`, `1K`, `1MiB`, `1GB`, `human-readable`, `si`).
- `-?, --help` — показати коротку довідку цієї команди.

## EXAMPLES

- `df` — використання кожного справжнього тому в блоках по 1024
  байти.
- `df -h` — те саме, у зручних розмірах.
- `df /Users/jo` — файлова система, що містить `/Users/jo`.
- `df -aT` — кожне монтування з типом файлової системи.
- `df --total -k` — томи плюс підсумковий рядок `total`.

## EXIT STATUS

- `0` — звіт покрив усе запитане (або надруковано коротку довідку).
- `1` — про операнд не вдалося звітувати, фільтри нічого не
  залишили, або запит чи вивід не вдалися.
- `2` — командний рядок не зрозуміло.

## ENVIRONMENT

- `LANG` — бажана мова короткої довідки (тег BCP-47, як-от
  `fr-FR`).
