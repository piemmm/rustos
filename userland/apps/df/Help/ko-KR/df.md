## NAME

df — 파일시스템의 공간 사용량 보고

## SYNOPSIS

`df [option...] [file...]`

## DESCRIPTION

마운트된 파일시스템마다 한 행으로 볼륨 크기, 사용된 공간, 사용 가능한
공간, 사용률, 마운트 지점을 보고한다. `file` 피연산자가 있으면 대신
각 피연산자를 담고 있는 파일시스템을 보고한다(피연산자를 몇 개
포함하든 파일시스템마다 한 행).

수치는 시스템 정보 API의 마운트 목록에서 오며, 마운트된 각 파일시스템
드라이버가 자신의 회계를 보고한 값이다. 기본적으로 보고서는 자체
용량이 없는 마운트(시스템의 합성 보기 바인딩)와 이미 나열된 볼륨의
추가 마운트를 숨긴다. `-a`는 전부 보여 주며, 숨겨진 수는 표준 정보
스트림(fd 3)에 기록될 뿐 표에는 결코 들어가지 않는다.

크기는 단위 옵션이 달리 선택하지 않는 한 1024바이트 블록으로 출력되고,
나중의 단위 옵션이 앞의 것을 대체하며, 블록 수는 올림된다. inode를
필요할 때 할당하는 형식의 파일시스템은 `-i`에서 0의 inode 수치를
보고한다 — 정직한 「추적되지 않음」의 답이다.

존재하지 않는 `file` 피연산자나 상대 경로 피연산자(마운트 지점은
절대 경로이며 `df`는 해석을 추측하지 않는다)는 표준 오류로 보고되고
보고서는 나머지를 계속한다. GNU의 `--output`, `--sync`, `--no-sync`
옵션은 아직 사용할 수 없다.

## OPTIONS

- `-a, --all` — 기본값이 숨기는 용량 없는·중복 마운트도 포함한다.
- `-T, --print-type` — 파일시스템 유형 열을 추가한다.
- `-t, --type <type>` — `type` 유형의 파일시스템만 보고한다(반복
  가능).
- `-x, --exclude-type <type>` — `type` 유형의 파일시스템을
  생략한다(반복 가능).
- `-i, --inodes` — 블록 사용량 대신 inode 수를 보고한다.
- `-P, --portability` — POSIX 이식 형식(`1024-blocks`와 `Capacity`
  머리글).
- `-l, --local` — 보고를 로컬 파일시스템으로 제한한다(오늘의 TAIRiX
  마운트는 모두 로컬이므로 아무것도 걸러지지 않는다).
- `--total` — 표시된 수치를 합산하는 `total` 행을 덧붙인다.
- `-k` — 1024바이트 블록(기본값).
- `-h, --human-readable` — 1024의 거듭제곱으로 읽기 쉬운 크기
  (`1.0K`, `23M`).
- `-H, --si` — 1000의 거듭제곱으로 읽기 쉬운 크기(`1.0k`, `23M`).
- `-B, --block-size <size>` — `size`바이트 블록으로 보고한다
  (`512`, `1K`, `1MiB`, `1GB`, `human-readable`, `si`).
- `-?, --help` — 이 명령 자체의 짧은 도움말을 표시한다.

## EXAMPLES

- `df` — 모든 실제 볼륨의 사용량을 1024바이트 블록으로.
- `df -h` — 같은 내용을 읽기 쉬운 크기로.
- `df /Users/jo` — `/Users/jo`를 담고 있는 파일시스템.
- `df -aT` — 모든 마운트를 파일시스템 유형과 함께.
- `df --total -k` — 볼륨들과 합산된 `total` 행.

## EXIT STATUS

- `0` — 요청된 모든 것을 보고했다(또는 짧은 도움말을 출력했다).
- `1` — 피연산자를 보고할 수 없었거나, 필터가 아무것도 남기지
  않았거나, 질의나 출력이 실패했다.
- `2` — 명령줄을 이해할 수 없었다.

## ENVIRONMENT

- `LANG` — 짧은 도움말의 선호 로캘(`fr-FR` 같은 BCP-47 태그).
