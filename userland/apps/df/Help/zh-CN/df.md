## NAME

df — 报告文件系统的空间使用情况

## SYNOPSIS

`df [option...] [file...]`

## DESCRIPTION

每个已挂载文件系统一行，报告卷的大小、已用空间、可用空间、使用百分
比和挂载点。带 `file` 操作数时，改为报告包含各操作数的文件系统（无
论覆盖多少个操作数，每个文件系统一行）。

数字来自系统信息 API 的挂载列表，即每个已挂载文件系统驱动报告的自
身记账。默认情况下，报告隐藏没有自身容量的挂载（系统的合成视图绑
定）以及已列出卷的额外挂载；`-a` 显示全部，被隐藏的数量记录在标准
信息流（fd 3）中，绝不进入表格。

除非单位选项另有选择，大小以 1024 字节块打印；后面的单位选项覆盖前
面的，块数向上取整。按需分配 inode 的文件系统在 `-i` 下报告为零的
inode 数字——诚实的「未跟踪」回答。

不存在的 `file` 操作数或相对路径操作数（挂载点是绝对路径；`df` 绝
不猜测解析）会报告到标准错误，报告继续处理其余部分。GNU 的
`--output`、`--sync` 和 `--no-sync` 选项尚不可用。

## OPTIONS

- `-a, --all` — 包含默认隐藏的无容量和重复挂载。
- `-T, --print-type` — 添加文件系统类型列。
- `-t, --type <type>` — 只报告类型为 `type` 的文件系统（可重复）。
- `-x, --exclude-type <type>` — 省略类型为 `type` 的文件系统（可重
  复）。
- `-i, --inodes` — 报告 inode 数量而不是块使用量。
- `-P, --portability` — POSIX 可移植格式（`1024-blocks` 和
  `Capacity` 表头）。
- `-l, --local` — 将报告限制为本地文件系统（今天 TAIRiX 的所有挂载
  都是本地的，因此不会过滤任何内容）。
- `--total` — 追加一行标记为 `total` 的合计。
- `-k` — 1024 字节块（默认）。
- `-h, --human-readable` — 以 1024 的幂显示易读大小（`1.0K`、
  `23M`）。
- `-H, --si` — 以 1000 的幂显示易读大小（`1.0k`、`23M`）。
- `-B, --block-size <size>` — 以 `size` 字节的块报告（`512`、
  `1K`、`1MiB`、`1GB`、`human-readable`、`si`）。
- `-?, --help` — 显示本命令自身的简短帮助。

## EXAMPLES

- `df` — 每个真实卷的使用量，以 1024 字节块表示。
- `df -h` — 相同内容，以易读大小表示。
- `df /Users/jo` — 包含 `/Users/jo` 的文件系统。
- `df -aT` — 每个挂载及其文件系统类型。
- `df --total -k` — 各卷加上一行合计的 `total`。

## EXIT STATUS

- `0` — 报告覆盖了所有请求的内容（或已写出简短帮助）。
- `1` — 无法报告某个操作数、过滤器未留下任何内容，或查询/输出失
  败。
- `2` — 无法理解命令行。

## ENVIRONMENT

- `LANG` — 简短帮助的首选语言（BCP-47 标签，如 `fr-FR`）。
