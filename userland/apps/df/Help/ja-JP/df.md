## NAME

df — ファイルシステムの領域使用量を報告する

## SYNOPSIS

`df [option...] [file...]`

## DESCRIPTION

マウントされたファイルシステムごとに 1 行で、ボリュームの大きさ、使用
済み領域、利用可能領域、使用率、マウントポイントを報告する。`file`
オペランドがあれば、代わりに各オペランドを含むファイルシステムを報告
する（いくつのオペランドを覆っていても、ファイルシステムごとに 1 行）。

数値はシステム情報 API のマウント一覧に由来し、マウントされた各ファイ
ルシステムドライバーが自身の会計を報告したものである。既定では、自身
の容量を持たないマウント（システムの合成ビュー結合）と、既に一覧され
たボリュームの追加マウントを隠す。`-a` はすべてを表示し、隠された数は
標準情報ストリーム（fd 3）に記され、表には決して入らない。

サイズは単位オプションが別を選ばない限り 1024 バイトブロックで印字さ
れ、後の単位オプションが先のものを上書きし、ブロック数は切り上げられ
る。inode を必要に応じて割り当てる形式のファイルシステムは `-i` でゼ
ロの inode 数値を報告する——正直な「未追跡」の答えである。

存在しない `file` オペランドや相対パスのオペランド（マウントポイント
は絶対パスであり、`df` は解決を推測しない）は標準エラーに報告され、
報告は残りを続ける。GNU の `--output`、`--sync`、`--no-sync` オプショ
ンはまだ利用できない。

## OPTIONS

- `-a, --all` — 既定で隠される容量なし・重複のマウントも含める。
- `-T, --print-type` — ファイルシステム種別の列を追加する。
- `-t, --type <type>` — 種別 `type` のファイルシステムのみ報告する
  （繰り返し可能）。
- `-x, --exclude-type <type>` — 種別 `type` のファイルシステムを省く
  （繰り返し可能）。
- `-i, --inodes` — ブロック使用量の代わりに inode 数を報告する。
- `-P, --portability` — POSIX の可搬形式（`1024-blocks` と
  `Capacity` の見出し）。
- `-l, --local` — 報告をローカルなファイルシステムに限る（今日の
  RustOS のマウントはすべてローカルであり、何も除外されない）。
- `--total` — 表示された数値を合計する `total` の行を追加する。
- `-k` — 1024 バイトブロック（既定）。
- `-h, --human-readable` — 1024 の累乗で読みやすいサイズ（`1.0K`、
  `23M`）。
- `-H, --si` — 1000 の累乗で読みやすいサイズ（`1.0k`、`23M`）。
- `-B, --block-size <size>` — `size` バイトのブロックで報告する
  （`512`、`1K`、`1MiB`、`1GB`、`human-readable`、`si`）。
- `-?, --help` — このコマンド自身の短いヘルプを表示する。

## EXAMPLES

- `df` — すべての実ボリュームの使用量を 1024 バイトブロックで。
- `df -h` — 同じ内容を読みやすいサイズで。
- `df /Users/jo` — `/Users/jo` を含むファイルシステム。
- `df -aT` — すべてのマウントを、その種別とともに。
- `df --total -k` — ボリュームと、合計の `total` 行。

## EXIT STATUS

- `0` — 求められたすべてを報告した（または短いヘルプを書いた）。
- `1` — オペランドを報告できなかった、フィルタが何も残さなかった、
  または照会か出力が失敗した。
- `2` — コマンド行を理解できなかった。

## ENVIRONMENT

- `LANG` — 短いヘルプの優先ロケール（`fr-FR` のような BCP-47 タグ）。
