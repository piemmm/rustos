## NAME

viewer — 그래픽 읽기 전용 파일 뷰어

## SYNOPSIS

`viewer`

## DESCRIPTION

데스크톱 창을 열고 곧바로 데스크톱 세션의 신뢰된 파일 선택기에 파일
선택을 요청합니다. 뷰어 자체는 파일 시스템 권한을 전혀 갖지 않으며,
스스로는 아무것도 열거나 나열하거나 읽을 수 없습니다. 세션이 뷰어를
대신해 자신의 권한으로 탐색하고, 사용자가 고른 단 하나의 파일만이
일회성·읽기 전용으로 뷰어에 위임됩니다.

선택된 파일의 내용은 창 상단부터 일반 텍스트로 표시됩니다. 인쇄
가능한 문자는 그대로 표시되고, 그 밖의 모든 바이트는 점으로
표시됩니다. 따라서 바이너리 내용은 명백히 정리된 상태로 읽힙니다.
표시되는 내용은 파일의 앞부분으로 제한됩니다.

창은 마우스로 구동됩니다. 헤더의 **Open…** (열기…) 버튼을 클릭하여
다른 파일을 요청하십시오. 스크롤바의 썸을 위아래로 드래그하여 긴 파일을
이동하고, 썸 위나 아래의 트랙을 클릭하여 페이지 단위로 이동하거나, 끝
버튼을 클릭하여 한 줄씩 이동하거나, 창 위에서 휠을 돌려 스크롤하십시오.
선택기를 취소하면 알림과 함께 뷰어가 열린 상태로 남습니다. 데스크톱에서
창을 닫으면 뷰어가 종료됩니다.

키보드는 동일한 동작을 위한 보조 경로입니다. `Enter` 는 다른 파일을
요청하고, 화살표 키는 한 줄씩 이동하며, Page Up/Page Down 은 한 페이지씩
이동하고, Home/End 는 맨 위나 맨 아래로 점프합니다.

## EXIT STATUS

정상 종료 후에는 0. 창 채널이나 공유 프레임 영역이 거부되면 0이 아닌
값(이유는 표준 오류 스트림에 출력됩니다)。
