## NAME

viewer — графічний переглядач файлів лише для читання

## SYNOPSIS

`viewer`

## DESCRIPTION

Відкриває вікно стільниці й одразу просить довірений вибір файлів
сеансу стільниці обрати файл. Переглядач не має жодних прав на
файлову систему: самостійно він нічого не може відкрити, перелічити
чи прочитати. Сеанс переглядає файли від імені переглядача під своєю
власною ідентичністю, і лише один обраний користувачем файл
делегується переглядачеві — одноразово й лише для читання.

Вміст обраного файлу показується як простий текст від верхнього краю
вікна. Друковані символи показуються як є; кожен інший байт
зображується крапкою. Показаний вміст обмежено початком файлу.

Натисніть `Enter`, щоб попросити інший файл. Скасування вибору
залишає переглядач відкритим із повідомленням. Закриття вікна зі
стільниці завершує переглядач.

## EXIT STATUS

Нуль після чистого закриття; ненульове значення, коли канал вікна або
спільна ділянка кадрів були відхилені (причину зазначено в
стандартному потоці помилок).
