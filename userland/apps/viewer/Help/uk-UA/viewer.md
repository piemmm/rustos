## NAME

viewer — графічний переглядач файлів лише для читання

## SYNOPSIS

`viewer`

## DESCRIPTION

Відкриває вікно стільниці й одразу просить довірений вибір файлів
сеансу стільниці обрати файл. Переглядач не має жодних прав на
файлову систему: самостійно він нічого не може відкрити, перелічити
чи прочитати. Сеанс переглядає файли від імені переглядача під своєю
власною ідентичністю, і лише один обраний користувачем файл
делегується переглядачеві — одноразово й лише для читання.

Вміст обраного файлу показується як простий текст від верхнього краю
вікна. Друковані символи показуються як є; кожен інший байт
зображується крапкою, тому бінарний вміст виглядає явно санованим.
Показаний вміст обмежено початком файлу.

Керування вікном здійснюється за допомогою миші. Натисніть кнопку
**Open…** (Відкрити…) у заголовку, щоб попросити інший файл.
Перетягуйте повзунок смуги прокручування вгору або вниз, щоб
переміщатися довгим файлом, клацайте на доріжці вище або нижче
повзунка, щоб гортати сторінки, натискайте кнопки на кінцях, щоб
переходити на один рядок, або крутіть коліщатко над вікном для
прокручування. Скасування вибору залишає переглядач відкритим із
повідомленням; закриття вікна зі стільниці завершує переглядач.

Клавіатура є допоміжним шляхом для тих самих дій: `Enter` просить
інший файл, клавіші зі стрілками переходять на рядок, Page Up/Page Down
переходять на сторінку, а Home/End переходять до початку або кінця.
