## NAME

rm — 删除文件和目录

## SYNOPSIS

`rm [-dfiIrRv] [--] file...`

## DESCRIPTION

按顺序删除每个文件操作数。非目录操作数被解除链接；目录操作数只有带 `-r`
（先深度优先删除其内容，再删除目录本身）或在其为空时带 `-d` 才被删除。

带 `-f` 时，不存在的操作数被静默跳过，且从不发问。`-i` 在每次删除前和进入
目录前在标准错误流上询问；`-I` 在删除多于三个操作数或递归删除之前先问一
次。被拒绝的询问无错误地跳过该对象（对 `-I` 则跳过整次运行）；无法读取的
回答绝不被当作同意。`-f`、`-i` 和 `-I` 以最后者为准。

在 `--preserve-root`（默认）下操作数 `/` 被拒绝。第一个失败会在任何后续操
作数之前停止运行。`--` 结束选项解析：之后的每个参数都是路径。

## OPTIONS

- `-r, -R, --recursive` — 删除目录及其内容。
- `-f, --force` — 忽略不存在的操作数；从不询问。
- `-d, --dir` — 删除空目录。
- `-i, --interactive` — 每次删除前询问；只有以 `y`/`Y` 开头的回答才算同
  意。
- `-I` — 在删除多于三个操作数或递归删除之前问一次。
- `-v, --verbose` — 以 `removed 'file'` 报告每次删除。
- `--preserve-root` — 拒绝删除 `/`（默认）。
- `--no-preserve-root` — 允许删除 `/`。
- `-h, -?, --help` — 显示本命令自身的简短帮助。

## EXAMPLES

- `rm notes.txt` — 删除一个文件。
- `rm -r Scratch` — 删除 `Scratch` 树及其中的一切。
- `rm -I a b c d` — 问一次，回答 `y` 后删除全部四个文件。

## EXIT STATUS

- `0` — 每次删除都成功（被拒绝的询问和 `-f` 的跳过不算失败）。
- `1` — 文件系统、询问或输出失败；原因打印在标准错误上。
- `2` — 无法理解命令行。

## ENVIRONMENT

- `LANG` — 简短帮助的首选区域设置（BCP-47 标签，例如 `zh-CN`）。
