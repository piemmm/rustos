## NAME

rm — 파일과 디렉터리 제거하기

## SYNOPSIS

`rm [-dfiIrRv] [--] file...`

## DESCRIPTION

각 파일 피연산자를 순서대로 제거합니다. 디렉터리가 아닌 피연산자는 연결
해제됩니다. 디렉터리 피연산자는 `-r`(내용을 깊이 우선으로 제거한 뒤
디렉터리 자체를 제거)이 있을 때만, 또는 비어 있을 때 `-d`가 있으면
제거됩니다.

`-f`가 있으면 존재하지 않는 피연산자는 조용히 건너뛰고 어떤 질문도 하지
않습니다. `-i`는 매 제거 전과 디렉터리로 내려가기 전에 표준 오류
스트림에서 물어봅니다. `-I`는 셋보다 많은 피연산자를 제거하기 전이나 재귀
제거 전에 처음에 한 번 물어봅니다. 거절된 질문은 그 대상(`-I`에서는 실행
전체)을 오류 없이 건너뜁니다. 읽을 수 없는 대답은 결코 동의로 취급되지
않습니다. `-f`, `-i`, `-I` 중 마지막 것이 이깁니다.

기본값인 `--preserve-root`에서는 피연산자 `/`가 거부됩니다. 첫 실패가
이후의 피연산자로 가기 전에 실행을 멈춥니다. `--`는 옵션 해석을 끝내며,
이후의 모든 인수는 경로입니다.

## OPTIONS

- `-r, -R, --recursive` — 디렉터리와 그 내용을 제거합니다.
- `-f, --force` — 존재하지 않는 피연산자를 무시합니다. 결코 묻지
  않습니다.
- `-d, --dir` — 빈 디렉터리를 제거합니다.
- `-i, --interactive` — 매 제거 전에 물어봅니다. `y`/`Y`로 시작하는
  대답만 동의합니다.
- `-I` — 셋보다 많은 피연산자를 제거하기 전이나 재귀 제거 전에 한 번
  물어봅니다.
- `-v, --verbose` — 각 제거를 `removed 'file'`로 보고합니다.
- `--preserve-root` — `/` 제거를 거부합니다(기본값).
- `--no-preserve-root` — `/` 제거를 허용합니다.
- `-h, -?, --help` — 이 명령 자체의 짧은 도움말을 표시합니다.

## EXAMPLES

- `rm notes.txt` — 파일 하나를 제거합니다.
- `rm -r Scratch` — `Scratch` 트리와 그 안의 모든 것을 제거합니다.
- `rm -I a b c d` — 한 번 물어본 뒤 `y`에 네 파일을 모두 제거합니다.

## EXIT STATUS

- `0` — 모든 제거가 성공했습니다(거절된 질문과 `-f`의 건너뜀은 실패가
  아닙니다).
- `1` — 파일 시스템, 질문 또는 출력 실패. 이유가 표준 오류에
  인쇄됩니다.
- `2` — 명령줄을 이해하지 못했습니다.

## ENVIRONMENT

- `LANG` — 짧은 도움말의 선호 로캘(`ko-KR` 같은 BCP-47 태그).
