## NAME

rm — ファイルとディレクトリを削除する

## SYNOPSIS

`rm [-dfiIrRv] [--] file...`

## DESCRIPTION

各ファイルオペランドを順に削除します。ディレクトリでないオペランドはアン
リンクされます。ディレクトリオペランドは `-r`（中身を深さ優先で削除して
からディレクトリ自体を削除）があるとき、または空なら `-d` があるときだけ
削除されます。

`-f` があれば、存在しないオペランドは静かに飛ばされ、質問は決してされま
せん。`-i` は各削除の前とディレクトリへ降りる前に標準エラーストリーム上
で尋ねます。`-I` は三つを超えるオペランドを削除する前、または再帰的な削
除の前に、最初に一度だけ尋ねます。断られた質問はその対象（`-I` なら実行
全体）をエラーなしで飛ばします。読めない返答が同意として扱われることは決
してありません。`-f`、`-i`、`-I` は最後に書かれたものが勝ちます。

オペランド `/` は既定の `--preserve-root` の下では拒否されます。最初の失
敗で、後続のオペランドに移る前に実行が止まります。`--` はオプション解析
を終え、以降のすべての引数はパスです。

## OPTIONS

- `-r, -R, --recursive` — ディレクトリとその中身を削除する。
- `-f, --force` — 存在しないオペランドを無視する。決して尋ねない。
- `-d, --dir` — 空のディレクトリを削除する。
- `-i, --interactive` — 各削除の前に尋ねる。`y`/`Y` で始まる返答だけが同
  意。
- `-I` — 三つを超えるオペランドの削除前、または再帰削除の前に一度だけ尋
  ねる。
- `-v, --verbose` — 各削除を `removed 'file'` の形で報告する。
- `--preserve-root` — `/` の削除を拒む（既定）。
- `--no-preserve-root` — `/` の削除を許す。
- `-h, -?, --help` — このコマンド自身の短いヘルプを表示する。

## EXAMPLES

- `rm notes.txt` — ファイルを一つ削除する。
- `rm -r Scratch` — `Scratch` の木とその中のすべてを削除する。
- `rm -I a b c d` — 一度尋ね、`y` で四つのファイルすべてを削除する。

## EXIT STATUS

- `0` — すべての削除が成功した（断られた質問と `-f` による飛ばしは失敗で
  はない）。
- `1` — ファイルシステム・問いかけ・出力の失敗。理由は標準エラーに印字さ
  れる。
- `2` — コマンド行を解釈できなかった。

## ENVIRONMENT

- `LANG` — 短いヘルプの優先ロケール（`ja-JP` のような BCP-47 タグ）。
