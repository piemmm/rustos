## NAME

printf — 데이터를 서식화하여 출력

## SYNOPSIS

`printf format [argument...]`

## DESCRIPTION

C의 `printf` 함수처럼 `format`의 제어 아래 각 `argument`를 출력합니다.
서식은 세 가지 요소를 담습니다. 표준 출력으로 그대로 복사되는 일반
문자, 백슬래시 이스케이프, 그리고 다음 인수를 변환하는 `%` 변환
지시자입니다.

이스케이프는 `\a`(경고음), `\b`(백스페이스), `\c`(모든 출력 즉시
종료), `\e`(이스케이프), `\f`(폼 피드), `\n`(줄바꿈), `\r`(캐리지
리턴), `\t`(탭), `\v`(수직 탭), `\\`, `\"`, `\NNN`(팔진 숫자 한 개
에서 세 개), `\xHH`(십육진 숫자 한 개 또는 두 개), 그리고 `\uHHHH` /
`\UHHHHHHHH`(유니코드 코드 포인트, 십육진 숫자 네 개 또는 여덟
개)입니다.

변환은 `%d`/`%i`(부호 있는 십진), `%u`(부호 없는 십진), `%o`/`%x`/
`%X`(팔진과 십육진), `%e`/`%E`/`%f`/`%F`/`%g`/`%G`/`%a`/`%A`(부동
소수점), `%c`(인수의 첫 문자), `%s`(문자열), `%b`(자체 이스케이프가
해석되는 문자열, 팔진은 `\0NNN`으로 표기), `%q`(셸 입력으로 재사용할
수 있게 인용된 문자열), `%%`(문자 그대로의 `%`)입니다. 지시자는 C
플래그 `-`, `+`, 공백, `#`, `0`, `'`와 필드 너비, 정밀도를 받습니다.
너비와 정밀도는 각각 `*`로 쓸 수 있으며 다음 인수에서 값을 읽습니다.
`%b`와 `%q`는 플래그, 너비, 정밀도를 받지 않습니다.

서식은 모든 인수를 소비할 때까지 필요한 만큼 재사용됩니다. 남은
인수가 없는 변환은 0 또는 빈 문자열을 출력합니다. 숫자 인수는 C
숫자처럼 읽힙니다(`0x` 십육진, 앞자리 `0` 팔진, 부동 소수점, `inf`,
`nan`). 앞의 `'` 또는 `"`는 다음 문자의 코드 포인트로 변환합니다.
숫자가 아니거나, 일부만 숫자이거나, 범위를 벗어난 인수는 표준 오류에
진단되고 가능한 데까지 변환됩니다 — 실행은 계속되고 상태 `1`로
끝납니다. 알 수 없는 변환, 받지 않는 변환에 붙인 플래그, 잘못된
이스케이프는 진단과 함께 실행을 끝냅니다.

GNU `printf`와의 의도적 차이 두 가지: 부동 소수점은 IEEE 754 배정도로
계산되므로(GNU는 `long double` 사용) double 범위를 넘는 값은 `inf`로
출력됩니다. 또한 *첫* 인수가 `-h`나 `-?`이면 이 짧은 도움말을
표시합니다 — 그런 서식은 `printf -- -h...`로 쓰십시오.

## OPTIONS

- `-h, -?` — 이 명령 자체의 짧은 도움말을 표시(첫 인수로만).
- `--` — 옵션 해석을 끝냄. 다음 인수가 서식이 됨.

## EXAMPLES

- `printf '%s\n' hello` — `hello`와 줄바꿈을 출력.
- `printf '%d\n' 0x10` — `16`을 출력.
- `printf '%5.2f|\n' 3.14159` — ` 3.14|`를 출력.
- `printf '%s=%q\n' greeting 'hi there'` — `greeting='hi there'`를
  출력.
- `printf '%b' 'one\ntwo\n'` — 인수 하나로 두 줄을 출력.
- `printf '%s-' a b c` — 서식을 재사용: `a-b-c-`.

## EXIT STATUS

- `0` — 모든 것(또는 요청된 짧은 도움말)이 기록됨.
- `1` — 변환 문제가 진단되었거나, 서식이 없거나 잘못되었거나,
  이스케이프가 잘못되었거나, 출력이 더 이상 바이트를 받지 않음.

## ENVIRONMENT

- `LANG` — 짧은 도움말에 쓸 선호 로캘(`ko-KR` 같은 BCP-47 태그).
