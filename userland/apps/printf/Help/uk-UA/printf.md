## NAME

printf — форматувати та друкувати дані

## SYNOPSIS

`printf format [argument...]`

## DESCRIPTION

Друкує `argument`(и) під керуванням `format`, як функція C `printf`.
Формат містить три види елементів: звичайні символи, що копіюються до
стандартного виводу; екрановані послідовності зі зворотною похилою
рискою; та директиви перетворення `%`, кожна з яких перетворює
наступний аргумент.

Екрановані послідовності: `\a` (сигнал), `\b` (забій), `\c` (негайно
завершити весь вивід), `\e` (escape), `\f` (подача сторінки), `\n`
(новий рядок), `\r` (повернення каретки), `\t` (табуляція), `\v`
(вертикальна табуляція), `\\`, `\"`, `\NNN` (від однієї до трьох
вісімкових цифр), `\xHH` (одна або дві шістнадцяткові цифри) та
`\uHHHH` / `\UHHHHHHHH` (кодові точки Unicode, чотири або вісім
шістнадцяткових цифр).

Перетворення: `%d`/`%i` (десяткове зі знаком), `%u` (десяткове без
знака), `%o`/`%x`/`%X` (вісімкове та шістнадцяткове), `%e`/`%E`/`%f`/
`%F`/`%g`/`%G`/`%a`/`%A` (з рухомою комою), `%c` (перший символ
аргумента), `%s` (рядок), `%b` (рядок із власними екранованими
послідовностями, вісімкове записується `\0NNN`), `%q` (рядок,
процитований для повторного використання в оболонці) та `%%`
(буквальний `%`). Директива приймає прапорці C `-`, `+`, пробіл, `#`,
`0` та `'`, ширину поля й точність; ширина та точність можуть бути `*`
і тоді читають своє значення з наступного аргумента. `%b` та `%q` не
приймають ані прапорців, ані ширини, ані точності.

Формат використовується повторно, доки не буде спожито всі аргументи;
перетворення без аргумента, що лишився, друкує нуль або порожній рядок.
Числовий аргумент читається як число C (шістнадцяткове `0x`, вісімкове
з початковим `0`, з рухомою комою, `inf`, `nan`); початковий `'` або
`"` перетворює кодову точку наступного символу. Аргумент, що не є
числом, є ним лише частково або виходить за межі, діагностується на
стандартному виводі помилок і перетворюється настільки, наскільки
можливо — виконання триває і завершується зі статусом `1`. Невідоме
перетворення, прапорець на перетворенні, яке його не приймає, або
неправильна екранована послідовність завершує виконання з діагностикою.

Дві навмисні розбіжності з GNU `printf`: рухома кома обчислюється в
подвійній точності IEEE 754 (GNU використовує `long double`), тож
значення поза межами double друкує `inf`; а *перший* аргумент `-h` чи
`-?` показує цю коротку довідку — такий формат пишеться
`printf -- -h...`.

## OPTIONS

- `-h, -?` — показати коротку довідку цієї команди (лише як перший
  аргумент).
- `--` — завершити аналіз параметрів; наступний аргумент — це формат.

## EXAMPLES

- `printf '%s\n' hello` — надрукувати `hello` і новий рядок.
- `printf '%d\n' 0x10` — надрукувати `16`.
- `printf '%5.2f|\n' 3.14159` — надрукувати ` 3.14|`.
- `printf '%s=%q\n' greeting 'hi there'` — надрукувати
  `greeting='hi there'`.
- `printf '%b' 'one\ntwo\n'` — надрукувати два рядки з одного
  аргумента.
- `printf '%s-' a b c` — повторно використати формат: `a-b-c-`.

## EXIT STATUS

- `0` — усе (або запитану коротку довідку) записано.
- `1` — діагностовано проблему перетворення, формат був відсутній чи
  недійсний, екранована послідовність була неправильною, або вивід
  перестав приймати байти.

## ENVIRONMENT

- `LANG` — бажана локаль для короткої довідки (мітка BCP-47, наприклад
  `uk-UA`).
