## NAME

printf — 格式化并打印数据

## SYNOPSIS

`printf format [argument...]`

## DESCRIPTION

在 `format` 的控制下打印各个 `argument`，与 C 的 `printf` 函数相同。
格式串包含三类内容：普通字符，原样复制到标准输出；反斜杠转义序列；
以及 `%` 转换指令，每条指令转换下一个参数。

转义序列包括 `\a`（响铃）、`\b`（退格）、`\c`（立即结束全部输出）、
`\e`（转义符）、`\f`（换页）、`\n`（换行）、`\r`（回车）、`\t`（制表
符）、`\v`（纵向制表符）、`\\`、`\"`、`\NNN`（一至三位八进制数字）、
`\xHH`（一或两位十六进制数字），以及 `\uHHHH` / `\UHHHHHHHH`
（Unicode 码点，四或八位十六进制数字）。

转换指令包括 `%d`/`%i`（带符号十进制）、`%u`（无符号十进制）、
`%o`/`%x`/`%X`（八进制与十六进制）、`%e`/`%E`/`%f`/`%F`/`%g`/`%G`/
`%a`/`%A`（浮点数）、`%c`（参数的第一个字符）、`%s`（字符串）、
`%b`（其自身转义序列被解释的字符串，八进制写作 `\0NNN`）、`%q`
（为供 shell 复用而加引号的字符串）以及 `%%`（字面 `%`）。指令接受
C 标志 `-`、`+`、空格、`#`、`0` 与 `'`，以及字段宽度和精度；宽度与
精度都可写作 `*`，从下一个参数读取其值。`%b` 与 `%q` 不接受任何标
志、宽度或精度。

格式串会按需重复使用，直至耗尽全部参数；没有剩余参数的转换打印零或
空字符串。数值参数按 C 数字读取（`0x` 十六进制、前导 `0` 八进制、
浮点、`inf`、`nan`）；前导 `'` 或 `"` 转换其后字符的码点。不是数字、
只是部分数字或超出范围的参数会在标准错误上得到诊断并尽可能转换 ——
运行继续并以状态 `1` 结束。未知的转换、用在不接受它的转换上的标志、
或格式错误的转义序列会以一条诊断终止运行。

与 GNU `printf` 的两处有意差异：浮点以 IEEE 754 双精度计算（GNU 使
用 `long double`），因此超出 double 范围的值打印 `inf`；*第一个*参数
为 `-h` 或 `-?` 时显示本简短帮助 —— 这样的格式应写作
`printf -- -h...`。

## OPTIONS

- `-h, -?` — 显示本命令自身的简短帮助（仅作为第一个参数时）。
- `--` — 结束选项解析；下一个参数即为格式串。

## EXAMPLES

- `printf '%s\n' hello` — 打印 `hello` 和一个换行。
- `printf '%d\n' 0x10` — 打印 `16`。
- `printf '%5.2f|\n' 3.14159` — 打印 ` 3.14|`。
- `printf '%s=%q\n' greeting 'hi there'` — 打印 `greeting='hi there'`。
- `printf '%b' 'one\ntwo\n'` — 由一个参数打印两行。
- `printf '%s-' a b c` — 重复使用格式串：`a-b-c-`。

## EXIT STATUS

- `0` — 全部内容（或请求的简短帮助）均已写出。
- `1` — 诊断出转换问题、格式串缺失或无效、转义序列格式错误，或输出
  不再接受字节。

## ENVIRONMENT

- `LANG` — 简短帮助的首选区域设置（BCP-47 标签，例如 `zh-CN`）。
