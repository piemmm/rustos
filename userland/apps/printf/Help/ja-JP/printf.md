## NAME

printf — データを整形して出力する

## SYNOPSIS

`printf format [argument...]`

## DESCRIPTION

C の `printf` 関数と同様に、`format` の制御下で各 `argument` を出力し
ます。フォーマットは三種類の要素を含みます。標準出力へそのまま複写さ
れる通常の文字、バックスラッシュのエスケープ列、そして次の引数を変換
する `%` 変換指示です。

エスケープ列は `\a`（ベル）、`\b`（後退）、`\c`（全出力を即座に終了）、
`\e`（エスケープ）、`\f`（改ページ）、`\n`（改行）、`\r`（復帰）、
`\t`（タブ）、`\v`（垂直タブ）、`\\`、`\"`、`\NNN`（八進数字一〜三
桁）、`\xHH`（十六進数字一〜二桁）、および `\uHHHH` / `\UHHHHHHHH`
（Unicode コードポイント、十六進数字四桁または八桁）です。

変換は `%d`/`%i`（符号付き十進）、`%u`（符号なし十進）、`%o`/`%x`/
`%X`（八進・十六進）、`%e`/`%E`/`%f`/`%F`/`%g`/`%G`/`%a`/`%A`（浮動
小数点）、`%c`（引数の最初の文字）、`%s`（文字列）、`%b`（自身のエス
ケープ列が解釈される文字列、八進は `\0NNN` と書く）、`%q`（シェル入
力として再利用できるよう引用された文字列）、`%%`（文字どおりの `%`）
です。指示は C のフラグ `-`、`+`、空白、`#`、`0`、`'`、フィールド幅、
精度を取ります。幅と精度はそれぞれ `*` と書け、その値を次の引数から
読み取ります。`%b` と `%q` はフラグも幅も精度も取りません。

フォーマットはすべての引数を消費するまで必要に応じて再利用されます。
残りの引数がない変換はゼロまたは空文字列を出力します。数値引数は C
の数値として読まれます（`0x` 十六進、先頭 `0` 八進、浮動小数点、
`inf`、`nan`）。先頭の `'` または `"` は次の文字のコードポイントに変
換します。数値でない、部分的にしか数値でない、または範囲外の引数は
標準エラーに診断され、可能なところまで変換されます — 実行は継続し、
状態 `1` で終了します。未知の変換、受け付けない変換へのフラグ、不正
なエスケープ列は診断とともに実行を終了させます。

GNU `printf` からの意図的な相違が二つあります。浮動小数点は IEEE 754
倍精度で計算されます（GNU は `long double` を使用）。そのため double
の範囲を超える値は `inf` と出力されます。また、*最初の*引数が `-h`
または `-?` のときはこの短いヘルプを表示します — そのようなフォー
マットは `printf -- -h...` と書いてください。

## OPTIONS

- `-h, -?` — このコマンド自身の短いヘルプを表示する（最初の引数とし
  てのみ）。
- `--` — オプション解析を終える。次の引数がフォーマットになる。

## EXAMPLES

- `printf '%s\n' hello` — `hello` と改行を出力する。
- `printf '%d\n' 0x10` — `16` を出力する。
- `printf '%5.2f|\n' 3.14159` — ` 3.14|` を出力する。
- `printf '%s=%q\n' greeting 'hi there'` — `greeting='hi there'` を出
  力する。
- `printf '%b' 'one\ntwo\n'` — 一つの引数から二行を出力する。
- `printf '%s-' a b c` — フォーマットを再利用する：`a-b-c-`。

## EXIT STATUS

- `0` — すべて（または要求された短いヘルプ）が書き出された。
- `1` — 変換の問題が診断された、フォーマットが無い・無効だった、エ
  スケープ列が不正だった、または出力がバイトを受け付けなくなった。

## ENVIRONMENT

- `LANG` — 短いヘルプに使う優先ロケール（`ja-JP` のような BCP-47 タ
  グ）。
