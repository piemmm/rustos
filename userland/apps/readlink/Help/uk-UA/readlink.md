## NAME

readlink — вивести ціль символьного посилання

## SYNOPSIS

`readlink [-nz] [-q | -s | -v] [--] файл...`

## DESCRIPTION

Виводить ціль, яку зберігає кожен операнд, по одній на операнд, у порядку
командного рядка.

Ціль виводиться **точно як збережено**. Ціль посилання — це дані, а не
шлях, розгорнутий під час створення посилання: вона може бути відносною,
містити `..` і не називати нічого. Тож `readlink` показує написання, а
`ls -l` показує посилання поряд з тим, що воно називає зараз.

Операнд, який **не** є символьним посиланням, не має цілі для виведення —
і файл, і каталог відхиляються з тією самою причиною «значення поза
межами» — а відсутнє ім'я — це «не знайдено». В обох випадках решта
операндів усе одно читається, а команда завершується з ненульовим
станом. Тиша — типова поведінка, як у інструменті GNU: `-v` вмикає
діагностику для кожного операнда.

`-n` прибирає розділювач після останньої цілі. Для більш ніж одного
операнда він ігнорується, і про це повідомляється, бо розділювачі між
цілями — це те, що їх розділяє.

Потрібен щонайменше один операнд. `--` завершує розбір параметрів.

Параметри канонізації GNU `-f`, `-e` та `-m` **відхиляються**, а не
наближаються. Розгортання кожного складника шляху — розгортати кожне
посилання, обробляти `..` фізично, застосовувати бюджет переходів і
правило, що посилання не може вийти за межі тому, який його зберігає —
це єдина реалізація файлової системи. Друга копія тут могла б вивести
шлях, який файлова система розгортає інакше, тож параметр відмовляє, доки
файлова система не запропонує таке розгортання сама.

## OPTIONS

- `-n, --no-newline` — не виводити розділювач після останньої цілі
  (ігнорується, з повідомленням, для більш ніж одного операнда).
- `-z, --zero` — завершувати кожну ціль NUL замість нового рядка.
- `-q, -s` — не діагностувати відмовлене читання (типово; також
  `--quiet`, `--silent`).
- `-v, --verbose` — діагностувати відмовлене читання в стандартний потік
  помилок.
- `-?, --help` — показати власну коротку довідку цієї команди.

## EXAMPLES

- `readlink Home:/Desktop/Notes` — вивести те, що зберігає ярлик.
- `readlink -v alias` — вивести й сказати чому, якщо це не посилання.
- `readlink -z a b | tr '\0' '\n'` — цілі, розділені NUL, для сценарію.

## EXIT STATUS

- `0` — ціль кожного операнда виведено (або записано коротку довідку).
- `1` — щонайменше одне читання відхилено або вивід не вдався.
- `2` — командний рядок не зрозуміло або він назвав параметр канонізації.

## ENVIRONMENT

- `LANG` — бажана локаль для короткої довідки (позначка BCP-47, як-от
  `fr-FR`).
