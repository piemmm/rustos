## NAME

mkdir — إنشاء الأدلة

## SYNOPSIS

`mkdir [-pv] [--] directory...`

## DESCRIPTION

ينشئ كل معطى دليل بالترتيب. بدون `-p` يجب أن يكون أب كل معطى موجودًا
سلفًا وألا يكون المعطى نفسه موجودًا؛ ويوقف أول فشل التشغيل قبل أي معطى
لاحق.

مع `-p` يُنشأ كل سلف مفقود أولًا، الأبعد فالأقرب، ولا يُعد المعطى (أو
السلف) الموجود سلفًا كدليل خطأً. أما السلف الموجود كملف فيظل يفشل: لا
يُستبدل شيء بصمت أبدًا.

الخيار `-m`/`--mode` من `mkdir` GNU غير مقبول بعد: تُنشأ الأدلة بالوضع
الافتراضي لنظام الملفات حتى تصل آلية ضبط الأوضاع، وسيصل المفتاح معها
بدلًا من تجاهله. ينهي `--` تحليل الخيارات: كل معطى لاحق هو مسار.

## OPTIONS

- `-p, --parents` — إنشاء الأدلة الأب المفقودة؛ المعطى الذي هو دليل
  سلفًا ليس خطأً.
- `-v, --verbose` — الإبلاغ عن كل دليل أُنشئ بالشكل
  `mkdir: created directory 'dir'`.
- `-h, -?` — عرض المساعدة القصيرة لهذا الأمر نفسه (أيضًا `--help`).

## EXAMPLES

- `mkdir Notes` — إنشاء دليل واحد في الدليل الحالي.
- `mkdir -p Projects/os/build` — إنشاء السلسلة كلها مع تخطي الأجزاء
  الموجودة سلفًا.
- `mkdir -pv Home:/tools/bin` — الإنشاء تحت جذر اسم بديل مع الإبلاغ عن
  كل دليل جديد.

## EXIT STATUS

- `0` — أُنشئ كل دليل (أو كان موجودًا سلفًا مع `-p`).
- `1` — فشل في نظام الملفات أو في الخرج؛ يُطبع السبب على الخطأ
  القياسي.
- `2` — لم يُفهم سطر الأوامر.

## ENVIRONMENT

- `LANG` — المنطقة المفضلة للمساعدة القصيرة (وسم BCP-47 مثل `ar-SA`).
