## NAME

mkdir — ディレクトリを作る

## SYNOPSIS

`mkdir [-pv] [--] directory...`

## DESCRIPTION

各ディレクトリオペランドを順に作成します。`-p` がなければ、各オペランドの
親はすでに存在していなければならず、オペランド自体は存在していてはなりま
せん。最初の失敗で、後続のオペランドに移る前に実行が止まります。

`-p` があれば、欠けている祖先が外側から順に先に作成され、すでにディレクト
リとして存在するオペランド（や祖先）はエラーになりません。ファイルとして
存在する祖先は依然として失敗します。何かが黙って置き換えられることは決し
てありません。

GNU `mkdir` の `-m`/`--mode` はまだ受け付けられません。モード設定の仕組み
が実装されるまで、ディレクトリはファイルシステムの既定モードで作成され、
このスイッチは無視されるのではなく、その仕組みと共に登場します。`--` はオ
プション解析を終え、以降のすべての引数はパスです。

## OPTIONS

- `-p, --parents` — 欠けている親ディレクトリを作る。すでにディレクトリで
  あるオペランドはエラーではない。
- `-v, --verbose` — 作成した各ディレクトリを
  `mkdir: created directory 'dir'` の形で報告する。
- `-h, -?` — このコマンド自身の短いヘルプを表示する（`--help` も可）。

## EXAMPLES

- `mkdir Notes` — 現在のディレクトリにディレクトリを一つ作る。
- `mkdir -p Projects/os/build` — 既存の部分を飛ばして連鎖全体を作る。
- `mkdir -pv Home:/tools/bin` — エイリアスルートの下に作り、新しいディレ
  クトリを逐一報告する。

## EXIT STATUS

- `0` — すべてのディレクトリを作成した（または `-p` の下ですでに存在し
  た）。
- `1` — ファイルシステムまたは出力の失敗。理由は標準エラーに印字される。
- `2` — コマンド行を解釈できなかった。

## ENVIRONMENT

- `LANG` — 短いヘルプの優先ロケール（`ja-JP` のような BCP-47 タグ）。
