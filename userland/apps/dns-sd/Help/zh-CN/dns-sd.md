## NAME

dns-sd — 浏览、解析和查找本地链路服务

## SYNOPSIS

`dns-sd [-t seconds] -B [type [domain]]`

`dns-sd [-t seconds] -L instance type [domain]`

`dns-sd [-t seconds] -G v4|v6|v4v6 host`

## DESCRIPTION

通过系统的本地链路发现服务，向本地网络（即链路）询问其提供的服务。`dns-sd`
本身从不使用组播 DNS：发现服务代表它询问网段，并按照程序自身的权限准许每个
请求。

使用 `-B` 时，它浏览某一服务类型的实例，例如打印机的 `_ipp._tcp`，并在每个
实例被添加或移除时将其打印出来。不给出类型时，它列出链路提供的所有服务类型。
使用 `-L` 时，它将一个实例解析为可到达它的主机和端口，并打印该实例对自身的
描述（其 `TXT` 属性）。使用 `-G` 时，它查找 `local` 下某个主机的地址。

每个应答都会指明其获知时所在的接口；`Flush` 行表示在该接口上获知的一切都已
不再有效——其链路已断开，或服务已重新开始。打印出的每个名称都由链路上的另一台
机器选定，因此以转义后的 DNS 表示形式显示：空格显示为 `\032`，控制字符显示为
其十进制代码。

浏览所有类型，或浏览当前帐户未被授予的类型，需要 `CAP_NET_DISCOVER_ALL`，
只有管理员帐户才具备该权限。链路上唯一的域是 `local`。

## OPTIONS

- `-B` — 浏览某一服务类型的实例；未给出类型时浏览所有类型。
- `-L` — 解析某一服务类型的一个实例。
- `-G` — 查找主机的 IPv4（`v4`）、IPv6（`v6`）或两者（`v4v6`）地址。
- `-t` — 在这么多秒后停止，而不是一直运行到被中断。
- `-?, --help` — 显示此命令自身的简短帮助。

## EXAMPLES

- `dns-sd -B _ipp._tcp` — 链路上的打印机，随其出现与消失而更新。
- `dns-sd -t 5 -B` — 五秒内看到的所有服务类型。
- `dns-sd -L "Hall Printer" _ipp._tcp` — 某台打印机的到达位置。
- `dns-sd -G v4v6 printer.local` — 某个主机的地址。

## EXIT STATUS

- `0` — 命令已运行完毕（或已写出简短帮助）。
- `1` — 发现服务拒绝了请求或未在运行。
- `2` — 无法理解命令行，或无法写出输出。

## ENVIRONMENT

- `LANG` — 简短帮助的首选语言环境（BCP-47 标记，例如 `fr-FR`）。
