## NAME

dns-sd — リンクローカルのサービスを参照、解決、検索する

## SYNOPSIS

`dns-sd [-t seconds] -B [type [domain]]`

`dns-sd [-t seconds] -L instance type [domain]`

`dns-sd [-t seconds] -G v4|v6|v4v6 host`

## DESCRIPTION

システムのリンクローカル探索サービスを通じて、ローカルネットワーク（リンク）
が提供するサービスを問い合わせます。`dns-sd` 自身がマルチキャスト DNS を話すこ
とはありません。探索サービスがセグメントに代わりに問い合わせ、各リクエストをプ
ログラム自身の権限に照らして受け付けます。

`-B` では、プリンターを表す `_ipp._tcp` のようなサービス種別のインスタンスを参
照し、インスタンスが追加または削除されるたびに表示します。種別を指定しない場合
は、リンクが提供するすべてのサービス種別を一覧します。`-L` では、1 つのインス
タンスを到達先のホストとポートに解決し、インスタンスが自身について述べる内容
（`TXT` 属性）を表示します。`-G` では、`local` 配下のホストのアドレスを検索しま
す。

各応答には、それを知ったインターフェースが示されます。`Flush` 行は、そのイン
ターフェースで知ったことがすべて無効になったことを意味します。リンクが切れた
か、サービスがやり直したためです。表示される名前はすべてリンク上の別のマシンが
選んだものなので、DNS の表示形式でエスケープして表示されます。空白は `\032`、
制御文字は 10 進コードになります。

すべての種別、または実行中のアカウントに許可されていない種別を参照するには
`CAP_NET_DISCOVER_ALL` が必要で、これは管理者アカウントだけが持ちます。リンク
上の唯一のドメインは `local` です。

## OPTIONS

- `-B` — サービス種別のインスタンスを参照します。種別を省略すると全種別を
  参照します。
- `-L` — サービス種別の 1 つのインスタンスを解決します。
- `-G` — ホストの IPv4（`v4`）、IPv6（`v6`）、または両方（`v4v6`）のアドレス
  を検索します。
- `-t` — 中断されるまで動くのではなく、指定秒数の後に停止します。
- `-?, --help` — このコマンド自身の簡易ヘルプを表示します。

## EXAMPLES

- `dns-sd -B _ipp._tcp` — リンク上のプリンターを、現れては消えるままに表示。
- `dns-sd -t 5 -B` — 5 秒以内に見えたすべてのサービス種別。
- `dns-sd -L "Hall Printer" _ipp._tcp` — 1 台のプリンターの到達先。
- `dns-sd -G v4v6 printer.local` — ホストのアドレス。

## EXIT STATUS

- `0` — コマンドが最後まで実行された（または簡易ヘルプが書き出された）。
- `1` — 探索サービスがリクエストを拒否したか、動作していない。
- `2` — コマンドラインを理解できなかった、または出力を書き出せなかった。

## ENVIRONMENT

- `LANG` — 簡易ヘルプに使う優先ロケール（`fr-FR` のような BCP-47 タグ）。
