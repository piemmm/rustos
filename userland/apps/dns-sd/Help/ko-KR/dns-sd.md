## NAME

dns-sd — 로컬 링크의 서비스를 탐색, 해석, 조회

## SYNOPSIS

`dns-sd [-t seconds] -B [type [domain]]`

`dns-sd [-t seconds] -L instance type [domain]`

`dns-sd [-t seconds] -G v4|v6|v4v6 host`

## DESCRIPTION

시스템의 로컬 링크 탐색 서비스를 통해 로컬 네트워크(링크)에 어떤 서비스가
있는지 묻습니다. `dns-sd`는 멀티캐스트 DNS를 직접 사용하지 않습니다. 탐색
서비스가 대신 세그먼트에 묻고, 각 요청을 프로그램 자신의 권한에 따라 허용합니다.

`-B`를 쓰면 프린터를 뜻하는 `_ipp._tcp` 같은 한 서비스 유형의 인스턴스를 탐색하고,
인스턴스가 추가되거나 제거될 때마다 출력합니다. 유형을 주지 않으면 링크가
제공하는 모든 서비스 유형을 나열합니다. `-L`을 쓰면 한 인스턴스를 도달할 수 있는
호스트와 포트로 해석하고, 인스턴스가 스스로에 대해 밝히는 내용(`TXT` 속성)을
출력합니다. `-G`를 쓰면 `local` 아래 호스트의 주소를 조회합니다.

각 응답은 그것을 알게 된 인터페이스를 밝히며, `Flush` 줄은 그 인터페이스에서
알게 된 모든 것이 더 이상 유효하지 않다는 뜻입니다. 링크가 끊겼거나 서비스가
다시 시작했기 때문입니다. 출력되는 모든 이름은 링크의 다른 기계가 정한 것이므로
DNS 표현 형식으로 이스케이프되어 표시됩니다. 공백은 `\032`, 제어 문자는 십진
코드로 나타납니다.

모든 유형, 또는 실행 중인 계정에 허가되지 않은 유형을 탐색하려면
`CAP_NET_DISCOVER_ALL`이 필요하며, 이는 관리자 계정만 가집니다. 링크의 유일한
도메인은 `local`입니다.

## OPTIONS

- `-B` — 서비스 유형의 인스턴스를 탐색하며, 유형을 주지 않으면 모든 유형을
  탐색합니다.
- `-L` — 서비스 유형의 한 인스턴스를 해석합니다.
- `-G` — 호스트의 IPv4(`v4`), IPv6(`v6`) 또는 둘 다(`v4v6`) 주소를
  조회합니다.
- `-t` — 중단될 때까지 실행하지 않고 지정한 초가 지나면 멈춥니다.
- `-?, --help` — 이 명령 자체의 짧은 도움말을 보여 줍니다.

## EXAMPLES

- `dns-sd -B _ipp._tcp` — 링크의 프린터를 나타나고 사라지는 대로 표시.
- `dns-sd -t 5 -B` — 5초 안에 보인 모든 서비스 유형.
- `dns-sd -L "Hall Printer" _ipp._tcp` — 한 프린터에 도달하는 곳.
- `dns-sd -G v4v6 printer.local` — 한 호스트의 주소.

## EXIT STATUS

- `0` — 명령이 끝까지 실행되었습니다(또는 짧은 도움말을 썼습니다).
- `1` — 탐색 서비스가 요청을 거부했거나 실행 중이 아닙니다.
- `2` — 명령줄을 이해하지 못했거나 출력을 쓸 수 없었습니다.

## ENVIRONMENT

- `LANG` — 짧은 도움말에 쓸 선호 로캘(`fr-FR` 같은 BCP-47 태그).
