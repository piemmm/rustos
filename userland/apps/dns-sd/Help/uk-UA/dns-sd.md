## NAME

dns-sd — переглядати, визначати й шукати служби локального з'єднання

## SYNOPSIS

`dns-sd [-t seconds] -B [type [domain]]`

`dns-sd [-t seconds] -L instance type [domain]`

`dns-sd [-t seconds] -G v4|v6|v4v6 host`

## DESCRIPTION

Запитує локальну мережу — з'єднання — про служби, які вона пропонує, через
системну службу виявлення в локальному з'єднанні. `dns-sd` ніколи сам не
говорить багатоадресним DNS: служба виявлення опитує сегмент від його імені й
допускає кожен запит відповідно до власних повноважень програми.

З `-B` вона переглядає екземпляри одного типу служби, як-от `_ipp._tcp` для
принтерів, і виводить кожен екземпляр, коли він додається чи зникає. Без типу
вона перелічує всі типи служб, які пропонує з'єднання. З `-L` вона визначає
вузол і порт, де доступний один екземпляр, і виводить, що екземпляр каже про
себе (його атрибути `TXT`). З `-G` вона шукає адреси вузла під `local`.

Кожна відповідь називає інтерфейс, на якому її дізналися, а рядок `Flush`
означає, що все дізнане на цьому інтерфейсі більше не відоме — його з'єднання
зникло або служба почала заново. Кожне виведене ім'я обрала інша машина в
з'єднанні, тому воно показується екранованим у формі подання DNS: пробіл як
`\032`, керівний символ — його десятковим кодом.

Перегляд усіх типів або типу, якого не надано поточному обліковому запису,
вимагає `CAP_NET_DISCOVER_ALL`, яку має лише обліковий запис адміністратора.
Єдиний домен у з'єднанні — `local`.

## OPTIONS

- `-B` — переглядати екземпляри типу служби або всі типи, якщо тип не
  вказано.
- `-L` — визначити один екземпляр типу служби.
- `-G` — шукати адреси IPv4 (`v4`), IPv6 (`v6`) або обидві (`v4v6`) вузла.
- `-t` — зупинитися через стільки секунд замість роботи до переривання.
- `-?, --help` — показати власну коротку довідку цієї команди.

## EXAMPLES

- `dns-sd -B _ipp._tcp` — принтери в з'єднанні, як вони з'являються й
  зникають.
- `dns-sd -t 5 -B` — усі типи служб, помічені за п'ять секунд.
- `dns-sd -L "Hall Printer" _ipp._tcp` — де доступний один принтер.
- `dns-sd -G v4v6 printer.local` — адреси вузла.

## EXIT STATUS

- `0` — команда виконалася повністю (або коротку довідку було записано).
- `1` — служба виявлення відхилила запит або не працює.
- `2` — рядок команди не зрозуміло, або вивід не вдалося записати.

## ENVIRONMENT

- `LANG` — бажана локаль для короткої довідки (тег BCP-47, як-от `fr-FR`).
