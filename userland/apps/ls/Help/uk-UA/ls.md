## NAME

ls — вивести вміст каталогів

## SYNOPSIS

`ls [-a] [-l] [--] [path...]`

## DESCRIPTION

Виводить кожен операнд-шлях по черзі. Для каталогу виводяться його
записи, впорядковані за іменем; операнд, що не є каталогом, виводиться
за своїм іменем. Без операндів виводиться поточний каталог.

Записи, ім'я яких починається з `.`, приховуються, якщо не задано
`-a`. Коли типовий фільтр приховує записи, `ls` зазначає їхню кількість
у консультативному потоці (fd 3); сам перелік не змінюється.

Якщо операндів кілька, спершу виводяться ті, що не є каталогами
(впорядковані за іменем), потім кожен каталог під заголовком `шлях:`,
а блоки розділяються порожнім рядком.

Довгий формат друкує для кожного запису: символ типу (`d` для
каталогу, інакше `-`), дев'ять бітів прав доступу, розмір у байтах,
вирівняний праворуч у межах блоку, і насамкінець ім'я.

## OPTIONS

- `-a, --all` — не приховувати записи, ім'я яких починається з `.`.
- `-l, --long` — довгий формат: тип і біти прав доступу, розмір, потім
  ім'я.
- `-h, -?` — показати коротку довідку цієї команди.

## EXAMPLES

- `ls` — вивести поточний каталог.
- `ls -la /System/Apps` — вивести всі записи `/System/Apps`, разом із
  прихованими, у довгому форматі.
- `ls -- -a` — вивести файл або каталог з іменем `-a`.

## EXIT STATUS

- `0` — кожен операнд виведено.
- `1` — операнд не вдалося перевірити, каталог не вдалося прочитати або
  перелік не вдалося видати.
- `2` — командний рядок не було зрозуміло.

## ENVIRONMENT

- `LANG` — бажана локаль для короткої довідки (тег BCP-47, наприклад
  `uk-UA`).
