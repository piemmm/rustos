## NAME

ls — ディレクトリの内容を一覧する

## SYNOPSIS

`ls [-aACcdFfghilmnopQrRsStUuvXx1] [-w cols] [--time=WORD]`
`[--time-style=STYLE] [--sort=WORD] [--full-time]`
`[--group-directories-first] [--] [path...]`

## DESCRIPTION

各パスオペランドを一覧します。ディレクトリオペランドはその項目が読まれ
て一覧され（`-d` がディレクトリ自体を指す場合を除く）、それ以外のオペラ
ンドはそれ自体として一覧されます。オペランドがなければ現在のディレクト
リ（`.`）が一覧されます。

項目は名前順に並びます（`-S` なら大きい順、`-t` なら時刻順で新しいものから、`-r` なら逆順）。既定では一行
に一つの名前です。名前が `.` で始まる項目は、`-a` か `-A` が与えられない
限り隠されます。項目が隠されたときは、標準情報ストリーム（fd 3）に注記が
出ます。一覧そのものには決して混ざりません。

長い形式（`-l`）は、種別と許可ビット、所有者とグループ、サイズ、そして
名前を描きます。所有者とグループは数値の id です。アカウント名の解決には
権能で守られたユーザーデータベースが必要で、一覧がそれを要求してはならな
いため、出力は GNU ツールの数値フォールバックに一致します（`-n` は同一の
描画になります）。タイムスタンプ列は既定で更新時刻を示します。`-c`・`-u`・`--time` は四つのうちどのタイムスタンプを表示（および並べ替え）に使うかを選び、`--time-style`（または `--full-time`）がその書式を決めます。リンク数の列はまだありません。ファイルシステムの契約がまだハードリンクを運ばないからで、運ぶようになれば現れます。

オペランドが複数与えられたとき — そして `-R` の下では常に — 各ディレクト
リの一覧の前に `path:` の見出しが付き、ブロックは空行で区切られます。

## OPTIONS

- `-t` — 表示されるタイムスタンプ順に、新しいものから並べる。
- `-c` — メタデータ変更時刻（ctime）を使う。`-l` では表示し、`-t` ではそれで並べ替える。`-l` がなければそれで並べ替える。
- `-u` — `-c` と同様だが、アクセス時刻（atime）。
- `-i, --inode` — 各項目のノード番号を印字する。
- `--time=WORD` — どのタイムスタンプを表示・並べ替えに使うか。`atime`（`access`、`use`）、`ctime`（`status`）、`mtime`（`modification`）、または `birth`（`creation`）。
- `--time-style=STYLE` — タイムスタンプの書式。`locale`（既定）、`long-iso`、`full-iso`、`iso`。独自の `+FORMAT` は非対応。
- `--full-time` — `-l --time-style=full-iso` と同じ。
- `-a, --all` — 名前が `.` で始まる項目を隠さない。
- `-A, --almost-all` — `-a` と同様だが、`.` と `..` は決して一覧しない。
- `-d, --directory` — ディレクトリオペランド自体を一覧し、その中身は一
  覧しない。
- `-F, --classify` — ディレクトリに `/`、実行可能ファイルに `*` を付け
  る。
- `-g` — 所有者の列を省いた長い形式。`-l` を含意する。
- `-h, --human-readable` — `-l` とともに、サイズを `1.1K`、`23M` のよう
  に印字する（1024 の累乗）。
- `-l` — 長い形式。許可ビット、所有者、グループ、サイズ、そして名前。
- `-m` — コンマ区切りの名前を幅で折り返す。
- `-n, --numeric-uid-gid` — 所有者とグループを数値にした長い形式。`-l`
  を含意する。ここでは所有者とグループは常に数値なので（上記参照）、
  `-l` と一致する。
- `-o` — グループの列を省いた長い形式。`-l` を含意する。
- `-p` — ディレクトリに `/` を付ける。
- `-Q, --quote-name` — 各名前を二重引用符で囲み、引用符・バックスラッ
  シュ・制御文字をエスケープする。
- `-r, --reverse` — 並び順を逆にする。
- `-R, --recursive` — サブディレクトリを再帰的に一覧する。
- `-s, --size` — 各項目の割り当てサイズを 1024 バイトブロックで印字し
  （`-h` で換算）、ディレクトリ一覧ごとに `total` の行を付ける。
- `-C` — 列で一覧表示し、上から下へ埋める（端末での既定）。
- `-S` — サイズ順、大きいものから。
- `-U` — 並べ替えず、ディレクトリの順序で一覧します。
- `-X` — 拡張子（最後の `.` 以降）で並べ替えます。同じ場合は
  名前順。
- `-v` — 自然な「バージョン」順で並べ替え、`f2` は `f10` より
  前になります。同じ場合は名前順。
- `-f` — 並べ替えずすべての項目を表示します。`-a` と `-U` を
  有効にし、`-l` と `-s` を無効にします。指定位置で適用される
  ため、後続の `-l`/`-s`/並べ替えフラグが優先されます。
- `--sort=WORD` — 並べ替えの基準を名前で選びます: `none`（`-U`）、
  `size`（`-S`）、`time`（`-t`）、`version`（`-v`）、
  `extension`（`-X`）、`name`。
- `--group-directories-first` — 他の項目の前にディレクトリを一覧
  します。`-r` を付けてもディレクトリが先になります。
- `-w, --width <cols>` — 出力幅を桁数で指定する。`0` は無制限。
- `-x` — 列で一覧表示し、左から右へ埋める。
- `-1` — 一行に一つの名前（既定）。
- `-?` — このコマンド自身の短いヘルプを表示する（長い形は `--help`）。

## EXAMPLES

- `ls` — 現在のディレクトリを一覧する。
- `ls -al /System` — 隠し項目も含めた `/System` の長い形式の一覧。
- `ls -lhS` — 長い形式、読みやすいサイズ、大きいものから。
- `ls -R Documents` — `Documents` を再帰的にたどり、ディレクトリごとに
  見出しを付ける。
- `ls -F` — ディレクトリを `/`、実行可能ファイルを `*` で標す。
- `ls -d Documents` — `Documents` の項目自体を一覧し、その中身は一覧し
  ない。

## EXIT STATUS

- `0` — すべてのオペランドを一覧した。
- `1` — オペランドを調べられなかった、ディレクトリを読めなかった、また
  は出力を届けられなかった。
- `2` — コマンド行を解釈できなかった。

## ENVIRONMENT

- `LANG` — 短いヘルプの優先ロケール（`ja-JP` のような BCP-47 タグ）。
