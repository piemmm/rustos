## NAME

usermod — ユーザーアカウントを変更する

## SYNOPSIS

`usermod [-c COMMENT] [-d HOME] [-s SHELL] [-g GID] [-G LIST] [-L | -U]
[--grants LIST] [--] NAME`

## DESCRIPTION

アカウントの識別フィールド、ロック状態、または権能の上限を変更します。アカウントの変更は管理操作です。ユーザー管理の権能を持たない呼び出し元をデータベースは拒否します。

識別情報の変更はセキュリティに関わらないフィールド一式をまるごと置き換えるため、まず現在のレコードを読み、誰も指定しなかったフィールドはそのまま送り返します。データベースが列挙しないアカウントは、何も送る前に拒否されます。

各スイッチはそれぞれ独立したデータベース操作で、一度に一つずつ、全部か皆無かで適用されます。複数を求める行は複数を送り、順序は固定です —
フィールド、次に権能、次にロック状態 — そして最初の拒否で止まり、その段階を名指し、先の変更が既に有効かもしれないと警告します。

`-G`
は補助グループ集合を追加ではなく丸ごと置き換えます。データベースは集合全体を受け取るので、古い読み取りに基づく追加は明示的な置換より悪くなります。`--grants`
は TAIRiX 固有の概念で長い形のみ。呼び出し元アカウント自身が持たない権能をデータベースは拒否します。

`--` はオプション解析を終え、以降のすべての引数はオペランドです。

## OPTIONS

- `-c, --comment COMMENT` — アカウントのコメント／氏名。
- `-d, --home HOME` — ホームディレクトリ。
- `-s, --shell SHELL` — ログインシェル。
- `-g, --gid GID` — 主グループの数値 id。
- `-G, --groups LIST` — カンマ区切りの補助グループ数値 id。現在の集合を置き換えます。空の一覧は消去します。
- `-L, --lock` — アカウントのログインを禁じます。
- `-U, --unlock` — 再び許します。
- `--grants LIST` — カンマ区切りの権能名で、上限全体を成します。空の一覧は消去します。
- `-h, -?, --help` — このコマンド自身の短いヘルプを表示します。

## EXAMPLES

- `usermod -c 'Ada Lovelace' ada` — アカウントの氏名を設定します。
- `usermod -L ada` — アカウントをロックします。
- `usermod --grants LIST` — 権能の上限を置き換えます。

## EXIT STATUS

- `0` — 要求されたすべての変更を行いました。
- `1` — データベースが変更を拒否または失敗しました。段階と理由は標準エラーに出力されます。
- `2` — コマンドラインを解釈できませんでした。

## ENVIRONMENT

- `LANG` — 短いヘルプに使う優先ロケール（`ja-JP` のような BCP-47 タグ）。
