## NAME

usermod — 사용자 계정을 변경한다

## SYNOPSIS

`usermod [-c COMMENT] [-d HOME] [-s SHELL] [-g GID] [-G LIST] [-L | -U]
[--grants LIST] [--] NAME`

## DESCRIPTION

계정의 신원 필드, 잠금 상태 또는 권능 상한을 바꿉니다. 계정 변경은 관리 작업이며, 사용자 관리 권능이 없는 호출자는 데이터베이스가 거부합니다.

신원 편집은 보안과 무관한 필드 집합 전체를 대체하므로, 도구는 먼저 현재 레코드를 읽고 아무도 지정하지 않은 필드를 그대로 되돌려
보냅니다. 데이터베이스가 목록에 두지 않은 계정은 아무것도 보내기 전에 거부됩니다.

각 스위치는 저마다 독립된 데이터베이스 작업이며, 한 번에 하나씩 전부 또는 전무로 적용됩니다. 여러 개를 요구하는 줄은 여러 번 보내며
순서는 고정입니다 — 필드, 그다음 권능, 그다음 잠금 상태 — 그리고 첫 거부에서 멈춰 그 단계를 밝히고 앞선 변경이 이미 적용되었을
수 있음을 경고합니다.

`-G` 는 보조 그룹 집합을 덧붙이지 않고 통째로 대체합니다. 데이터베이스는 집합 전체를 받으므로, 낡은 읽기에 근거한 덧붙이기는
명시적 대체보다 나쁩니다. `--grants` 는 TAIRiX 고유 개념이라 긴 형식만 쓰며, 호출 계정이 스스로 갖지 않은 권능은
데이터베이스가 거부합니다.

`--` 는 옵션 해석을 끝내며, 그 뒤의 모든 인수는 피연산자입니다.

## OPTIONS

- `-c, --comment COMMENT` — 계정 주석 / 전체 이름.
- `-d, --home HOME` — 홈 디렉터리.
- `-s, --shell SHELL` — 로그인 셸.
- `-g, --gid GID` — 기본 그룹의 숫자 식별자.
- `-G, --groups LIST` — 쉼표로 구분한 보조 그룹 숫자 식별자로, 현재 집합을 대체합니다. 빈 목록은 이를 지웁니다.
- `-L, --lock` — 계정의 로그인을 막습니다.
- `-U, --unlock` — 다시 허용합니다.
- `--grants LIST` — 쉼표로 구분한 권능 이름으로, 상한 전체를 이룹니다. 빈 목록은 이를 지웁니다.
- `-h, -?, --help` — 이 명령 자체의 짧은 도움말을 표시합니다.

## EXAMPLES

- `usermod -c 'Ada Lovelace' ada` — 계정의 전체 이름을 설정합니다.
- `usermod -L ada` — 계정을 잠급니다.
- `usermod --grants LIST` — 권능 상한을 대체합니다.

## EXIT STATUS

- `0` — 요청한 모든 변경이 이루어졌습니다.
- `1` — 데이터베이스가 변경을 거부했거나 실패했습니다. 단계와 이유는 표준 오류로 출력됩니다.
- `2` — 명령줄을 이해하지 못했습니다.

## ENVIRONMENT

- `LANG` — 짧은 도움말에 쓰는 선호 로케일(`ko-KR` 같은 BCP-47 태그).
