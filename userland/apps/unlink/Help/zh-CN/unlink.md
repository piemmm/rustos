## NAME

unlink — 删除一个名称

## SYNOPSIS

`unlink [--] 文件`

## DESCRIPTION

通过 POSIX `unlink` 函数所指的那一次文件系统调用，恰好删除一个名称。
这里有意不提供递归、强制、询问和报告：需要只删除一个名称而不做其他事
的脚本，由此获得一个无法做更多事的工具。需要那些选项请用 `rm`，删除目
录请用 `rmdir`。

名称**按所写的样子**删除。符号链接被删除的是它自己，从不被跟随，因此
放在该名称上的链接无法把删除重定向到它所指之处。

**目录**由文件系统拒绝，且在本会删除该目录项的同一次加锁遍历中拒绝
——这里不存在先检查后删除的竞态。

必须恰好给出一个操作数：没有操作数和给出两个及以上操作数都是用法错
误，并且不会删除任何东西。`--` 结束选项解析，因此以短横线开头的名称
仍然可以删除。

## OPTIONS

- `-?, --help` — 显示本命令自己的简短帮助。

## EXAMPLES

- `unlink old.log` — 删除一个名称。
- `unlink Home:/Documents/alias` — 删除符号链接本身，而不是它指向的
  对象。
- `unlink -- -奇怪的名称` — 删除以短横线开头的名称。

## EXIT STATUS

- `0` — 名称已删除（或已写出简短帮助）。
- `1` — 文件系统拒绝了删除，或输出失败；原因打印到标准错误。
- `2` — 未能理解命令行。

## ENVIRONMENT

- `LANG` — 简短帮助的首选区域设置（如 `fr-FR` 这样的 BCP-47 标签）。
