## NAME

unlink — 名前を一つ削除する

## SYNOPSIS

`unlink [--] ファイル`

## DESCRIPTION

POSIX の `unlink` 関数が指す唯一のファイルシステム呼び出しによって、
ちょうど一つの名前を削除する。再帰も強制も確認も報告も意図的に持たな
い。一つの名前だけを削除しそれ以上は何もしない必要があるスクリプトに
は、それ以上できない道具が与えられる。それらのオプションが必要なら
`rm`、ディレクトリなら `rmdir` を使う。

名前は **書かれたとおりに** 削除される。シンボリックリンクはそれ自身
が削除され、決してたどられないので、その名前に仕込まれたリンクが削除
先を指し先に付け替えることはできない。

**ディレクトリ** はファイルシステムが拒否する。しかもエントリを削除し
たはずの同じロック付きの走査の中で拒否するので、確認と削除の競合はこ
こには存在しない。

オペランドはちょうど一つ必要である。オペランドなしも、二つ以上も、と
もに使用法の誤りであり、何も削除されない。`--` はオプション解析を終わ
らせるので、ハイフンで始まる名前も削除できる。

## OPTIONS

- `-?, --help` — このコマンド自身の短いヘルプを表示する。

## EXAMPLES

- `unlink old.log` — 名前を一つ削除する。
- `unlink Home:/Documents/alias` — シンボリックリンクが指す先ではな
  く、リンク自身を削除する。
- `unlink -- -奇妙な名前` — ハイフンで始まる名前を削除する。

## EXIT STATUS

- `0` — 名前を削除した（または短いヘルプを書き出した）。
- `1` — ファイルシステムが削除を拒否した、または出力が失敗した。理由
  は標準エラーに表示される。
- `2` — コマンド行を解釈できなかった。

## ENVIRONMENT

- `LANG` — 短いヘルプの優先ロケール（`fr-FR` のような BCP-47 タグ）。
