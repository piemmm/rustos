## NAME

tail — 파일의 마지막 부분을 출력

## SYNOPSIS

`tail [option...] [file...]`

## DESCRIPTION

각 `file`의 마지막 10줄을 표준 출력에 인쇄합니다. `file`이 여러 개이면 각
부분 앞에 `==> file <==` 머리글이 붙습니다. `file`이 없거나 `file`이 `-`이면
표준 입력을 읽습니다.

`-n`과 `-c`는 인쇄량을 바꿉니다. 단순한 개수(또는 앞에 `-`를 붙여 쓴 개수)는
마지막 `num`줄 또는 바이트를 인쇄합니다. 앞에 `+`를 붙여 쓴 개수는 `num`번째
줄 또는 바이트(1부터 셈)**부터** 끝까지 전부를 인쇄합니다. 개수에는 배수
접미사를 붙일 수 있습니다. `b` (512), `kB` (1000), `K` (1024), `MB`, `M`,
`GB`, `G`, 이어서 `T`, `P`, `E`, `Z`, `Y`, `R`, `Q`도 마찬가지입니다(문자
하나만 쓰면 1024의 거듭제곱, `B`를 붙이면 1000의 거듭제곱, `iB`를 붙이면
1024의 거듭제곱으로 곱합니다).

역사적인 첫 인수 형식 `tail -num` / `tail +num`(끝에 선택적으로 `b`/`c`/`l`
문자를 붙일 수 있음)도 GNU 도구와 동일하게 받아들입니다.

따라가기 모드(`-f`, `-F`, `--follow`, `--retry`, `--pid`, `--sleep-interval`,
`--max-unchanged-stats`)는 아직 사용할 수 없으며 인식할 수 없는 옵션으로
보고됩니다. 파일 변경 시 깨우는 소스가 필요하지만 시스템이 아직 제공하지
않으며, 그 대신 바쁜 대기를 하지도 않습니다.

앞부분 내용이 표시되지 않을 때는 표준 정보 스트림(fd 3)에 안내 레코드가
기록됩니다. 이는 출력이나 종료 상태를 절대 바꾸지 않습니다. 읽을 수 없는
파일은 오류 출력에 보고되고 실행은 다음 파일로 계속됩니다.

## OPTIONS

- `-c, --bytes <num>` — 각 파일의 마지막 `num`바이트를 인쇄합니다. 앞에
  `+`가 있으면 `num`바이트째부터 전부를 인쇄합니다.
- `-n, --lines <num>` — 각 파일의 마지막 `num`줄을 인쇄합니다. 앞에 `+`가
  있으면 `num`번째 줄부터 전부를 인쇄합니다.
- `-q, --quiet, --silent` — `==> file <==` 머리글을 결코 인쇄하지 않습니다.
- `-v, --verbose` — `==> file <==` 머리글을 항상 인쇄합니다.
- `-z, --zero-terminated` — 줄이 줄바꿈 대신 NUL로 구분됩니다.
- `-h, -?` — 이 명령 자체의 짧은 도움말을 표시합니다.

## EXAMPLES

- `tail log.txt` — `log.txt`의 마지막 10줄을 인쇄합니다.
- `tail -n 3 a b` — `a`와 `b`의 마지막 3줄을 각자의 머리글 아래에
  인쇄합니다.
- `tail -c 1K image` — `image`의 마지막 1024바이트를 인쇄합니다.
- `tail -n +5 notes` — `notes`를 5번째 줄부터 인쇄합니다.

## EXIT STATUS

- `0` — 모든 파일을 인쇄했습니다(또는 짧은 도움말을 썼습니다).
- `1` — 파일을 읽을 수 없었거나 출력을 전달할 수 없었습니다.
- `2` — 명령줄을 이해하지 못했습니다.

## ENVIRONMENT

- `LANG` — 짧은 도움말에 선호되는 로캘(`fr-FR` 같은 BCP-47 태그).
