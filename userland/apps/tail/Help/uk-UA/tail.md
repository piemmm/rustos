## NAME

tail — виводити останню частину файлів

## SYNOPSIS

`tail [option...] [file...]`

## DESCRIPTION

Виводить останні 10 рядків кожного `file` до стандартного виводу. За
наявності кількох `file` кожну частину випереджає заголовок
`==> file <==`. Без `file`, або коли `file` дорівнює `-`, читається
стандартний ввід.

`-n` та `-c` змінюють, скільки виводиться: проста кількість (або
записана з `-` на початку) виводить останні `num` рядків або байтів;
кількість, записана з `+` на початку, виводить усе **починаючи** з рядка
чи байта `num` (рахуючи від 1) до кінця. Кількість може мати суфікс
множника: `b` (512), `kB` (1000), `K` (1024), `MB`, `M`, `GB`, `G`, і
так далі для `T`, `P`, `E`, `Z`, `Y`, `R`, `Q` (окрема літера множить на
степені 1024; із `B` на степені 1000; із `iB` на степені 1024).

Історична форма першого аргументу `tail -num` / `tail +num` (з
необовʼязковою кінцевою літерою `b`/`c`/`l`) приймається, як і в
інструменті GNU.

Режим стеження тримає кожен файл відкритим і виводить нові дані в міру
його зростання; він блокується, доки файл не зміниться — ніколи
активне очікування. `-f` стежить за дескриптором; `-F` стежить за
іменем і повторно відкриває ротований файл, а `--retry` чекає появи
імені. `--pid=PID` завершує стеження, коли процес завершується
(перевірка кожні `--sleep-interval` секунд, типово 1;
`--max-unchanged-stats` типово 5). Про усічення повідомляється, і файл
відстежується з його нового початку.

Коли початковий вміст не показано, до стандартного потоку інформації
(fd 3) записується довідковий запис; він ніколи не змінює вивід чи код
виходу. Файл, який неможливо прочитати, повідомляється в потоці помилок,
і виконання триває з наступним файлом.

## OPTIONS

- `-c, --bytes <num>` — вивести останні `num` байтів кожного файлу; із
  `+` на початку — усе, починаючи з байта `num`.
- `-n, --lines <num>` — вивести останні `num` рядків кожного файлу; із
  `+` на початку — усе, починаючи з рядка `num`.
- `-q, --quiet, --silent` — ніколи не виводити заголовки `==> file <==`.
- `-v, --verbose` — завжди виводити заголовки `==> file <==`.
- `-z, --zero-terminated` — рядки розділяються NUL замість символу
  нового рядка.
- `-f, --follow[=descriptor]` — стежити за дескриптором, виводячи дописані дані.
- `-F` — стежити за іменем (`--follow=name --retry`); повторно відкривати ротований файл.
- `--follow=name` — стежити за іменем, а не за дескриптором.
- `--retry` — продовжувати спроби відкрити ще відсутній файл.
- `--pid <PID>` — зупинити стеження, коли процес `PID` завершиться.
- `--sleep-interval <N>` — секунди між перевірками (типово 1).
- `--max-unchanged-stats <N>` — тихі цикли, перш ніж `-F` перевірить ім'я (типово 5).
- `-h, -?` — показати коротку довідку цієї команди.

## EXAMPLES

- `tail log.txt` — вивести останні 10 рядків `log.txt`.
- `tail -n 3 a b` — вивести останні 3 рядки `a` та `b`, кожен під своїм
  заголовком.
- `tail -c 1K image` — вивести останні 1024 байти `image`.
- `tail -n +5 notes` — вивести `notes` починаючи з 5-го рядка.

## EXIT STATUS

- `0` — кожен файл виведено (або записано коротку довідку).
- `1` — файл не вдалося прочитати, або вивід не вдалося доставити.
- `2` — командний рядок не зрозуміло.

## ENVIRONMENT

- `LANG` — бажана локаль для короткої довідки (мітка BCP-47, наприклад
  `fr-FR`).
