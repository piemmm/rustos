## NAME

sysmon — カーネルのメモリと負荷をライブで観察する

## SYNOPSIS

`sysmon [-d 秒.十分の一] [-h | -?]`

## DESCRIPTION

システム情報 API を通じて、カーネルのメモリと負荷を全画面でライブ表示
します。対象は物理メモリ、カーネルヒープ、履歴付きのメモリ圧力バンド、
回収可能キャッシュの台帳、圧縮層 `ramzip`、ピン留めメモリの合計、CPU
ごとの負荷、そしてプロセスの集計です。意図的な負荷の下でも使用可能な
まま動き続け、アイドル時は更新の合間に静止します。

起動時にモニターは自身のメモリをピン留めします（`mem_pin`、
`CAP_MEM_PIN` が必要）。これにより、観察している当の圧力の下で自身の
ページフォルトに阻まれることがありません。ピン留めが拒否された場合は
タイトル行に報告され、セッションはピン留めなしで続行します — ピン留め
は付随的なもので、致命的にはなりません。

画面は各間隔（`-d` で変更しない限り 3.0 秒）ごとに自動更新され、`r`
で即時更新できます。モニターはオペランドを取りません: セッション内の
キーで操作します。

- `q` — 終了。
- `p` — 詳細パネルの切り替え: 回収可能キャッシュ、圧縮層、CPU ごとの
  負荷、プロセス。
- `r` — 今すぐ更新。
- `+` / `-` — 更新間隔を 1 秒ずつ延長 / 短縮（0.1 秒から 60 秒の
  範囲）。
- 上/下、PgUp/PgDn、Home/End — パネルのスクロール。
- `h`、`?` — キー一覧の表示切り替え。

詳細パネルの上には 6 行の要約があります: タイトル（稼働時間、負荷
平均、ピン留め状態）、ピン留め合計を含む MiB 単位のメモリ数値、深さ
ゲージ・空き/予約数値・突入カウンター付きの圧力バンド、バンド履歴
（更新ごとに 1 文字: `.` 正常、`-` 軽度、`=` 中程度、`#` 重度、`!`
危機）、CPU 全体の行、タスクの集計です。

すべての数値はシステム情報 API を経由します — `/proc` はありません。
カーネル統計の照会には `CAP_SYSINFO_KERNEL` が、全プロセスの集計には
`CAP_SYSINFO_GLOBAL` が必要です: いずれかを持たない呼び出し元には、
そのパネルの拒否が明示され、セッションの残りは続行します。完全な対話
型プロセス一覧は `top` の仕事です。ここのプロセスパネルは集計と、
`%CPU` およびメモリ別の上位消費者のみを表示します。

## OPTIONS

- `-d, --delay <seconds>` — 自動更新の間隔。秒単位で小数部は任意
  （最初の小数一桁、十分の一のみ保持）: `sysmon -d 1.5` は 1.5 秒
  ごとに更新します。既定は 3.0。GNU `top` はゼロ間隔を受け付けて
  可能な限り速く更新しますが、RustOS は決して空回りしないため、ゼロ
  は最小の 0.1 秒に引き上げられます。
- `-h, -?` — このコマンド自身の短いヘルプを表示して終了します。実行
  中のセッション内では、同じキーはキー一覧の表示切り替えになります。

## EXIT STATUS

- `0` — セッションが `q` で終了したか、短いヘルプが表示された。
- `1` — 端末に障害が発生。理由は標準エラーに出力される。
- `2` — コマンド行を解釈できなかった。

## ENVIRONMENT

- `LANG` — 短いヘルプの優先ロケール（`ja-JP` のような BCP-47 タグ）。
