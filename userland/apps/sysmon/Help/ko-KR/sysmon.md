## NAME

sysmon — 커널의 메모리와 부하를 실시간으로 관찰

## SYNOPSIS

`sysmon [-d 초.십분의일] [-h | -?]`

## DESCRIPTION

시스템 정보 API를 통해 커널의 메모리와 부하를 전체 화면으로 실시간
표시합니다. 대상은 물리 메모리, 커널 힙, 이력이 있는 메모리 압력
밴드, 회수 가능한 캐시 장부, 압축 계층 `ramzip`, 고정된 메모리 총량,
CPU별 부하, 프로세스 집계입니다. 이 도구는 의도된 부하 아래에서도
계속 사용할 수 있으며, 유휴 상태에서는 갱신 사이에 조용히 대기합니다.

시작할 때 모니터는 자신의 메모리를 고정합니다(`mem_pin`,
`CAP_MEM_PIN` 필요). 그래서 자신이 관찰하는 바로 그 압력 아래에서
자신의 페이지 폴트에 멈추는 일이 없습니다. 고정이 거부되면 제목 줄에
보고되고 세션은 고정 없이 계속됩니다 — 고정은 부수적이며 결코 치명적
이지 않습니다.

화면은 매 간격(`-d`로 바꾸지 않으면 3.0초)마다 스스로 갱신되며,
`r`은 즉시 갱신합니다. 모니터는 피연산자를 받지 않습니다: 세션 안의
키로 조작합니다.

- `q` — 종료.
- `p` — 상세 패널 전환: 회수 가능한 캐시, 압축 계층, CPU별 부하,
  프로세스.
- `r` — 지금 갱신.
- `+` / `-` — 갱신 간격을 1초씩 늘리기 / 줄이기 (0.1초에서 60초
  사이).
- 위/아래, PgUp/PgDn, Home/End — 패널 스크롤.
- `h`, `?` — 키 요약 표시 전환.

상세 패널 위에는 여섯 줄의 요약이 있습니다: 제목(가동 시간, 부하
평균, 고정 상태); 고정 총량을 포함한 MiB 단위 메모리 수치; 깊이
게이지와 여유/예비 수치, 진입 카운터가 있는 압력 밴드; 밴드 이력
(갱신마다 한 글자: `.` 정상, `-` 경미, `=` 보통, `#` 심각, `!`
위기); 전체 CPU 줄; 그리고 작업 집계.

모든 수치는 시스템 정보 API를 거칩니다 — `/proc`는 없습니다. 커널
통계 조회에는 `CAP_SYSINFO_KERNEL`이, 전체 프로세스 집계에는
`CAP_SYSINFO_GLOBAL`이 필요합니다: 둘 중 하나가 없는 호출자에게는
해당 패널의 거부가 명시되고 세션의 나머지는 계속됩니다. 완전한
대화형 프로세스 목록은 `top`의 일입니다. 여기의 프로세스 패널은
집계와 `%CPU` 및 메모리 기준 상위 소비자만 보여줍니다.

## OPTIONS

- `-d, --delay <seconds>` — 자동 갱신 사이의 간격. 초 단위이며 소수
  부분은 선택(첫 소수 자리, 십분의일만 유지): `sysmon -d 1.5`는
  1.5초마다 갱신합니다. 기본값 3.0. GNU `top`은 0 간격을 받아들여
  최대한 빠르게 갱신하지만, TAIRiX는 결코 헛돌지 않으므로 0은 최소값
  0.1초로 올립니다.
- `-h, -?` — 이 명령 자체의 짧은 도움말을 표시하고 종료합니다. 실행
  중인 세션 안에서는 같은 키가 대신 키 요약을 전환합니다.

## EXIT STATUS

- `0` — 세션이 `q`로 끝났거나 짧은 도움말이 표시됨.
- `1` — 터미널 오류; 이유가 표준 오류에 출력됨.
- `2` — 명령줄을 이해하지 못함.

## ENVIRONMENT

- `LANG` — 짧은 도움말의 선호 로케일(`ko-KR` 같은 BCP-47 태그).
