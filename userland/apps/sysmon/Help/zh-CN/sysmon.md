## NAME

sysmon — 实时观察内核的内存与负载

## SYNOPSIS

`sysmon [-d 秒.十分位] [-h | -?]`

## DESCRIPTION

通过系统信息 API 以全屏实时显示内核的内存与负载：物理内存、内核堆、
带历史记录的内存压力档位、可回收缓存台账、压缩层 `ramzip`、固定内存
总量、每个 CPU 的负载，以及进程统计。该工具在刻意施加的负载下依然
可用，空闲时在两次刷新之间保持静默。

启动时监视器会固定自己的内存（`mem_pin`，需要 `CAP_MEM_PIN`），
这样它在观察的压力之下永远不会因自身的缺页而停顿。固定被拒绝时会在
标题行报告，会话继续以未固定状态运行 —— 固定是附带的，绝不致命。

屏幕在每个间隔自动刷新（除非 `-d` 更改，默认 3.0 秒），`r` 立即
刷新。监视器不接受操作数：在会话内用按键控制。

- `q` — 退出。
- `p` — 轮换详情面板：可回收缓存、压缩层、每 CPU 负载、进程。
- `r` — 立即刷新。
- `+` / `-` — 将刷新间隔延长 / 缩短一秒，范围 0.1 到 60 秒。
- 上/下、PgUp/PgDn、Home/End — 滚动面板。
- `h`、`?` — 切换按键一览。

详情面板上方有六行摘要：标题（运行时间、负载平均值和固定状态）；
以 MiB 计的内存数字及固定总量；带深度计、空闲/预留数字和进入计数器
的压力档位；档位历史（每次刷新一个字符：`.` 正常、`-` 轻度、`=`
中度、`#` 重度、`!` 危急）；CPU 总览行；以及任务统计。

每个数字都经由系统信息 API —— 没有 `/proc` 可抓取。内核统计查询
需要 `CAP_SYSINFO_KERNEL`，全部进程统计需要 `CAP_SYSINFO_GLOBAL`：
缺少其一的调用者会看到该面板的拒绝被明确说明，而会话的其余部分继续
运行。完整的交互式进程列表是 `top` 的职责；这里的进程面板只显示
统计以及按 `%CPU` 和内存排序的最大消费者。

## OPTIONS

- `-d, --delay <seconds>` — 自动刷新之间的间隔，单位为秒，可带小数
  （只保留第一位小数，即十分位）：`sysmon -d 1.5` 每 1.5 秒刷新一
  次。默认 3.0。GNU `top` 接受零间隔并尽可能快地刷新；TAIRiX 从不
  空转，因此零会被提高到最小值 0.1 秒。
- `-h, -?` — 显示本命令自己的简短帮助并退出。在运行中的会话内，
  同样的按键改为切换按键一览。

## EXIT STATUS

- `0` — 会话以 `q` 结束，或显示了简短帮助。
- `1` — 终端出错；原因写到标准错误。
- `2` — 无法理解命令行。

## ENVIRONMENT

- `LANG` — 简短帮助的首选区域设置（形如 `zh-CN` 的 BCP-47 标签）。
