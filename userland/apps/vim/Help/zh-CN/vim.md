## NAME

vim — 模态文本编辑器

## SYNOPSIS

`vim [-R] [+num | + | +/pattern] [--] [file ...]`

## DESCRIPTION

用著名 vim 编辑器的模态命令集编辑文本文件。会话从普通模式开始：按键即命
令，`i`（或 `a`、`o` 及其变体）进入插入模式，此时输入成为文本。`Esc` 返
回普通模式。`:q` 退出；`:wq`（或 `ZZ`）写入并退出。

可以指定多个文件；会话打开第一个，`:n` / `:prev` 在参数列表中前后移动。
尚不存在的文件是 `[New File]`，在第一次写入时创建。

普通模式命令（已实现的 vim 核心）：

- 移动：`h j k l`、方向键、`w W b B e E`、`0 ^ $`、`f F t T` 及其
  `;`/`,` 重复、`gg G`、`{ }`、`%`、`H M L` 和 `Enter`。计数前缀重复一个
  移动：`3w`。
- 操作符：`d`（删除）、`c`（更改）、`y`（复制），可施于任何移动或文本对
  象（`iw aw i( a( i[ i{ i" i' i<` 及其配对）；双写（`dd cc yy`）时作用
  于整行。简写：`x X s S D C Y r ~ J`。
- 寄存器：操作符或粘贴前的 `"a`–`"z` 选择命名寄存器；大写字母表示追加。
  `p`/`P` 在光标后/前粘贴。
- 撤销历史：`u` 撤销整个更改，`Ctrl-R` 重做，`.` 重复上次更改（包括其插
  入的文本）。
- 搜索：`/pattern` 向前，`?pattern` 向后，`n`/`N` 重复，`*` 查找光标下
  的词。模式支持字面量、`.`、`*`、`^`、`$`、`[...]` 类和 `\<` `\>` 词边
  界。匹配保持高亮直到 `:noh`。
- 可视选择：`v`（字符）和 `V`（行），用任何移动或文本对象扩展，再用
  `d x c s y J` 操作。
- 滚动：`Ctrl-D Ctrl-U`（半窗）、`Ctrl-F Ctrl-B` 和 PageUp/PageDown（整
  窗）；`Ctrl-G` 显示文件摘要。

ex（`:`）命令核心：`:w [file]`、`:q`、`:wq`、`:x`、`:e file`、`:enew`、
`:r file`、`:n`、`:prev`、`:noh`、`:set number` / `:set nonumber`、行地
址（`:12`、`:$`、`:.+2`）、`:[range]d` 以及
`:[range]s/pattern/replacement/[g]`（替换中 `&` 表示整个匹配，`%` 表示范
围内的每一行）。`w`、`q` 或 `e` 后的 `!` 强行越过只读姿态或未写入的更
改。

vim 在此核心之外的一切都分期到后续阶段；分期清单在源代码树的
`plans/VIM.md` 中。

## OPTIONS

- `-R` — 只读：缓冲区在内存中可编辑，但 `:w` 被拒绝，除非用 `:w!` 强
  制。
- `+num` — 从第一个文件的第 `num` 行开始。
- `+` — 从第一个文件的最后一行开始。
- `+/pattern` — 从第一个文件中 `pattern` 的第一个匹配处开始。
- `--` — 选项结束；之后的每个参数都是文件名。
- `-h, -?` — 显示本命令自身的简短帮助并退出。

## EXIT STATUS

- `0` — 会话以退出命令结束，或简短帮助已显示。
- `1` — 终端失败；原因打印在标准错误上。
- `2` — 无法理解命令行。

## ENVIRONMENT

- `LANG` — 简短帮助的首选区域设置（BCP-47 标签，例如 `zh-CN`）。
- `TERM` — 会话驱动的终端配置；未知的值退化到「dumb」基线。
