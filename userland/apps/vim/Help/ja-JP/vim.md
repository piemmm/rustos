## NAME

vim — モーダルなテキストエディタ

## SYNOPSIS

`vim [-R] [+num | + | +/pattern] [--] [file ...]`

## DESCRIPTION

よく知られた vim エディタのモーダルなコマンド群でテキストファイルを編集
します。セッションはノーマルモードで始まります。キーはコマンドであり、
`i`（または `a`、`o` とその変種）で挿入モードに入ると、打鍵が文字になり
ます。`Esc` でノーマルモードへ戻ります。`:q` で終了、`:wq`（または
`ZZ`）で書き込んで終了します。

複数のファイルを指定できます。セッションは最初の一つを開き、`:n` /
`:prev` で引数一覧をたどります。まだ存在しないファイルは `[New File]`
で、最初の書き込みで作成されます。

ノーマルモードのコマンド（実装済みの vim の核）：

- 移動：`h j k l`、矢印キー、`w W b B e E`、`0 ^ $`、`f F t T` と
  `;`/`,` の繰り返し、`gg G`、`{ }`、`%`、`H M L`、`Enter`。数の前置き
  は移動を繰り返します：`3w`。
- オペレータ：`d`（削除）、`c`（変更）、`y`（ヤンク）。任意の移動やテキ
  ストオブジェクト（`iw aw i( a( i[ i{ i" i' i<` とその対）に適用でき、
  二重打ち（`dd cc yy`）では行全体に働きます。短縮形：
  `x X s S D C Y r ~ J`。
- レジスタ：オペレータやプットの前の `"a`–`"z` が名前付きレジスタを選び
  ます。大文字は追記です。`p`/`P` はカーソルの後/前に貼り付けます。
- アンドゥ履歴：`u` は変更全体を取り消し、`Ctrl-R` はやり直し、`.` は直
  前の変更（挿入した文字も含めて）を繰り返します。
- 検索：`/pattern` は前方、`?pattern` は後方、`n`/`N` は繰り返し、`*`
  はカーソル下の単語を探します。パターンはリテラル、`.`、`*`、`^`、
  `$`、`[...]` のクラス、`\<` `\>` の単語境界に対応します。一致は
  `:noh` まで強調されたままです。
- ビジュアル選択：`v`（文字単位）と `V`（行単位）。任意の移動やテキスト
  オブジェクトで広げ、`d x c s y J` で操作します。
- スクロール：`Ctrl-D Ctrl-U`（半画面）、`Ctrl-F Ctrl-B` と
  PageUp/PageDown（全画面）。`Ctrl-G` はファイルの要約を示します。

ex（`:`）コマンドの核：`:w [file]`、`:q`、`:wq`、`:x`、`:e file`、
`:enew`、`:r file`、`:n`、`:prev`、`:noh`、`:set number` /
`:set nonumber`、行アドレス（`:12`、`:$`、`:.+2`）、`:[range]d`、そして
`:[range]s/pattern/replacement/[g]`（置換文字列の `&` は一致全体、`%`
は範囲内の全行）。`w`、`q`、`e` の後の `!` は、読み取り専用の姿勢や未書
き込みの変更を押し切ります。

この核を超えて vim が備えるものはすべて後の段階に区分されています。区分
の一覧はソースツリーの `plans/VIM.md` にあります。

## OPTIONS

- `-R` — 読み取り専用。バッファはメモリ上で編集できるが、`:w!` で強制し
  ない限り `:w` は拒否される。
- `+num` — 最初のファイルの `num` 行目から始める。
- `+` — 最初のファイルの最終行から始める。
- `+/pattern` — 最初のファイルで `pattern` が最初に一致した所から始め
  る。
- `--` — オプションの終わり。以降のすべての引数はファイル名。
- `-h, -?` — このコマンド自身の短いヘルプを表示して終了する。

## EXIT STATUS

- `0` — セッションが終了コマンドで終わった、または短いヘルプを表示し
  た。
- `1` — 端末が失敗した。理由は標準エラーに印字される。
- `2` — コマンド行を解釈できなかった。

## ENVIRONMENT

- `LANG` — 短いヘルプの優先ロケール（`ja-JP` のような BCP-47 タグ）。
- `TERM` — セッションが駆動する端末プロファイル。未知の値は「dumb」の基
  準線に格下げされる。
