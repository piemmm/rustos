## NAME

vim — 모드 기반 텍스트 편집기

## SYNOPSIS

`vim [-R] [+num | + | +/pattern] [--] [file ...]`

## DESCRIPTION

잘 알려진 vim 편집기의 모드 기반 명령 집합으로 텍스트 파일을 편집합니다.
세션은 일반 모드에서 시작합니다. 키가 곧 명령이고, `i`(또는 `a`, `o`와 그
변형)로 삽입 모드에 들어가면 입력이 텍스트가 됩니다. `Esc`는 일반 모드로
돌아갑니다. `:q`는 종료, `:wq`(또는 `ZZ`)는 쓰고 종료합니다.

여러 파일을 지정할 수 있습니다. 세션은 첫 파일을 열고 `:n` / `:prev`가
인수 목록을 오갑니다. 아직 없는 파일은 `[New File]`이며 첫 쓰기에서
만들어집니다.

일반 모드 명령(구현된 vim 핵심):

- 이동: `h j k l`, 방향키, `w W b B e E`, `0 ^ $`, `f F t T`와 `;`/`,`
  반복, `gg G`, `{ }`, `%`, `H M L`, `Enter`. 수 접두어는 이동을
  반복합니다: `3w`.
- 연산자: `d`(삭제), `c`(변경), `y`(복사). 어떤 이동이나 텍스트
  객체(`iw aw i( a( i[ i{ i" i' i<`와 그 짝)에도 적용되고, 겹쳐
  쓰면(`dd cc yy`) 행 전체에 작용합니다. 준말: `x X s S D C Y r ~ J`.
- 레지스터: 연산자나 붙여넣기 앞의 `"a`–`"z`가 이름 있는 레지스터를
  고릅니다. 대문자는 덧붙입니다. `p`/`P`는 커서 뒤/앞에 붙입니다.
- 되돌리기 역사: `u`는 변경 전체를 되돌리고, `Ctrl-R`은 다시 하며, `.`은
  마지막 변경(삽입된 텍스트 포함)을 반복합니다.
- 찾기: `/pattern`은 앞으로, `?pattern`은 뒤로, `n`/`N`은 반복, `*`는
  커서 아래 낱말을 찾습니다. 패턴은 리터럴, `.`, `*`, `^`, `$`, `[...]`
  클래스, `\<` `\>` 낱말 경계를 지원합니다. 일치는 `:noh`까지 강조된 채
  남습니다.
- 시각 선택: `v`(문자)와 `V`(행). 어떤 이동이나 텍스트 객체로도 넓히고,
  `d x c s y J`로 조작합니다.
- 스크롤: `Ctrl-D Ctrl-U`(반 화면), `Ctrl-F Ctrl-B`와
  PageUp/PageDown(전체 화면). `Ctrl-G`는 파일 요약을 보여 줍니다.

ex(`:`) 명령 핵심: `:w [file]`, `:q`, `:wq`, `:x`, `:e file`, `:enew`,
`:r file`, `:n`, `:prev`, `:noh`, `:set number` / `:set nonumber`, 행
주소(`:12`, `:$`, `:.+2`), `:[range]d`, 그리고
`:[range]s/pattern/replacement/[g]`(치환문에서 `&`는 일치 전체, `%`는
범위 안의 모든 행). `w`, `q`, `e` 뒤의 `!`는 읽기 전용 자세나 쓰지 않은
변경을 밀어붙입니다.

이 핵심 너머로 vim이 갖춘 모든 것은 뒤 단계로 구분되어 있습니다. 구분
목록은 소스 트리의 `plans/VIM.md`에 있습니다.

## OPTIONS

- `-R` — 읽기 전용: 버퍼는 메모리에서 편집되지만 `:w!`로 강제하지 않는
  한 `:w`는 거부됩니다.
- `+num` — 첫 파일의 `num` 행에서 시작합니다.
- `+` — 첫 파일의 마지막 행에서 시작합니다.
- `+/pattern` — 첫 파일에서 `pattern`의 첫 일치에서 시작합니다.
- `--` — 옵션의 끝. 이후의 모든 인수는 파일 이름입니다.
- `-h, -?` — 이 명령 자체의 짧은 도움말을 표시하고 종료합니다.

## EXIT STATUS

- `0` — 세션이 종료 명령으로 끝났거나 짧은 도움말이 표시되었습니다.
- `1` — 터미널이 실패했습니다. 이유가 표준 오류에 인쇄됩니다.
- `2` — 명령줄을 이해하지 못했습니다.

## ENVIRONMENT

- `LANG` — 짧은 도움말의 선호 로캘(`ko-KR` 같은 BCP-47 태그).
- `TERM` — 세션이 구동하는 터미널 프로필. 알 수 없는 값은 「dumb」
  기준선으로 낮아집니다.
