## NAME

true — לא לעשות דבר, בהצלחה

## SYNOPSIS

`true [ignored arguments]`

## DESCRIPTION

מסיים במצב `0` תוך התעלמות מכל ארגומנט. תסריטים משתמשים בו בכל מקום שבו
נדרשת פקודה שמצליחה תמיד — כפקודת מקום, כתנאי אמת תמידי או כגוף לולאה.

רק ארגומנט **ראשון** של `-h`, `-?` או `--help` מכובד (המיקום שבו `true`
של GNU מכבד את `--help`); בכל מיקום מאוחר יותר האסימונים הללו מתעלמים
כמו כל השאר.

## OPTIONS

- `-h, -?` — (כארגומנט ראשון בלבד) הצגת העזרה הקצרה של פקודה זו עצמה.

## EXAMPLES

- `true` — להצליח.
- `while true; do …; done` — לולאה עד שמפסיקים אותה.

## EXIT STATUS

- `0` — תמיד (זו כל מטרת הכלי).
- `1` — לא ניתן היה לכתוב עזרה קצרה שהתבקשה.

## ENVIRONMENT

- `LANG` — האזור המועדף לעזרה הקצרה (תג BCP-47 כגון `he-IL`).
