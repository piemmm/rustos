## NAME

true — нічого не робити, успішно

## SYNOPSIS

`true [ігноровані аргументи]`

## DESCRIPTION

Завершується зі статусом `0`, ігноруючи всі аргументи. Скрипти
використовують його всюди, де потрібна команда, що завжди
завершується успішно, — як команда-заглушка, завжди істинна умова чи
тіло циклу.

Враховується лише **перший** аргумент `-h`, `-?` або `--help` (позиція,
в якій GNU `true` враховує `--help`); у будь-якій пізнішій позиції ці
слова ігноруються, як і все інше.

## OPTIONS

- `-h, -?` — (лише як перший аргумент) показати коротку довідку цієї
  команди.

## EXAMPLES

- `true` — завершитися успішно.
- `while true; do …; done` — повторювати до переривання.

## EXIT STATUS

- `0` — завжди (це і є призначення інструмента).
- `1` — запитану коротку довідку не вдалося записати.

## ENVIRONMENT

- `LANG` — бажана локаль для короткої довідки (позначка BCP-47, як-от
  `uk-UA`).
