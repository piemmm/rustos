## NAME

true — 何もせず、成功する

## SYNOPSIS

`true [ignored arguments]`

## DESCRIPTION

すべての引数を無視して、状態 `0` で終了します。常に成功するコマンドが必要
な場面 — 置き場所を確保するだけのコマンド、常に真の条件、ループ本体 — でス
クリプトが使います。

**最初の**引数としての `-h`、`-?`、`--help` だけが受け付けられます（GNU の
`true` が `--help` を受け付ける位置です）。それ以降の位置では、これらの語
も他のすべてと同様に無視されます。

## OPTIONS

- `-h, -?` — （最初の引数のときのみ）このコマンド自身の短いヘルプを表示す
  る。

## EXAMPLES

- `true` — 成功する。
- `while true; do …; done` — 中断されるまでループする。

## EXIT STATUS

- `0` — 常に（それがこのツールの目的そのものです）。
- `1` — 要求された短いヘルプを書き出せなかった。

## ENVIRONMENT

- `LANG` — 短いヘルプの優先ロケール（`ja-JP` のような BCP-47 タグ）。
