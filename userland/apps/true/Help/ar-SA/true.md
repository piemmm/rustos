## NAME

true — لا تفعل شيئًا، وتنجح

## SYNOPSIS

`true [ignored arguments]`

## DESCRIPTION

يخرج بالحالة `0` متجاهلًا كل المعطيات. تستخدمه البرامج النصية حيثما لزم أمر
ينجح دائمًا — كأمر حافظ للمكان، أو شرط صحيح دائمًا، أو جسم حلقة.

لا يُقبل إلا معطى **أول** من `-h` أو `-?` أو `--help` (وهو الموضع الذي يقبل
فيه `true` من GNU الخيار `--help`)؛ وفي أي موضع لاحق تُتجاهل هذه الرموز
مثل كل شيء آخر.

## OPTIONS

- `-h, -?` — (كمعطى أول فقط) عرض المساعدة القصيرة لهذا الأمر نفسه.

## EXAMPLES

- `true` — النجاح.
- `while true; do …; done` — التكرار حتى المقاطعة.

## EXIT STATUS

- `0` — دائمًا (وهذا هو غرض الأداة كله).
- `1` — تعذّرت كتابة مساعدة قصيرة مطلوبة.

## ENVIRONMENT

- `LANG` — المنطقة المفضلة للمساعدة القصيرة (وسم BCP-47 مثل `ar-SA`).
