## NAME

edit — 전체 화면 텍스트 편집기

## SYNOPSIS

`edit [file] [-h | -?]`

## DESCRIPTION

고전 QuickBasic / MS-DOS 편집기의 정신을 잇는 전체 화면 텍스트
편집기입니다. 맨 위에 메뉴 막대, 그 아래 본문, 그리고 파일 이름·커서
위치·키 안내를 보여 주는 상태 줄이 있습니다. 한 번에 파일 하나를
편집합니다.

`file` 피연산자와 함께 시작하면 편집기는 그 파일을 불러옵니다. 아직 없는
파일은 빈 버퍼로 열리고 첫 저장에서 만들어집니다. 피연산자 없이 시작하면
이름 없는 버퍼를 열고 처음 저장할 때 이름을 물어봅니다.

메뉴(`F10` 또는 `Alt`와 제목의 강조 문자 — `File`은 `Alt-F`, `Search`는
`Alt-S` — 로 열고, 방향키로 이동, `Enter`로 선택, `Esc`나 `F10`으로
닫음)에는 다음이 있습니다.

- `File` — `New`, `Open...`, `Save`, `Save As...`, `Exit`.
- `Search` — `Find...`, `Repeat Last Find`.

저장하지 않은 변경을 버리게 될 동작(`New`, `Open...`, `Exit`)에서는
편집기가 먼저 물어봅니다. `y`는 저장하고 계속, `n`은 버림, `c`(또는
`Esc`)는 취소입니다.

세션 안의 키:

- 입력은 커서 위치에 삽입됩니다. `Insert`는 덮어쓰기를 전환합니다(상태
  줄에 `OVR`).
- `Enter`는 행을 나눕니다. `Backspace`와 `Delete`는 문자를 지우고 행
  끝에서는 행을 잇습니다.
- 방향키, `Home`, `End`, `PageUp`, `PageDown`은 커서를 옮기고, 화면은
  (수평으로도) 따라서 스크롤합니다.
- `Tab`은 다음 여덟 칸 멈춤까지 공백을 삽입합니다.
- `F1`은 키 요약을 보여 주고, `F2`는 저장, `F3`은 마지막 찾기 반복,
  `F10`(또는 `Alt-F` / `Alt-S`)은 메뉴를 엽니다.

`Find...`는 커서에서 앞으로, 글자 그대로 대소문자를 구분해 찾으며 버퍼
끝에서 되감아 돕니다. 일치가 없는 찾기는 `Match not found`를 보고하고
커서를 있던 자리에 둡니다.

이 편집기는 텍스트 파일만 편집하며, 무엇을 바꾸는지 정확히 말합니다.

- 파일은 16 MiB 이하의 UTF-8 텍스트여야 합니다. 그 밖의 것(이진 파일,
  홀로 있는 캐리지 리턴, 너무 큰 파일)은 이유를 밝히며 거부됩니다 —
  결코 깨진 채로 열리지 않습니다.
- 불러올 때 탭 문자는 여덟 칸 멈춤에서 공백으로 펼쳐지고, CRLF 행 끝은
  LF가 됩니다. 각 변환은 상태 줄에 알려지며, 결코 조용히 적용되지
  않습니다.
- 파일 끝 줄 바꿈의 유무는 보존됩니다.

세션 안에서 실패한 불러오기나 저장은 상태 줄에 보고되고 버퍼는
유지됩니다. 거부된 파일 때문에 세션이 죽는 일은 없습니다. 모든 경로는
커널이 호출자 자신의 신원으로 해석하고 권한을 검사합니다 — 편집기는 특별
권한을 갖지 않습니다.

## OPTIONS

- `-h, -?` — 이 명령 자체의 짧은 도움말을 표시하고 종료합니다.

## EXIT STATUS

- `0` — 세션이 `File > Exit`로 끝났거나 짧은 도움말이 표시되었습니다.
- `1` — 지정한 파일을 불러올 수 없었거나(텍스트가 아님, 너무 큼, 거부됨)
  터미널이 실패했습니다. 이유가 표준 오류에 인쇄됩니다.
- `2` — 명령줄을 이해하지 못했습니다.

## ENVIRONMENT

- `LANG` — 짧은 도움말의 선호 로캘(`ko-KR` 같은 BCP-47 태그).
- `TERM` — 세션이 그리는 대상 터미널. 알 수 없거나 없는 값은 안전한
  기준선으로 낮아집니다.
