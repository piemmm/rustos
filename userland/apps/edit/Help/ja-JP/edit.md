## NAME

edit — 全画面テキストエディタ

## SYNOPSIS

`edit [file] [-h | -?]`

## DESCRIPTION

古典的な QuickBasic / MS-DOS のエディタの精神を継ぐ全画面テキストエディ
タです。最上部にメニューバー、その下に本文、そしてファイル名・カーソル位
置・キーの手引きを示す状態行があります。一度に一つのファイルを編集しま
す。

`file` オペランド付きで起動すると、エディタはそのファイルを読み込みま
す。まだ存在しないファイルは空のバッファとして開かれ、最初の保存で作成さ
れます。オペランドなしで起動すると、無名のバッファを開き、最初の保存時に
名前を尋ねます。

メニュー（`F10`、または `Alt` と見出しの強調文字 — `File` は `Alt-F`、
`Search` は `Alt-S` — で開き、矢印キーで移動、`Enter` で選択、`Esc` か
`F10` で閉じる）には次があります。

- `File` — `New`、`Open...`、`Save`、`Save As...`、`Exit`。
- `Search` — `Find...`、`Repeat Last Find`。

未保存の変更を捨てることになる操作（`New`、`Open...`、`Exit`）では、エ
ディタが先に尋ねます。`y` は保存して続行、`n` は破棄、`c`（または
`Esc`）は取り消しです。

セッション内のキー：

- 打鍵はカーソル位置に挿入します。`Insert` は上書きを切り替えます（状態
  行に `OVR`）。
- `Enter` は行を分割します。`Backspace` と `Delete` は文字を消し、行末で
  は行をつなぎます。
- 矢印キー、`Home`、`End`、`PageUp`、`PageDown` はカーソルを動かし、
  ビューは（水平にも）追ってスクロールします。
- `Tab` は次の八桁の停止位置まで空白を挿入します。
- `F1` はキー一覧、`F2` は保存、`F3` は直前の検索の繰り返し、`F10`（また
  は `Alt-F` / `Alt-S`）はメニューを開きます。

`Find...` はカーソルから前方へ、文字通り・大文字小文字を区別して検索し、
バッファの終わりで回り込みます。一致のない検索は `Match not found` と報
告し、カーソルを元の場所に残します。

このエディタはテキストファイルだけを編集し、何を変えるかを正確に述べま
す。

- ファイルは 16 MiB 以下の UTF-8 テキストでなければなりません。それ以外
  （バイナリファイル、単独の復帰文字、大きすぎるファイル）は理由を述べて
  拒否されます — 決して文字化けのまま開かれません。
- 読み込み時にタブ文字は八桁の停止位置で空白に展開され、CRLF の行末は LF
  になります。各変換は状態行で告げられ、黙って適用されることはありませ
  ん。
- ファイル末尾の改行の有無は保存されます。

セッション内で失敗した読み込みや保存は状態行で報告され、バッファは保たれ
ます。拒否されたファイルのためにセッションが死ぬことはありません。すべて
のパスはカーネルが呼び出し元自身の身元で解決し、許可を検査します — エ
ディタは特別な権限を持ちません。

## OPTIONS

- `-h, -?` — このコマンド自身の短いヘルプを表示して終了する。

## EXIT STATUS

- `0` — セッションが `File > Exit` で終わった、または短いヘルプを表示し
  た。
- `1` — 名指しされたファイルを読み込めなかった（テキストでない、大きす
  ぎる、拒否された）、または端末が失敗した。理由は標準エラーに印字され
  る。
- `2` — コマンド行を解釈できなかった。

## ENVIRONMENT

- `LANG` — 短いヘルプの優先ロケール（`ja-JP` のような BCP-47 タグ）。
- `TERM` — セッションが描画対象とする端末。未知または欠落した値は安全な
  基準線に格下げされる。
