## NAME

edit — 全屏文本编辑器

## SYNOPSIS

`edit [file] [-h | -?]`

## DESCRIPTION

一个全屏文本编辑器，承袭经典 QuickBasic / MS-DOS 编辑器的风格：顶部一条
菜单栏，其下是正文，状态行显示文件名、光标位置和按键提示。它一次编辑一个
文件。

带 `file` 操作数启动时，编辑器载入该文件；尚不存在的文件作为空缓冲区打
开，并在第一次保存时创建。不带操作数启动时，打开一个无名缓冲区，第一次保
存时询问名字。

菜单（用 `F10` 或 `Alt` 加标题的高亮字母打开 — `Alt-F` 打开 `File`、
`Alt-S` 打开 `Search` — 用方向键导航，`Enter` 选择，`Esc` 或 `F10` 关闭）
包含：

- `File` — `New`、`Open...`、`Save`、`Save As...`、`Exit`。
- `Search` — `Find...`、`Repeat Last Find`。

当某个动作会丢弃未保存的更改（`New`、`Open...`、`Exit`）时，编辑器先询
问：`y` 保存并继续，`n` 丢弃，`c`（或 `Esc`）取消。

会话内的按键：

- 输入在光标处插入；`Insert` 切换覆盖模式（状态行显示 `OVR`）。
- `Enter` 拆分行；`Backspace` 和 `Delete` 删除字符，并在行尾合并行。
- 方向键、`Home`、`End`、`PageUp`、`PageDown` 移动光标；视图（包括水平方
  向）滚动跟随。
- `Tab` 插入空格直到下一个八列停位。
- `F1` 显示按键摘要，`F2` 保存，`F3` 重复上次查找，`F10`（或
  `Alt-F` / `Alt-S`）打开菜单。

`Find...` 从光标处向前按字面、区分大小写地搜索，在缓冲区末尾回绕；没有匹
配的搜索报告 `Match not found` 并让光标留在原处。

编辑器只编辑文本文件，并确切说明它改了什么：

- 文件必须是不超过 16 MiB 的 UTF-8 文本；其他任何东西（二进制文件、孤立
  的回车、过大的文件）都被拒绝并说明原因 — 绝不当作乱码打开。
- 载入时制表符按八列停位展开为空格，CRLF 行尾变为 LF；每次转换都在状态行
  上宣告，绝不悄悄进行。
- 文件末尾换行符的有无被保留。

会话内失败的载入或保存在状态行上报告，缓冲区保留；会话绝不因被拒绝的文件
而消亡。每个路径都由内核以调用者自己的身份解析并检查权限 — 编辑器不持有
特殊权限。

## OPTIONS

- `-h, -?` — 显示本命令自身的简短帮助并退出。

## EXIT STATUS

- `0` — 会话经 `File > Exit` 结束，或简短帮助已显示。
- `1` — 命名的文件无法载入（不是文本、过大或被拒绝），或终端失败；原因打
  印在标准错误上。
- `2` — 无法理解命令行。

## ENVIRONMENT

- `LANG` — 简短帮助的首选区域设置（BCP-47 标签，例如 `zh-CN`）。
- `TERM` — 会话为之绘制的终端；未知或缺失的值退化到安全基线。
