## NAME

du — 파일의 디스크 사용량 추정

## SYNOPSIS

`du [option...] [file...]`

## DESCRIPTION

각 `file` 피연산자를 순회하며 디렉터리마다(가장 깊은 것부터) 그 아래
트리가 차지하는 저장 공간을 `size<TAB>path` 형태로 출력한다. `file`
이 없으면 현재 디렉터리(`.`)를 순회한다. 디렉터리가 아닌 `file`
피연산자는 단독으로 출력된다.

기본 측정값은 마운트된 파일시스템이 보고하는 각 노드의 실제 할당된
저장 공간이므로, 희소 파일이나 압축된 파일은 실제로 차지하는 만큼만
계산된다. `--apparent-size`(또는 `-b`)는 대신 겉보기 바이트 길이를
측정한다. 크기는 단위 옵션이 달리 선택하지 않는 한 1024바이트 블록
으로 출력되며, 나중의 단위 옵션이 앞의 것을 대체하고, 블록 수는 올림
된다(부분적으로 사용된 블록도 사용된 블록이다).

읽을 수 없는 경로는 표준 오류로 보고되고 순회는 나머지를 계속한다.
읽을 수 없는 디렉터리는 추측된 부분 합 대신 아무것도 기여하지
않는다.

`du`는 이름이 여럿인 파일을 아직 중복 제거하지 않는다. 두 이름으로
도달한 파일은 이름마다 한 번씩 계산되며, GNU의 링크 중복 제거
스위치는 존재하지 않는다. `-x`(단일
파일시스템)는 아직 사용할 수 없다. `DU_BLOCK_SIZE` 계열 환경 변수는
읽지 않으며, 배율은 옵션만으로 선택된다.

## OPTIONS

- `-a, --all` — 디렉터리뿐 아니라 각 파일도 보고한다.
- `-s, --summarize` — 각 피연산자의 합계만 보고한다(`-a`, `-d`와
  충돌).
- `-c, --total` — `total`이라 표시된 총합 행을 덧붙인다.
- `-d, --max-depth <n>` — 피연산자 아래 최대 `n` 단계까지의
  디렉터리를 보고한다(`0`은 피연산자만). 합계는 변하지 않는다.
- `-S, --separate-dirs` — 디렉터리의 행은 그 하위 디렉터리를
  제외한다.
- `--apparent-size` — 할당된 저장 공간이 아니라 겉보기 바이트
  길이를 측정한다.
- `-b, --bytes` — 겉보기 크기를 단일 바이트로(블록 크기 1의
  `--apparent-size`).
- `-k` — 1024바이트 블록(기본값).
- `-m` — 1048576바이트 블록.
- `-h, --human-readable` — 1024의 거듭제곱으로 읽기 쉬운 크기
  (`1.0K`, `23M`).
- `--si` — 1000의 거듭제곱으로 읽기 쉬운 크기(`1.0k`, `23M`).
- `-B, --block-size <size>` — `size`바이트 블록으로 보고한다
  (`512`, `1K`, `1MiB`, `1GB`, `human-readable`, `si`).
- `-0, --null` — 각 행을 줄바꿈 대신 NUL로 끝낸다.
- `-?, --help` — 이 명령 자체의 짧은 도움말을 표시한다.

## EXAMPLES

- `du` — 현재 디렉터리의 트리, 디렉터리마다 한 행.
- `du -sh /Users/jo` — `/Users/jo`의 읽기 쉬운 합계 하나.
- `du -a docs` — `docs` 아래의 모든 파일과 디렉터리.
- `du -d1 -c /Apps /Users` — 각 저장소의 첫 단계와 총합.

## EXIT STATUS

- `0` — 모든 피연산자를 순회했다(또는 짧은 도움말을 출력했다).
- `1` — 경로를 읽을 수 없었거나 출력을 전달할 수 없었다.
- `2` — 명령줄을 이해할 수 없었다.

## ENVIRONMENT

- `LANG` — 짧은 도움말의 선호 로캘(`fr-FR` 같은 BCP-47 태그).
