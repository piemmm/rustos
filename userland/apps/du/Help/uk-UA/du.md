## NAME

du — оцінити використання дискового простору файлами

## SYNOPSIS

`du [option...] [file...]`

## DESCRIPTION

Обходить кожен операнд `file` і друкує, для кожного каталогу
(найглибший першим), обсяг сховища, який займає дерево під ним, у
вигляді `size<TAB>path`. Без `file` обходиться поточний каталог
(`.`). Операнд `file`, що не є каталогом, друкується окремо.

Типова міра — фактично виділене сховище кожного вузла, як його
повідомляє змонтована файлова система; розріджені або стиснуті файли
рахують те, що вони справді займають. `--apparent-size` (або `-b`)
натомість вимірює видимі довжини в байтах. Розміри друкуються в
блоках по 1024 байти, якщо параметр одиниці не вибере інше; пізніший
параметр одиниці замінює попередній, а кількість блоків округлюється
вгору (частково використаний блок — використаний блок).

Нечитабельний шлях повідомляється в стандартний потік помилок, і
обхід триває з рештою; нечитабельний каталог не додає нічого замість
вгаданої часткової суми.

Файл, досягнутий більш ніж одним іменем, рахується **один раз**, тож
його сховище не звітується двічі; натомість `-l` рахує кожне ім'я.
`-x` (одна файлова система) ще не доступний; змінні
середовища родини `DU_BLOCK_SIZE` не читаються — масштаб вибирається
лише параметрами.

## OPTIONS

- `-a, --all` — звітувати також про кожен файл, а не лише каталоги.
- `-s, --summarize` — звітувати лише підсумок кожного операнда
  (конфліктує з `-a` та `-d`).
- `-c, --total` — додати рядок загального підсумку з позначкою
  `total`.
- `-d, --max-depth <n>` — звітувати про каталоги щонайбільше `n`
  рівнів під операндом (`0` звітує лише про операнди); підсумки не
  змінюються.
- `-S, --separate-dirs` — рядок каталогу не включає його
  підкаталоги.
- `-l, --count-links` — рахувати файл з кількома іменами по разу на
  кожне ім'я, а не один раз.
- `--apparent-size` — вимірювати видимі довжини в байтах, а не
  виділене сховище.
- `-b, --bytes` — видимий розмір в окремих байтах
  (`--apparent-size` з розміром блока 1).
- `-k` — блоки по 1024 байти (типово).
- `-m` — блоки по 1048576 байтів.
- `-h, --human-readable` — зручні для читання розміри в степенях
  1024 (`1.0K`, `23M`).
- `--si` — зручні для читання розміри в степенях 1000 (`1.0k`,
  `23M`).
- `-B, --block-size <size>` — звітувати в блоках по `size` байтів
  (`512`, `1K`, `1MiB`, `1GB`, `human-readable`, `si`).
- `-0, --null` — завершувати кожен рядок NUL замість нового рядка.
- `-?, --help` — показати коротку довідку цієї команди.

## EXAMPLES

- `du` — дерево поточного каталогу, один рядок на каталог.
- `du -sh /Users/jo` — один зручний для читання підсумок для
  `/Users/jo`.
- `du -a docs` — кожен файл і каталог під `docs`.
- `du -d1 -c /Apps /Users` — перший рівень кожного сховища, потім
  загальний підсумок.

## EXIT STATUS

- `0` — кожен операнд обійдено (або надруковано коротку довідку).
- `1` — шлях не вдалося прочитати або вивід не вдалося доставити.
- `2` — командний рядок не зрозуміло.

## ENVIRONMENT

- `LANG` — бажана мова короткої довідки (тег BCP-47, як-от
  `fr-FR`).
