## NAME

top — 프로세스 목록을 실시간으로 지켜보기

## SYNOPSIS

`top [-d secs.tenths] [-h | -?]`

## DESCRIPTION

GNU `top`의 정신으로, 시스템 정보 API를 통해 프로세스 목록의 실시간 전체
화면 보기를 표시합니다. 호출자 자신의 프로세스에서 시작합니다. 시스템
전체 보기는 `CAP_SYSINFO_GLOBAL`을 지닌 호출자에게만 서비스가
허가합니다.

표시는 지연 간격마다 스스로 새로 고쳐지고(`-d`로 바꾸지 않으면 3.0초),
`r`은 즉시 새로 고칩니다.

뷰어는 피연산자를 받지 않습니다. 세션 안에서 누르는 키로 조작합니다.

- `q` — 종료합니다.
- `a` — 자신의 프로세스와 시스템 전체 보기 사이를 전환합니다. 서비스가
  시스템 전체 보기를 거부하면(`CAP_SYSINFO_GLOBAL`이 필요) 뷰어는 자신의
  프로세스에 머무르고 상태 줄이 이유를 말합니다. 세션은 계속 돕니다.
- `r` — 목록을 새로 고칩니다.
- 위/아래, PageUp/PageDown, Home/End — 선택을 옮깁니다.
- `h`, `?` — 세션 안의 키 안내 겹침 표시를 전환합니다.

목록 앞에 네 줄의 요약이 옵니다. 가동 시간·로그인한 사용자 수·1/5/15분
부하 평균, 상태별 작업 통계, `%Cpu(s)` 사용률 분할, MiB 단위의 메모리
숫자입니다. 메모리 줄에는 `CAP_SYSINFO_KERNEL`이 필요합니다. 없는
호출자에게는 거부가 명시되고 세션은 계속됩니다.

`%Cpu(s)` 줄은 지난 간격에 모든 CPU가 합쳐서 바쁘게(작업 실행) 보낸
몫과 놀며 보낸 몫을 보여 줍니다. RustOS는 바쁨과 놂 시간만 계산하므로,
GNU `top`이 바쁨 몫을 user/system/nice/iowait로 나누는 자리에서 이 줄은
일부러 실제 두 숫자만 보여 줍니다.

행은 `%CPU` 순으로, 가장 큰 소비자부터 정렬되고 다음을 담습니다.

- `PID` — 숫자 프로세스 id.
- `USER` — 소유 계정의 사용자 이름. 시스템 계정 명부에서 해석되며, 이름을
  해석할 수 없으면 숫자 uid가 대신합니다.
- `SIZE` — 프로세스 주소 공간에 매핑된 메모리(이미지, 스택, 힙 모두).
- `S` — 상태 문자: `R` 실행 중(초록), `r` 실행 가능, CPU 대기(청록), `S`
  잠듦, `T` 정지(노랑), `Z` 좀비(자홍). 색은 컬러 터미널에서만 나타나며,
  문자 자체가 항상 상태를 나릅니다.
- `%CPU` — 직전 새로 고침 이후 간격의 CPU 몫.
- `WCPU` — 새로 고침에 걸쳐 가중(지수 평활)된 CPU 몫. 순간 열보다
  안정적입니다.
- `TIME+` — 누적 CPU 시간, `분:초.백분초` 형식.
- `COMMAND` — 프로세스 이름.

## OPTIONS

- `-d, --delay <seconds>` — 자동 새로 고침 사이의 간격. 초 단위이며
  소수를 붙일 수 있습니다(소수 첫째 자리, 십분의 일 초만 유지).
  `top -d 1.5`는 1.5초마다 새로 고칩니다. 기본값은 3.0. GNU `top`은 0
  지연을 받아들여 가능한 한 빨리 새로 고치지만, RustOS는 결코 바쁜 대기를
  하지 않으므로 0은 최소값 0.1초로 고정됩니다.
- `-h, -?` — 이 명령 자체의 짧은 도움말을 표시하고 종료합니다. 실행 중인
  세션 안에서는 같은 키가 대신 키 안내 겹침 표시를 전환합니다.

## EXIT STATUS

- `0` — 세션이 `q`로 끝났거나 짧은 도움말이 표시되었습니다.
- `1` — 서비스나 터미널이 실패했습니다. 이유가 표준 오류에 인쇄됩니다.
- `2` — 명령줄을 이해하지 못했습니다.

## ENVIRONMENT

- `LANG` — 짧은 도움말의 선호 로캘(`ko-KR` 같은 BCP-47 태그).
