## NAME

top — 实时观察进程列表

## SYNOPSIS

`top [-d secs.tenths] [-h | -?]`

## DESCRIPTION

以 GNU `top` 的风格，通过系统信息 API 显示进程列表的实时全屏视图。它从调
用者自己的进程开始；全系统视图只由服务授予持有 `CAP_SYSINFO_GLOBAL` 的调
用者。

显示每隔一个延迟间隔自动刷新（除非 `-d` 改变，默认 3.0 秒），`r` 立即刷
新。

查看器不接受操作数：它由会话内按下的键控制。

- `q` — 退出。
- `a` — 在你自己的进程与全系统视图之间切换。若服务拒绝全系统视图（它需要
  `CAP_SYSINFO_GLOBAL`），查看器停留在你自己的进程上，状态行说明原因；会
  话继续运行。
- `r` — 刷新列表。
- 上/下、PageUp/PageDown、Home/End — 移动选择。
- `h`、`?` — 切换会话内按键提示层。

列表之前有四行摘要：运行时间、登录用户数和 1/5/15 分钟平均负载；按状态统
计的任务普查；`%Cpu(s)` 利用率划分；以及以 MiB 计的内存数字。内存行需要
`CAP_SYSINFO_KERNEL` — 没有它的调用者会看到明说的拒绝，会话继续。

`%Cpu(s)` 行显示上一间隔内所有 CPU 合计忙碌（运行任务）与空闲的份额。
RustOS 只统计忙碌与空闲时间，因此在 GNU `top` 把忙碌份额拆成
user/system/nice/iowait 的地方，这一行有意只显示两个真实数字。

各行按 `%CPU` 排序，最大消耗者在前，并携带：

- `PID` — 数字进程 id。
- `USER` — 属主账户的用户名，从系统账户目录解析；名字无法解析时以数字
  uid 代替。
- `SIZE` — 映射进进程地址空间的内存（映像、栈和堆一并计入）。
- `S` — 状态字母：`R` 运行中（绿）、`r` 可运行、等待 CPU（青）、`S` 睡
  眠、`T` 停止（黄）、`Z` 僵尸（品红）。颜色只在彩色终端上出现；字母本身
  始终携带状态。
- `%CPU` — 自上次刷新以来这一间隔内的 CPU 份额。
- `WCPU` — 跨刷新加权（指数平滑）的 CPU 份额，比瞬时列更平稳。
- `TIME+` — 累计 CPU 时间，形如 `分:秒.百分秒`。
- `COMMAND` — 进程名。

## OPTIONS

- `-d, --delay <seconds>` — 自动刷新之间的间隔，以秒计，可带小数（只保留
  第一位小数，即十分之一秒）：`top -d 1.5` 每 1.5 秒刷新一次。默认 3.0。
  GNU `top` 接受零延迟并尽可能快地刷新；RustOS 从不忙等，因此零被钳制到
  0.1 秒的下限。
- `-h, -?` — 显示本命令自身的简短帮助并退出。在运行中的会话里，相同的键
  改为切换按键提示层。

## EXIT STATUS

- `0` — 会话以 `q` 结束，或简短帮助已显示。
- `1` — 服务或终端失败；原因打印在标准错误上。
- `2` — 无法理解命令行。

## ENVIRONMENT

- `LANG` — 简短帮助的首选区域设置（BCP-47 标签，例如 `zh-CN`）。
