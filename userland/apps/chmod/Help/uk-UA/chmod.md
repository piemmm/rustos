## NAME

chmod — змінити біти режиму файлу

## SYNOPSIS

`chmod [-cfRv] [--] MODE file...`

## DESCRIPTION

Змінює біти доступу кожного файлового операнда на `MODE`, по черзі.
`MODE` — це або абсолютне вісімкове значення (`644`, `0755`, …), яке
повністю замінює біти доступу, або розділений комами список
символьних виразів `[ugoa]*[-+=][rwxXst]*` (`g+w`, `o-rx`, `a=rx`,
`u+s`), які перетворюють поточні біти файлу. Символьний `X` надає
виконання лише каталогу або файлу, що вже має біт виконання.

Лише власник файлу може змінити його режим; ядро відмовляє будь-кому
іншому, а володіння capability не дає жодних привілеїв. З `-R`
каталог-операнд змінюється, а потім рекурсивно змінюється його вміст.
Перша невдача зупиняє виконання перед будь-яким наступним операндом.
`--` завершує розбір параметрів: кожен наступний аргумент є
операндом. Режим, що починається з `-`, пишіть без дефіса (`a-w`) або
спершу завершіть параметри (`chmod -- -w file`).

## OPTIONS

- `-R, --recursive` — змінювати файли й каталоги рекурсивно.
- `-c, --changes` — повідомляти лише про файли, режим яких справді
  змінився.
- `-v, --verbose` — повідомляти про кожен опрацьований файл.
- `-f, --silent, --quiet` — не виводити більшість повідомлень про
  помилки; виконання все одно завершується невдачею, і код виходу це
  показує.
- `-h, -?, --help` — показати коротку довідку цієї команди.

## EXAMPLES

- `chmod 644 notes.txt` — читання/запис для власника, лише читання
  для решти.
- `chmod g+w shared.txt` — додати запис для групи до поточних
  бітів.
- `chmod -R a=rx Docs` — зробити дерево `Docs` доступним для
  читання й проходу всім.

## EXIT STATUS

- `0` — кожна зміна режиму вдалася.
- `1` — помилка файлової системи або виводу; причину надруковано в
  потік помилок (приховано з `-f`).
- `2` — командний рядок не зрозуміло, або операнд режиму не був ані
  вісімковим, ані символьним.

## ENVIRONMENT

- `LANG` — бажана локаль для короткої довідки (тег BCP-47, як-от
  `uk-UA`).
