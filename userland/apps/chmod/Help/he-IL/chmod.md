## NAME

chmod — שינוי סיביות המצב של קובץ

## SYNOPSIS

`chmod [-cfRv] [--] MODE file...`

## DESCRIPTION

משנה את סיביות ההרשאה של כל אופרנד קובץ ל-`MODE`, לפי הסדר. `MODE`
הוא ערך אוקטלי מוחלט (`644`, `0755`, …) שמחליף את סיביות ההרשאה
כליל, או רשימה מופרדת בפסיקים של ביטויים סמליים
`[ugoa]*[-+=][rwxXst]*` (`g+w`, `o-rx`, `a=rx`, `u+s`) שמעבדים את
הסיביות הנוכחיות של הקובץ. ה-`X` הסמלי מעניק הרצה רק לספרייה או
לקובץ שכבר נושא סיבית הרצה.

רק הבעלים של קובץ רשאי לשנות את מצבו; הליבה מסרבת לכל אחד אחר,
והחזקת capability אינה מעניקה שום עקיפה. עם `-R` אופרנד ספרייה
משתנה ואחריו תוכנו משתנה רקורסיבית. הכישלון הראשון עוצר את הריצה
לפני כל אופרנד מאוחר יותר. `--` מסיים את ניתוח האפשרויות: כל ארגומנט
מאוחר יותר הוא אופרנד. למצב שמתחיל ב-`-`, כתבו אותו בלי המקף
(`a-w`) או סיימו קודם את האפשרויות (`chmod -- -w file`).

## OPTIONS

- `-R, --recursive` — שינוי קבצים וספריות רקורסיבית.
- `-c, --changes` — דיווח רק על קבצים שמצבם השתנה בפועל.
- `-v, --verbose` — דיווח על כל קובץ שעובד.
- `-f, --silent, --quiet` — השתקת רוב הודעות השגיאה; הריצה עדיין
  נכשלת וקוד היציאה מדווח על כך.
- `-h, -?, --help` — הצגת העזרה הקצרה של פקודה זו.

## EXAMPLES

- `chmod 644 notes.txt` — קריאה/כתיבה לבעלים, קריאה בלבד לשאר.
- `chmod g+w shared.txt` — הוספת כתיבה לקבוצה לסיביות הנוכחיות.
- `chmod -R a=rx Docs` — הפיכת העץ `Docs` לקריא ועביר לכולם.

## EXIT STATUS

- `0` — כל שינויי המצב הצליחו.
- `1` — כשל של מערכת הקבצים או הפלט; הסיבה מודפסת לפלט השגיאה
  (מושתקת תחת `-f`).
- `2` — שורת הפקודה לא הובנה, או שאופרנד המצב לא היה אוקטלי ולא
  סמלי.

## ENVIRONMENT

- `LANG` — האזור המועדף לעזרה הקצרה (תג BCP-47 כגון `he-IL`).
