## NAME

chmod — تغيير بتّات نمط الملف

## SYNOPSIS

`chmod [-cfRv] [--] MODE file...`

## DESCRIPTION

يغيّر بتّات الأذونات لكل معامل ملف إلى `MODE`، بالترتيب. `MODE` هو
إما قيمة ثمانية مطلقة (`644`، `0755`، …) تستبدل بتّات الأذونات
بالكامل، أو قائمة من العبارات الرمزية مفصولة بفواصل
`[ugoa]*[-+=][rwxXst]*` (`g+w`، `o-rx`، `a=rx`، `u+s`) تحوّل بتّات
الملف الحالية. الرمز `X` يمنح التنفيذ فقط لدليل أو لملف يحمل بالفعل
بتّ تنفيذ.

مالك الملف وحده يستطيع تغيير نمطه؛ يرفض النواةُ أيَّ شخص آخر، وحيازة
capability لا تمنح أي تجاوز. مع `-R` يُغيَّر معامل الدليل ثم يُغيَّر
محتواه تكراريًا. يوقف أول فشلٍ التنفيذَ قبل أي معامل لاحق. `--` ينهي
تحليل الخيارات: كل وسيطة لاحقة معامل. لنمطٍ يبدأ بـ `-`، اكتبه بدون
الشرطة (`a-w`) أو أنهِ الخيارات أولًا (`chmod -- -w file`).

## OPTIONS

- `-R, --recursive` — تغيير الملفات والأدلة تكراريًا.
- `-c, --changes` — الإبلاغ فقط عن الملفات التي تغيّر نمطها فعلًا.
- `-v, --verbose` — الإبلاغ عن كل ملف عولج.
- `-f, --silent, --quiet` — كتم معظم رسائل الخطأ؛ يظل التنفيذ
  فاشلًا وتُظهر حالة الخروج ذلك.
- `-h, -?, --help` — عرض المساعدة القصيرة لهذا الأمر.

## EXAMPLES

- `chmod 644 notes.txt` — قراءة/كتابة للمالك، وقراءة فقط للبقية.
- `chmod g+w shared.txt` — إضافة كتابة المجموعة إلى البتّات
  الحالية.
- `chmod -R a=rx Docs` — جعل شجرة `Docs` قابلة للقراءة والعبور
  للجميع.

## EXIT STATUS

- `0` — نجح كل تغيير نمط.
- `1` — فشل في نظام الملفات أو الإخراج؛ يُطبع السبب على مخرج الخطأ
  (مكتوم مع `-f`).
- `2` — لم يُفهم سطر الأوامر، أو لم يكن معامل النمط ثمانيًا ولا
  رمزيًا.

## ENVIRONMENT

- `LANG` — اللغة المفضلة للمساعدة القصيرة (وسم BCP-47 مثل
  `ar-SA`).
