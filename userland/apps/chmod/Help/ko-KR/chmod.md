## NAME

chmod — 파일 모드 비트 변경

## SYNOPSIS

`chmod [-cfRv] [--] MODE file...`

## DESCRIPTION

각 파일 피연산자의 허가 비트를 순서대로 `MODE`로 변경합니다.
`MODE`는 허가 비트를 통째로 바꾸는 절대 8진수 값(`644`, `0755`
등)이거나, 파일의 현재 비트를 변형하는 쉼표로 구분된 기호 절
`[ugoa]*[-+=][rwxXst]*`(`g+w`, `o-rx`, `a=rx`, `u+s`)의 목록입니다.
기호 `X`는 디렉터리이거나 이미 실행 비트를 가진 파일에만 실행
권한을 부여합니다.

파일의 모드는 소유자만 변경할 수 있습니다. 커널은 그 외 누구도
거부하며, capability를 보유해도 예외가 되지 않습니다. `-R`을 주면
디렉터리 피연산자를 변경한 뒤 그 내용을 재귀적으로 변경합니다. 첫
번째 실패에서 이후 피연산자보다 먼저 실행이 중단됩니다. `--`는
옵션 해석을 끝내며, 이후의 모든 인수는 피연산자입니다. `-`로
시작하는 모드는 대시 없이 쓰거나(`a-w`) 옵션을 먼저
끝내십시오(`chmod -- -w file`).

## OPTIONS

- `-R, --recursive` — 파일과 디렉터리를 재귀적으로 변경합니다.
- `-c, --changes` — 모드가 실제로 바뀐 파일만 보고합니다.
- `-v, --verbose` — 처리한 모든 파일을 보고합니다.
- `-f, --silent, --quiet` — 대부분의 오류 메시지를 숨깁니다.
  실행은 여전히 실패하며 종료 코드가 이를 보고합니다.
- `-h, -?, --help` — 이 명령의 짧은 도움말을 표시합니다.

## EXAMPLES

- `chmod 644 notes.txt` — 소유자는 읽기/쓰기, 나머지는 읽기 전용.
- `chmod g+w shared.txt` — 현재 비트에 그룹 쓰기를 추가.
- `chmod -R a=rx Docs` — `Docs` 트리를 모두가 읽고 탐색할 수 있게
  만듭니다.

## EXIT STATUS

- `0` — 모든 모드 변경이 성공했습니다.
- `1` — 파일 시스템 또는 출력 실패. 이유는 표준 오류로
  출력됩니다(`-f`에서는 숨김).
- `2` — 명령줄을 이해하지 못했거나, 모드 피연산자가 8진수도
  기호도 아니었습니다.

## ENVIRONMENT

- `LANG` — 짧은 도움말에 사용할 선호 로캘(`ko-KR` 같은 BCP-47
  태그).
