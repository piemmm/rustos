## NAME

chmod — 更改文件模式位

## SYNOPSIS

`chmod [-cfRv] [--] MODE file...`

## DESCRIPTION

按顺序把每个文件操作数的权限位改为 `MODE`。`MODE` 要么是一个整体
替换权限位的绝对八进制值（`644`、`0755` 等），要么是一个以逗号分隔
的符号子句列表 `[ugoa]*[-+=][rwxXst]*`（`g+w`、`o-rx`、`a=rx`、
`u+s`），用来变换文件当前的权限位。符号 `X` 只对目录、或已带有执行
位的文件授予执行权限。

只有文件的所有者才能更改其模式；内核会拒绝其他任何人，持有
capability 也不能越权。加 `-R` 时，先更改目录操作数，然后递归更改
其内容。第一次失败会在任何后续操作数之前停止运行。`--` 结束选项解
析：之后的每个参数都是操作数。以 `-` 开头的模式请去掉短横线书写
（`a-w`），或先结束选项（`chmod -- -w file`）。

## OPTIONS

- `-R, --recursive` — 递归更改文件和目录。
- `-c, --changes` — 只报告模式确实发生变化的文件。
- `-v, --verbose` — 报告每个处理过的文件。
- `-f, --silent, --quiet` — 抑制大多数错误消息；运行仍会失败，
  退出状态会报告这一点。
- `-h, -?, --help` — 显示本命令的简短帮助。

## EXAMPLES

- `chmod 644 notes.txt` — 所有者可读写，其他人只读。
- `chmod g+w shared.txt` — 在当前权限位上增加组写权限。
- `chmod -R a=rx Docs` — 让 `Docs` 树对所有人可读且可进入。

## EXIT STATUS

- `0` — 每次模式更改都成功。
- `1` — 文件系统或输出失败；原因打印到标准错误（`-f` 下被抑
  制）。
- `2` — 无法理解命令行，或模式操作数既不是八进制也不是符号形式。

## ENVIRONMENT

- `LANG` — 简短帮助的首选区域设置（BCP-47 标签，如 `zh-CN`）。
