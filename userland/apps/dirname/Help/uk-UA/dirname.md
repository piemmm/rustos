## NAME

dirname — прибрати останню складову з назв

## SYNOPSIS

`dirname [-z] name...`

## DESCRIPTION

Друкує кожен запис шляху без його останньої складової: спочатку
прибираються кінцеві похилі риски, потім остання складова та похилі
риски перед нею. Операція суто лексична — жоден шлях не розв'язується і
не торкається диска. Запис без похилої риски, що лишилася, має
батьківський елемент `.`; батьківський елемент, що спорожнів, — це
корінь.

Корінь ніколи не розрізається: `dirname /tools` — це `/`, а —
відповідник у лісі сховищ TAIRiX — `dirname Home:/tools` — це
`Home:/`. Корінь псевдоніма (`Home:/`, `System:/`, …) відіграє саме ту
роль, яку `/` відіграє в системах POSIX.

## OPTIONS

- `-z, --zero` — завершувати кожен результат NUL замість переведення
  рядка.
- `-h, -?` — показати коротку довідку цієї команди.

## EXAMPLES

- `dirname /System/Commands/top.app` — надрукувати `/System/Commands`.
- `dirname src/lib.rs` — надрукувати `src`.
- `dirname file` — надрукувати `.` (немає каталожної частини).
- `dirname Home:/tools` — надрукувати `Home:/` (корінь ніколи не
  розрізається).

## EXIT STATUS

- `0` — результати (або коротку довідку) записано.
- `1` — вивід не вдалося доставити.
- `2` — командний рядок не було зрозуміло.

## ENVIRONMENT

- `LANG` — бажана локаль для короткої довідки (позначка BCP-47, як-от
  `uk-UA`).
