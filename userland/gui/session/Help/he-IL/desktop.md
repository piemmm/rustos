## NAME

desktop — הפעלת הפעלת שולחן העבודה הגרפית

## SYNOPSIS

`desktop`

## DESCRIPTION

מפעיל את הפעלת שולחן העבודה הגרפית על עמדת המכונה הזו: הפקודה רוכשת
את חוזה התצוגה והקלט הבלעדי של העמדה, מתחברת לשירות התצוגה ומריצה את
שולחן העבודה המורכב — מנהל החלונות ושורת המשימות — עד שההפעלה
מסתיימת. הפקודה חוזרת כאשר הפעלת שולחן העבודה מסתיימת.

אותו שולחן עבודה מופעל אוטומטית לאחר האימות כאשר המנהל הגדיר כניסה
גרפית (`configure os.loginType graphical`); פקודה זו מפעילה אותו לפי
דרישה ממעטפת טקסט.

כאשר אין שירות תצוגה פועל, או כאשר הפעלה אחרת כבר מחזיקה בעמדה,
הפקודה נכשלת וכותבת את הסיבה לפלט השגיאה התקני — היא לעולם אינה
מדיחה הפעלה פועלת.

## OPTIONS

- `-h, -?` — הצגת העזרה הקצרה של פקודה זו.

## EXAMPLES

- `desktop` — הפעלת הפעלת שולחן העבודה.

## EXIT STATUS

- `0` — העזרה הקצרה הוצגה.
- `2` — שורת הפקודה לא הובנה.
- כל קוד אחר שאינו אפס — ההפעלה לא יכלה להתחיל (אין עמדה, אין שירות
  תצוגה) או הסתיימה (חוזה העמדה אבד); הסיבה נכתבת לפלט השגיאה
  התקני.

## ENVIRONMENT

- `LANG` — האזור המועדף לעזרה הקצרה (תג BCP-47 כגון `fr-FR`).
