## NAME

desktop — 启动图形桌面会话

## SYNOPSIS

`desktop`

## DESCRIPTION

在本机的座席上启动图形桌面会话：该命令获取座席的独占显示与输入租约，
连接显示服务，并运行合成桌面——窗口管理器与任务栏——直到会话结束。
桌面会话结束时命令返回。

同一桌面会在认证后自动启动：在能够运行图形登录的机器上，图形登录
（`os.loginType`）即为默认。本命令则用于从文本 shell 按需启动它。

当没有显示服务在运行，或另一个会话已持有该座席时，命令失败并将原因
写入标准错误——它绝不会顶替正在运行的会话。

## OPTIONS

- `-h, -?` — 显示本命令自身的简短帮助。

## EXAMPLES

- `desktop` — 启动桌面会话。

## EXIT STATUS

- `0` — 已输出简短帮助。
- `2` — 无法理解命令行。
- 其他任何非零代码 — 会话无法启动（没有座席、没有显示服务）或已结束
  （座席租约丢失）；原因写入标准错误。

- `LANG` — 简短帮助的首选区域设置（BCP-47 标签，例如 `fr-FR`）。
