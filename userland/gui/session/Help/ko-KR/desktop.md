## NAME

desktop — 그래픽 데스크톱 세션 시작

## SYNOPSIS

`desktop`

## DESCRIPTION

이 머신의 좌석에서 그래픽 데스크톱 세션을 시작합니다. 명령은 좌석의
배타적인 디스플레이·입력 임차권을 획득하고 디스플레이 서비스에 연결한
뒤, 합성 데스크톱(창 관리자와 작업 표시줄)을 세션이 끝날 때까지
실행합니다. 데스크톱 세션이 끝나면 명령이 반환됩니다.

관리자가 그래픽 로그인(`configure os.loginType graphical`)을 설정한
경우 같은 데스크톱이 인증 후 자동으로 시작됩니다. 이 명령은 텍스트
셸에서 필요할 때 그것을 시작합니다.

디스플레이 서비스가 실행 중이 아니거나 다른 세션이 이미 좌석을 보유한
경우, 명령은 그 이유를 표준 오류에 기록하고 실패합니다 — 실행 중인
세션을 밀어내는 일은 결코 없습니다.

## OPTIONS

- `-h, -?` — 이 명령 자체의 짧은 도움말을 표시합니다.

## EXAMPLES

- `desktop` — 데스크톱 세션을 시작합니다.

## EXIT STATUS

- `0` — 짧은 도움말을 표시했습니다.
- `2` — 명령줄을 이해할 수 없었습니다.
- 그 밖의 0이 아닌 코드 — 세션을 시작할 수 없었거나(좌석 없음,
  디스플레이 서비스 없음) 세션이 끝났습니다(좌석 임차권 상실). 이유는
  표준 오류에 기록됩니다.

## ENVIRONMENT

- `LANG` — 짧은 도움말에 선호되는 로케일(`fr-FR` 같은 BCP-47 태그).
