## NAME

desktop — グラフィカルなデスクトップセッションを開始する

## SYNOPSIS

`desktop`

## DESCRIPTION

このマシンのシートでグラフィカルなデスクトップセッションを開始します。
コマンドはシートの排他的な表示・入力リースを取得し、ディスプレイサービス
に接続して、合成デスクトップ（ウィンドウマネージャとタスクバー）をセッ
ションが終わるまで実行します。デスクトップセッションが終了するとコマン
ドは戻ります。

同じデスクトップが認証後に自動的に起動します。グラフィカルログイン
（`os.loginType`）は、それを実行できる機械では既定です。本コマンドはテ
キストシェルから必要に応じてそれを起動します。

ディスプレイサービスが動いていない場合や、別のセッションが既にシートを
保持している場合、コマンドは理由を標準エラーに書いて失敗します。実行中
のセッションを押しのけることは決してありません。

## OPTIONS

- `-h, -?` — このコマンド自身の短いヘルプを表示します。

## EXAMPLES

- `desktop` — デスクトップセッションを開始する。

## EXIT STATUS

- `0` — 短いヘルプを表示した。
- `2` — コマンドラインを理解できなかった。
- その他の非ゼロコード — セッションを開始できなかった（シートがない、
  ディスプレイサービスがない）か、終了した（シートのリースを失った）。
  理由は標準エラーに書かれます。

## ENVIRONMENT

- `LANG` — 短いヘルプの優先ロケール（`fr-FR` のような BCP-47 タグ）。
